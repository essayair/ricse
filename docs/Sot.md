## 一期范围（严格收口）

| 纳入一期 ✅ | 不在本期 ⛔ |
|-----------|-----------|
| 合约：创建 → 审核 → 生效 | 履约执行 |
| 单一角色：采购/交易员 | 多角色、复杂权限 |
| 合约主线必需的最小数据模型 | 物流/仓单/资金等完整建模 |
| 最简版认证 + RBAC + 单一审批流程 | 通用审批引擎、多租户 |
| AI OS 文档体系骨架 + 持续完善 | — |

## 命名规范

### Git 提交前缀

| 前缀 | 场景 |
|------|------|
| `feat:` | 新功能 |
| `fix:` | 修复 |
| `docs:` | 仅文档 |
| `refactor:` | 重构 |
| `chore:` | 工程/配置 |
| `db:` | 数据库迁移/Prisma |
| `ai:` | AI 相关内容 |

### 分支命名

```
{type}/{描述}
示例：feat/contract-create, fix/login-redirect, db/add-contract-status
```
