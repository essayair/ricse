## 一期当前范围

最初“仅合约主线”的验证目标已经完成，后续经产品决策扩展为线上测试业务链：

| 已纳入并完成第一版 ✅ | 后续建设 ⬜ |
|----------------------|-------------|
| 合同、角色会签顺序审批、执行批次、执行通知 | 流程版本、节点增删排序和通用审批中心 |
| 物流运单、磅单、质检单 | 设备直连、OCR 服务、承运商/质检机构门户 |
| 采购入库、销售出库、库存批次、库存台账、库存冲销 | 结算、发票、收付款完整闭环 |
| 自建 JWT、多角色 RBAC、用户角色数据范围 | 主数据与组织模块的外部门户精细化视图 |
| 外部企业合同及下游关联数据隔离 | 参与方映射和字段级敏感信息隔离 |

### 权限与数据范围锁定口径

- 功能权限与数据范围分别计算。
- 一个账号可拥有多个角色，数据范围配置在用户角色授权上。
- 外部企业账号固定查看所属企业合作伙伴作为卖方、买方或签约主体的合同及其全部下游关联数据，同企业员工共享，不限创建人。
- 外部企业不能查看无关企业数据、不能授予系统管理员、一期最多 6 个有效账号。
- 列表、详情、候选单据、状态操作和附件必须使用同一服务端范围。
- 结算、发票和收付款后续开发时继续继承合同或出入库来源范围。

产品统一口径见[权限与数据范围规范](./产品/权限与数据范围规范.md)，技术实现见[角色权限与数据范围设计](./技术/模块设计/角色权限与数据范围.md)。
