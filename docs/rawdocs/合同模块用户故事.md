# 大宗贸易合同模块 — 用户故事与需求

> 版本：v1.0 | 日期：2026-07-08 | 对照原型 `ux-prototype/caixiao/`

---

## 用户画像

**采销业务员**（如业务经理、采购对接员、销售内勤）。日常工作：与上下游谈判条款 → 录入系统 → 跟踪执行 → 协调物流/质检/结算。

痛点：
- 合同录入字段太多，分不清哪些必填哪些可后补
- 价格条款复杂（一口价/基差定价/不定价），记不住对应的结算规则
- 不知道当前合同执行到哪一步了
- 不知道额度还剩多少

---

## 核心用户故事

### US-01：我作为业务员，需要创建一份采购/销售合同

**流程**：选择合同类型 → 填写基本信息 → 填写货物与价格 → 填写结算条款 → 提交审批

**字段定义**：

#### 第一步：合同基本信息（所有类型必填）

| 字段 | 说明 | 来源 |
|------|------|------|
| 合同标题 | 如「采购萤石粉CaF₂≥97% 5000吨」 | 手动 |
| 合同类型 | 采购 / 销售 / 双边（以销定购） | 选择 |
| 我方签约主体 | 选择内部企业（如嘉溢、供应链、和光云链） | 组织数据 |
| 业务部门 | 如采购部、销售部 | 组织数据 |
| 业务员 | 默认当前用户 | 自动 |
| 外部合同号 | 对手方给的合同号，方便对账 | 手动 |

#### 第二步：交易对手方信息

| 字段 | 说明 | 来源 |
|------|------|------|
| 对手方 | 供应商（采购合同）/ 客户（销售合同）/ 两端（双边） | 主数据 |
| 联系人/电话 | 选择对手方后自动填充 | 主数据 |
| 授信额度检查 | 选择后自动显示额度使用情况 | 系统计算 |

#### 第三步：货物与价格

| 字段 | 说明 |
|------|------|
| 物料 | 从主数据选择 |
| 合同数量（吨） | 数字 |
| 定价类型 | 一口价 / 基差定价 / 不定价 |
| 单价 | 一口价时填写 |
| 溢装比例上限 | 如 ±10%，大宗贸易惯例 |
| 短装比例下限 | 如 -5% |

#### 第四步：结算条款

| 字段 | 说明 |
|------|------|
| 结算数量依据 | 磅单净重 / 质检干重 / 合同量 |
| 预付比例 | 如 30% |
| 尾款支付周期 | 收到发票后 N 天 |
| 付款方式 | 电汇 / 承兑 / 信用证 |
| 扣水规则 | 水分超标扣款标准 |
| 扣杂规则 | 杂质超标扣款标准 |

#### 第五步（仅双边合同）：拆单预览

- 采购对手方选择
- 销售对手方选择
- 采购单价 / 销售单价
- 预估毛利 = 销售金额 - 采购金额

**验收标准**：
- 创建后可打印导出
- 额度超额时弹窗预警
- 双边提交时自动生成采购+销售两份合同

### US-02：我作为业务员，需要查看合同执行进度

**详情页展示**：

| 区域 | 内容 |
|------|------|
| 头部 | 合同编号、类型、状态、对手方名称 |
| 进度条 | 草稿→待审批→已通过→执行中→已完成 |
| 基本信息 | 签约主体、对手方、物料、数量、单价、总金额、日期 |
| 履约进度 | 已到货量/百分比、已入库批次、在途车辆、已结算额 |
| 关联单据 | 发货指令列表、结算单列表、磅单、质检单 |
| 操作历史 | 时间线：创建→审批→执行→收货→结算 |

**验收标准**：
- 能看到本合同产生的所有下游单据
- 能跳转到关联单据详情
- 状态进度条实时更新

---

### US-03：我作为业务员，需要对草稿合同进行编辑

**规则**：
- 仅草稿（DRAFT）可编辑
- 已驳回（REJECTED）可修改后重新提交
- 已生效后**不可编辑**，只能走变更流程（未来迭代）
- 编码/类型不可修改

---

### US-04：我作为运营管理员，需要审批合同

**审批操作**：通过 / 驳回（填写意见）

**审批后自动动作**：
- 审批通过 → 合同生效，可生成发货指令
- 审批驳回 → 退回草稿，业务员修改后可重新提交

---

## 状态机（完整版）

```
草稿(DRAFT)
  ├→ 提交审批 → 待审批(PENDING_APPROVAL)
  └→ 作废(VOIDED)

待审批(PENDING_APPROVAL)
  ├→ 审核通过 → 已生效(APPROVED)
  └→ 驳回 → 草稿(DRAFT)

已生效(APPROVED)
  └→ 开始执行 → 执行中(EXECUTING)

执行中(EXECUTING)
  ├→ 全部收货/结算完成 → 已完成(COMPLETED)
  └→ 终止 → 已关闭(CLOSED) 或 已作废(VOIDED)

已完成(COMPLETED)
  └→ (终端状态，不可变更)

已关闭(CLOSED)
  └→ (终端状态)

已作废(VOIDED)
  └→ (终端状态)
```

## 当前实现差距

### 已实现 ✅

| 功能 | 状态 |
|------|:---:|
| 创建合同（基本信息+行项） | ✅ |
| 合同列表（分页+搜索） | ✅ |
| 合同详情 + 状态流转 | ✅ |
| 编辑（仅草稿） | ✅ |
| 删除（仅草稿/已作废） | ✅ |

### 缺失 ❌

#### 数据字段缺失

合同表当前只有 12 个字段，大宗贸易合同实际需要 ~30+ 字段：

| 字段组 | 缺失字段 |
|--------|---------|
| 我方信息 | `companyId` 签约主体、`departmentId` 业务部门、`externalContractNo` 外部合同号 |
| 对手方 | `contactPerson`/`contactPhone`（应自动带出但不存冗余） |
| 货物 | `pricingType` 定价类型、`overfillPct` 溢装比例、`shortfallPct` 短装比例 |
| 履约 | `deliveryMethod` 交货方式、`deliveryLocation` 收货地 |
| 结算 | `prepayPct` 预付比例、`paymentDays` 账期、`paymentMethod` 付款方式、`moistureRule` 扣水、`impurityRule` 扣杂 |
| 双边 | 拆单逻辑（当前 type=BILATERAL 但不会自动拆分） |

#### 功能缺失

| 功能 | 差距 |
|------|------|
| 签约主体选择 | 无 Company 下拉 |
| 额度检查 | 无校验/预警 |
| 定价类型切换 | 无 |
| 双边拆单 | 无拆分逻辑 |
| 详情页关联单据 | 无下游单据列表 |
| 详情页履约进度 | 无 |
| 操作历史时间线 | 无 |
| 导出打印 | 无 |
| 附件上传 | 无 |
| 列表列数 | 7列 vs 原型11列 |
