### 1.5 文字色阶

| Tailwind 类 | 原型 Token | 用途 |
|------------|-----------|------|
| `text-foreground` | `--text: #0f172a` | 正文、标题 |
| `text-muted-foreground` | `--text-2: #64748b` | 次要文字 |
| `text-muted-foreground/70` | `--text-3: #94a3b8` | 最弱文字、占位符 |

### 1.6 使用原则

- **不要硬编码颜色值**（如 `#2563eb`、`text-gray-500`），一律使用语义类
- Badge 背景用 `success-bg`，文字用 `success`（已配对比度）
- 按钮主色用 `bg-primary` + `text-primary-foreground`

## 2. 字阶

| 层级 | Class | 大小 | 原型场景 |
|------|-------|------|----------|
| h1 | `text-3xl` | 30px | 页面标题 |
| h2 | `text-xl` | 20px | 区块标题 |
| h3 | `text-base` | 16px | 卡片标题 |
| body | `text-sm` | 14px | 正文、表格、表单 |
| small | `text-xs` | 12px | 辅助文字、标签 |
| micro | `text-[11px]` | 11px | 侧边栏分组标记、时间戳 |

字体使用系统字体栈（已在 `globals.css` 的 `body` 设置），不引入额外字体文件。

## 4. 圆角与阴影

| Token | Class | 值 | 原型 |
|-------|-------|-----|------|
| `--radius` | `rounded-md` | 6px | `--radius` |
| `--radius` + 4px | `rounded-lg` | 10px | `--radius-lg` |
| `--radius` - 2px | `rounded-sm` | 4px | — |
| `shadow-sm` | `shadow-sm` | 微阴影 | `--shadow-sm` |
| `shadow` | `shadow` | 卡片阴影 | `--shadow` |

卡片阴影在原型中 `--shadow: 0 1px 3px rgba(0,0,0,.1)`，浅且柔和，不使用大投影。

## 5. 组件规范

### 5.1 Badge

```
bg-{color}-bg text-{color} rounded-md px-2 py-0.5 text-xs font-medium
```

样式参考：

| 状态 | Class |
|------|-------|
| 成功/启用/已完成 | `bg-success-bg text-success` |
| 警告/预警/待处理 | `bg-warning-bg text-warning` |
| 危险/作废/停用 | `bg-destructive-bg text-destructive` |
| 普通/默认 | `bg-muted text-muted-foreground` |

### 5.2 Alert

```
flex items-start gap-3 rounded-lg p-3 text-sm bg-{color}-bg text-{color}
```

与 Badge 使用相同的语义色板。

### 5.3 按钮

| 变体 | Class |
|------|-------|
| 主要 | `bg-primary text-primary-foreground hover:bg-primary/90` |
| 默认（次要不强调） | `bg-secondary text-secondary-foreground hover:bg-secondary/80` |
| 幽灵（轻量） | `hover:bg-accent hover:text-accent-foreground` |
| 危险 | `bg-destructive text-destructive-foreground hover:bg-destructive/90` |
| 轮廓 | `border border-input bg-background hover:bg-accent` |

### 5.4 表格

- 表头 `text-xs font-medium text-muted-foreground uppercase`
- 行悬停 `hover:bg-muted/50`
- 单元格 `px-3 py-2 text-sm`

## 6. 侧边栏

折叠状态：宽 64px（仅图标），展开状态：宽 256px（16rem）。

- 一级标题 `text-sm font-semibold text-sidebar-foreground/70`
- 子菜单 `text-sm text-sidebar-foreground`
- 激活项 `bg-sidebar-accent text-sidebar-accent-foreground`
- 悬停 `hover:bg-sidebar-accent hover:text-sidebar-accent-foreground`
- 手风琴菜单切换路由后，仅当前路由所属一级模块自动展开；原模块失去激活状态时自动收起。
- 路由匹配必须先判断路径是否属于菜单基础路径，再执行生产任务等特殊子路由判断，禁止按字符串截取误判其他模块。

---

## 7. CSS 约定

- 所有 CSS 变量采用 shadcn/ui 标准命名（见 `globals.css`）
- 不使用 `@apply` 自定义类（除非组件库必需）
- Tailwind 自定义颜色名映射到 CSS 变量，不使用十六进制
