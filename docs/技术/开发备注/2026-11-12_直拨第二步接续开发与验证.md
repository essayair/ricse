# 直拨第二步接续开发与验证

## 接续范围

保留并继续另一会话已提交的 `9649624`（采购结算跟随销售、跨侧原因、税率读取），以及其未提交的4个磅单/运单页面改动。本次不重置代码、不操作生产、不自动提交推送。

1. 直拨磅单按供应商发货、客户收货带出主体，覆盖自动空白单、手工新增/追加及列表详情标签。
2. 新增库存管理二级菜单“直拨进出”，按交付版本成对展示采购/销售业务单据、双数量及凭证依据；支持搜索、状态/日期、分页、有效数量汇总与撤销历史展开。不计入仓库库存。
3. 接通运单待直拨交付筛选和中文入口，排除取消、转仓、拒收及结束合同，与移动待办数量保持相同规则。
4. 直拨两侧采信不再套用库存或货款选用；任一侧已采信后称重任务完成。交付与结算仍在各自流程选择依据。
5. 补齐小程序默认同侧磅单及跨侧原因，避免后端新增必填规则而移动端没有输入位置；保留常规库存选用。
6. 更新仓库内 `smoke-direct-domain.ts --http`，覆盖“先销售确认、采购再跟随”及新列表/筛选，不使用临时脚本作为唯一回归入口。
