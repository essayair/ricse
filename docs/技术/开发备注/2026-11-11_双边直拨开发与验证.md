# 双边直拨开发与验证

> 2026-11-11，Codex。本次仅本地开发、迁移和 QA，不包含生产操作、提交、推送或小程序上传。

## 开发内容

- 新增独立直拨执行、版本化交付及成对业务单据；两向数量一致、不产生仓储库存。
- 双边合同销售方向资料、合同附件分类、价格复制和差价提示；外部方向字段与附件隔离。
- 双边合同维护限内部运营；外部账号误配写权限仍拒绝创建、编辑、类型变更、状态变更及附件写入，保留本方方向只读查看。
- 配对执行创建页、合同参与方地址快速填入和联系人、两向剩余数量；共享运单及采购视角追踪。
- Web/小程序交付预览、确认、运营经理复核、撤销重确认、取消、拒收及整车转仓。
- 采购/销售结算来源适配、方向独立占用、有效交付版本快照、资金对手方保护、内部四流核对。
- 供应商承运/客户自提、最终报告归集任务补建、待直拨交付清单。
- 本地迁移两份；原地交割、历史 DIRECT 自动转换未实施。

## 验证方式

1. API 全套 Jest 回归；覆盖原库存、物流、价税、资金、质量及访问控制模块。
2. API/Web TypeScript 检查；小程序 TypeScript、变动文件 ESLint 和微信端编译。
3. 新脚本 `apps/api/scripts/smoke-direct-domain.ts`，附 `--http` 访问本机真实 API：
   - 硬限制 `localhost/127.0.0.1/[::1]` 下 `ricse_dev`，不接受生产 URL。
   - 真实管理员权限服务、真实事务/唯一约束；短期令牌不写文件、不打印。
   - QA 自建合同、两向批次/通知、三家伙伴、折干物料、单侧凭证、签收与质检。
   - 并发只生成一组 20 吨实物 / 19 吨辅助数量的配对单据，库存数不变。
   - 采购 19000 元、销售 22800 元分别确认结算，互不占用；有效结算阻止撤销。
   - 结算反向后撤销/第二版重确认；复核稳定快照；已签收车单取消；整车拒收；单车转仓且采购计划不重复。
   - 四流核对与执行候选的真实 HTTP 请求；`finally` 仅清理自建 QA 记录。

真实 HTTP 联调曾发现运行中的旧 API 未加载新增路由，返回 404；已精准重启本地核心 API 并复测，不是通过绕开 API 完成验证。浏览器访问宿主不可用，因此没有声称通过截图视觉测试；微信编译不等于真机验收。
