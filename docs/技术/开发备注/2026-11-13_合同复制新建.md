# 2026-11-13 合同复制新建

## 范围

用户确认后开发 Web 合同复制入口、独立新建表单、只读复制模板接口、来源权限检查与操作留痕。未操作生产、未提交推送。产品规则见[合同复制新建方案与使用说明](../../产品/合同复制新建方案与使用说明.md)。

## 实现

- `GET /contracts/:id/copy-template`：同时校验 `contract.create` 和来源 `contract.view`；按字段白名单构造模板，不写数据库。返回合同填写所需的精简启用物料目录，不额外要求主数据权限。
- `contract-copy.ts`：多行标量与 JSON 快照复制，深克隆采销规则；重置日期、编号与确认。草稿使用已保存原始表单，正式合同忽略旧缓存。
- `POST /contracts` 增加可选 `copySourceContractId`，后端重新检查来源；同事务写新草稿与 `COPY_FROM` 操作记录，已有 `clientRequestId` 幂等机制继续有效。无需 Prisma 迁移。
- 合同列表/详情由后端 `canCopy` 控制入口，服务端仍作最终授权。外部企业双边合同复制禁止。
- 原编辑表单提取为共享 `contract-editor.tsx`，编辑与 `/contracts/[id]/copy` 复用。复制首次保存使用 POST，后续 PATCH 新 ID；串行保存锁和请求标识防重复，先记住新 ID 再上传附件。
- 保留未记录 `materialId` 的历史质量规则快照，避免复制/编辑时被最新主数据模板覆盖；换物料时仍清空旧快照。
- 新建页展示来源和不可选档案提示；面包屑为合同管理 → 来源合同 → 复制新建合同。
