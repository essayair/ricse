# 计划数量偏差提示

- 原“磅差异常”实际比较的是磅单净重与运单计划数量，统一改称“计划数量偏差”；详情复核区为“计划数量偏差提示”，差值为“与计划差额”，参数为“计划偏差提示阈值”。
- Web 总览、磅单列表/详情及小程序统一提示含义，采用橙黄色 warning 配色，不再把计划偏差展示为红色异常。真实发货/收货磅差、重量一致性错误与质检拒收不混用。
- 计划偏差不再使过磅任务进入 EXCEPTION；仍按称重、待确认、库存采信完成正常推进。历史 EXCEPTION 在管理接口按已有进度兼容展示，不修改原始磅单，不清理历史数据。
- 保留按实际磅单的一次确认，不要求另填偏差原因；重量关系错误、凭证要求与后续业务权限不放宽。
- API 字段 abnormal、toleranceRate 及筛选参数保持兼容，不涉及数据库迁移。

验证：API 类型检查、74 套/800 项回归测试、Web 生产构建、小程序类型检查、变更文件 ESLint 与微信端编译通过；另有系统弹窗提示分类 3 项测试通过。浏览器与真机视觉验收仍需进行。
