## 开发内容与使用方法

| 功能 | 变化 | 使用位置 |
|---|---|---|
| 直拨进出 | 成对展示采购业务入库/销售出库，按交付版本筛选、分页、汇总与历史追溯；不形成仓库库存 | 库存管理 → 直拨进出 |
| 待交付入口与磅单 | 统一Web/移动待直拨条件；上游发货、下游收货主体正确；仅做两侧采信，不套用我方仓储库存选用 | 运单待直拨筛选、磅单管理、小程序工作台 |
| 双侧冻结快照 | 固化两侧采信磅单及报告品位、水分和净重差；不把采用依据复制成两侧原始事实，不用当前资料回填旧快照 | 运单直拨交付预览/确认、小程序、直拨进出展开记录 |
| 合作方检测 | 合同供应商/客户可直接出具合作方报告，无需客户变供应商或另建质检服务生态；第三方仍严格校验 | 任务添加报告、独立报告、小程序任务 |
| 独立报告关联 | 合同上下文只筛机构；首次关联任务锁定归属，全部解除后释放；修复管理员关联后详情404 | 检测报告 → 新建、关联任务 |
| 日期流水编号 | 常规与直拨批次/通知/运单共用事务锁和数字流水；直拨业务单据独立采购/销售前缀 | 新创建单据自动生成，旧编号不改 |
| 采购跟随销售 | 销售审批后才可保存采购；依据及数量只读跟随，金额按采购价；销售整单调量时采购须同车组同总量，页面自动带入 | 采购结算逐车选择、整单数量区 |

## 实测发现并修复

独立报告首次关联只写合同归属、不强行写一张磅单；管理员原查询组合中 `contract:{}` 被Prisma折叠，导致关联后404。现管理员直接返回全范围，普通/外部范围维持原规则。新增回归用例，并以完整HTTP验证“创建→确认→关联→读取→全部解除→范围释放”。
