# 运单结算防重复与列表合计

## 范围与规则

- 采购及销售实际货物结算（GOODS）按运单占用，不再仅按剩余数量判断可选性。未删除、未作废结算单均占用，包含草稿、驳回及待审批；作废后释放，编辑及确认原结算单排除本单。
- 依据服务同时检查当前货物行的结算明细及同一运单其他行占用。返回 `settlementOccupied` 与 `occupiedSettlements`，页面置灰并展示关联单号；后端预览、创建、更新及确认仍统一校验 `available`，绕过前端不能重复创建。写入沿用合同事务锁，避免并发重复占用。
- 不把运费结算与货款结算混为一类。物流结算原有运单占用、事务锁和作废释放规则保持不变；本次为其选车、详情和列表补合计。
- 不删除或改写已存在的结算记录。历史多张结算单占用同一运单时，不允许再建；如需继续修改冲突单据，应先人工核对并处理其他占用记录。

## 合计与显示

- 逐车依据表：当前筛选、已勾选范围；逐车结算明细：全部已选范围。结算金额仅使用当前有效后端计算结果，不显示过期计算金额。
- 结算详情及合同台账按当前展示数据统计；结算列表排除作废、包含草稿，并在合计标签明确，不冒充正式应收应付余额。
- 重量精度 3 位、金额精度 2 位，逐行取整后合计；缺失或非法数据不按 0 伪造合计。单价、百分比不相加，吨和车次分别统计。
- 无数据库迁移，不调整付款及核销业务规则。

## 回归重点

部分数量已结也不可重复选择；更换重量或报告不释放占用；草稿占用；编辑排除本单；作废、软删除不占用；同车其他行占用；采购销售方向；全选、取消、按批次筛选后的合计；缺失重量和负向金额调整；页面不产生实际新结算数据。
