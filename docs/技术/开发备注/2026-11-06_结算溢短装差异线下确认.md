# 结算溢短装差异线下确认

适用：采购、销售实际货物结算（GOODS）。不改变付款申请审批、库存过账和逐车质量价格计算。

## 产品口径

超出合同允许数量仍正常试算。生成前弹窗确认，差异说明必填、附件选填，允许按实际数量生成；不强制合同变更，不因这一项差异触发线上审批。分批结算不检查短装，勾选最终结算才检查合同各物料行短装下限。正式打印后供需双方线下签章，扫描件可后补。

## 数据及兼容

- 不增加数据库列或迁移；在首条结算明细 `sourceSnapshot.settlementQuantityReview` 保存版本、最终结算标记、逐物料差异、说明、经办人和时间。历史结算单无此快照时保持原流程，不强行补写或重算。
- 使用 Decimal 计算合同数量与 `overfillPct`、`shortfallPct`。累计包含未作废结算单的已结及草稿占用，编辑时排除本单；每个物料独立核对，不混加不同物料。
- DTO 新增 `isFinalSettlement`、`quantityVarianceConfirmed`、`quantityVarianceReason`、`quantityVarianceKey`。后端重新计算，不信任客户端提供的差额；预览签名变化必须重新核对。确认单据时再次检查合同及累计范围是否变化。
- 附件分类 `QUANTITY_VARIANCE_EVIDENCE` 为选填差异依据，不冒充 `SIGNED_SETTLEMENT_CONFIRMATION`。先保存单据，再上传文件；上传失败保留已保存单据并提示详情补传，避免重复建单。已确认有效结算允许追加附件，删除仍限草稿。
- 详情展示内部经办信息，打印只展示数量事实和双方确认说明。仅溢短装差异不进入线上审批；其他已存在的结算审批触发条件不变。
- 合同详情增加只读“结算记录”；列表 API 支持 `contractId` 精确筛选，仍要求 `settlement.view` 和原合同权限范围。差异说明读取结算快照而不复制到合同；有效金额按采购/销售分别汇总，排除草稿、待审批、驳回和作废。右侧履约结算入口定位该区域，详情链接沿用结算单权限。

## 验证重点

全选超上限仍有金额；不填说明不能确认生成；原因空白和过期预览签名均被后端拒绝；最终结算才提示短装；编辑排除本单；差异说明打印和草稿回显；已确认单据补传扫描件；历史单据不受影响。
