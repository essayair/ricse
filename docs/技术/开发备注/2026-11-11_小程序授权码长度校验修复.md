# 小程序授权码长度校验修复

## 问题与调整

小程序登录和手机号授权接口原先都使用 `MaxLength(200)`。请求中的 code 超过 200 字符即在 DTO 校验阶段被拒绝，尚未进入微信验证，前端收到英文长度错误。

- 两个接口的授权码上限统一调整为 4096 字符。这是服务端防御性上限，不是微信协议固定长度。
- 接受超过旧 200 字符限制的凭证，按原字符串交给微信验证，不截断、不重新编码或记录凭证。
- 保留字符串、非空白和最大长度校验，错误改为具体中文提示。
- 不改变微信登录与手机号授权码的分离使用、协议授权同意、身份校验、限流及微信实际验证。

## 验证与发布

回归覆盖短码、201/1024/4096 字符、不截断、缺失/空白/非字符串、超长拒绝及未同意协议拒绝。

验证通过：API 类型检查、后端生产构建、75 套/825 项完整回归测试（新增25项授权码校验用例），以及 `git diff --check`。未使用真实微信用户授权码联调。

本次仅调整 RICSE 后端，无数据库迁移，小程序请求格式不变。线上生效需要发布后端内容 API 服务；无需仅为此修复重新上传小程序。真实微信授权仍需发布后用新的一次性授权码验收，不能复用已消费或已过期的 code。
