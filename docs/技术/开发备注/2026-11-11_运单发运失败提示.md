# 运单发运失败提示

- Web发运失败标题明确为“发运失败”，正文保留服务端阻断原因。送达/到达确认与取消失败也使用对应动作标题。
- 失败弹窗采用既有错误色标题、图标、浅背景、边框和按钮，不显示成功样式。
- 合并通用系统弹窗和原生alert兼容入口的结果判断，先识别失败和前置要求，再识别成功。“销售常规出库必须先完成物流出库和库存扣减”不再因包含“完成”而误报成功。
- 小程序运单状态操作失败从容易截断的Toast改为完整原因弹窗，并显示对应失败标题与错误色确认按钮。
- 不修改销售出库前必须完成出库和库存扣减的校验，不自动发运或扣库存。
