# 运营管理后台配色规范

本规范适用于 RICSE Web 运营管理后台。颜色统一从 `apps/web/src/app/globals.css` 的 CSS 变量和 `apps/web/tailwind.config.ts` 的语义类取用，不在页面里直接写 Tailwind 原始色阶或十六进制颜色。新增颜色先判断能否复用现有语义；确需扩展时，同时定义文字、浅背景与边框，并检查对比度。

| 用途 | 文字 / 图标 | 浅背景 | 边框 |
| --- | --- | --- | --- |
| 页面正文与次要说明 | `text-foreground` / `text-muted-foreground` | `bg-background` / `bg-muted` | `border-border` |
| 主要操作、链接、选中 | `text-primary` | `bg-primary-bg` | `border-primary-border` |
| 提示信息 | `text-info` | `bg-info-bg` | `border-info-border` |
| 成功、完成 | `text-success` | `bg-success-bg` | `border-success-border` |
| 待处理、注意 | `text-warning` | `bg-warning-bg` | `border-warning-border` |
| 错误、拒绝、危险操作 | `text-destructive` | `bg-destructive-bg` | `border-destructive-border` |
| 采购 / 供应商 / 应付 | `text-business-purchase` | `bg-business-purchase-bg` | `border-business-purchase-border` |
| 销售 / 客户 / 应收 | `text-business-sales` | `bg-business-sales-bg` | `border-business-sales-border` |
| 双边合同 | `text-business-bilateral` | `bg-business-bilateral-bg` | `border-business-bilateral-border` |

交互约定：按钮和可点击项沿用共享组件的 `hover`、`focus`、`disabled` 样式；输入框聚焦使用 `ring`，错误提示使用错误色，不能只靠颜色传达状态。业务方向色与状态色分开：采购红不等于报错，销售蓝不等于所有信息提示。内部/外部企业属性用中性色，不占用警告色。打印归档页面保持黑白打印配色，不套用屏幕提示色。

状态文案优先使用 `StatusText`；新页面优先复用共享的 `Button`、`Badge`、`Input` 等组件，避免在同类元素上重复定义颜色。地图、图表等数据可视化可以使用独立连续色阶，但应与页面操作色区分。
