# 产业数据库模块设计

## 一 边界

产业数据库是静态产业研究资料库，部署在核心 API 中。它与 `partners`、合同和财务模型无外键关系，不沿用交易数据范围，也不向交易主数据自动同步。

## 二 数据模型

| 数据表 | 用途 |
|---|---|
| `industry_fluorite_producers` | 萤石生产企业独立档案 |
| `industry_fluorochemical_producers` | 氟化工生产企业档案 |
| `industry_mine_resources` | 矿山、矿区和资源项目 |
| `industry_capacity_projects` | 企业基地、产品和产能项目 |
| `industry_parks` | 氟化工产业园区及空间资料 |

所有表保留创建人、更新人、创建时间和更新时间。资料通过 `dataYear`、`source` 和 `remark` 说明静态数据的时间与来源口径。

## 三 API

统一前缀为 `/api/v1/industry-database`。

| 资源 | 列表与新增路径 |
|---|---|
| 产业概览 | `GET /summary` |
| 萤石生产企业 | `/fluorite-producers` |
| 氟化工生产企业 | `/fluorochemical-producers` |
| 矿山与资源 | `/mine-resources` |
| 产能与项目 | `/capacity-projects` |
| 产业园区 | `/parks` |

每种资料支持分页列表、关键词/省份/状态筛选、单条详情、新增、编辑和删除。

## 四 权限

| 权限编码 | 含义 |
|---|---|
| `industry.database.view` | 查看产业数据库和统计概览 |
| `industry.database.manage` | 新增、编辑和删除产业资料 |

迁移默认将两项权限授予 `ADMIN` 和 `CONTENT_OPERATOR`。前端按查看权限显示一级菜单，按维护权限显示新增、编辑和删除入口，后端再次强制校验。

## 五 后续扩展

Excel 导入、地图展示、数据版本管理和公开查询接口均在现有数据模型上扩展。自动采集、行情价格、政策和标准不属于当前模块范围。
