## 跨模块权限规则

所有新模块必须先阅读 `角色权限与数据范围.md`：

- 功能权限和数据范围分别校验；
- 外部企业范围以合同参与方为根，沿来源单据继承；
- 列表、详情、候选单据、状态操作和附件使用同一范围；
- 结算、发票、收付款等后续模块不得仅按创建人过滤。
