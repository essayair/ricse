# 销售出库与库存扣减模块设计

## 1. 业务链路

```text
销售执行批次
  → 销售发货通知单（指定发货仓库）
  → 待发运物流运单
  → 已复核出库磅单
  → 物流出库单（库存批次分配）
  → 销售出库单
  → 库存批次扣减 + 出库台账
  → 物流运单确认发运
```

销售常规出库在车辆发运前完成库存扣减。物流运单的 `PENDING → IN_TRANSIT` 状态变更会校验是否存在已入账物流出库单，防止货物已经发出但系统库存仍未扣减。

## 2. 数据模型

| 模型 | 职责 | 关键约束 |
|------|------|----------|
| `OutboundReceipt` | 物流出库、离场信息和出库数量快照 | `receiptNo` |
| `OutboundReceiptAllocation` | 物流出库单的库存批次分配 | `outboundReceiptId + inventoryLotId` |
| `SalesOutbound` | 货权和库存扣减凭证 | `outboundNo`、`receiptId` |
| `SalesOutboundLine` | 每个被扣减批次及扣减后余额 | `salesOutboundId + inventoryLotId` |
| `InventoryLedger` | 记录负数 `OUTBOUND` 变动 | 每个被扣减批次一条 |
| `Attachment` | 装车、门岗和放行凭证 | `outboundReceiptId` 外键 |

## 3. API

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/outbound-receipts/eligible-waybills` | 待发运且存在已复核出库磅单的销售常规运单 |
| GET | `/outbound-receipts/eligible-lots?waybillId=` | 指定运单可选库存批次 |
| POST | `/outbound-receipts` | 创建物流出库单和批次分配 |
| GET | `/outbound-receipts` | 关键词、状态查询 |
| GET | `/outbound-receipts/:id` | 完整出库详情 |
| PATCH | `/outbound-receipts/:id/confirm` | 确认货物离场 |
| PATCH | `/outbound-receipts/:id/cancel` | 作废草稿 |
| POST | `/outbound-receipts/:id/post` | 生成销售出库并扣减库存 |
| POST | `/outbound-receipts/:id/attachments` | 上传出库凭证 |
| DELETE | `/outbound-receipts/attachments/:id` | 删除草稿附件 |
| GET | `/outbound-receipts/attachments/:id/view-url` | 获取附件临时查看地址 |

## 4. 一致性设计

- 创建物流出库单时校验磅单结算重量与批次分配合计相等。
- 批次必须与销售发货仓库、物料一致，且状态为可用。
- 入账时使用带 `availableQuantity >= quantity` 条件的原子更新，防止并发超卖。
- 销售出库、所有批次扣减、出库明细、库存台账和物流出库状态更新处于同一数据库事务。
- 任一批次库存不足则整单回滚，不产生半张销售出库单或部分库存台账。
- 批次余额为零时状态改为 `DEPLETED`。

## 5. 首版边界

- 支持 `STANDARD` 常规销售出库。
- 一张物流运单只支持单一物料，可从多个库存批次组合出库。
- `DIRECT` 直拨出库需要补齐反向入库和虚拟库存过账，将独立迭代。
- 暂不支持出库冲销、销售退货、库存预占和拣货锁定。
