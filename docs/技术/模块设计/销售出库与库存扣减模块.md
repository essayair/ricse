# 出库管理、销售出库与库存扣减模块设计

## 1. 业务链路

```text
销售发货通知单下达
  → 自动生成通知级管理单
  → STANDARD：按仓库、物料冻结待出库库存，计算库存缺口
  → 创建物流运单
  → 自动生成车次出库作业（运单级）
  → 出库磅单（销售默认皮重后毛重）及可选质检单
  → 按已复核磅单实际重量拣配库存批次
  → 正常差异自动进入待放行，异常差异进入待处理
  → 确认放行
  → 销售出库单 + 批次扣减 + 负数库存台账 + 物流运单进入在途

销售直拨通知单下达
  → 自动生成 DFM 直拨发运管理占位单
  → 不冻结、不拣配、不扣减我方库存
  → 汇总物流运单、磅单、质检单、到达与签收进度
```

销售发货通知是库存冻结的唯一常规业务来源。通知草稿不冻结；通知下达时冻结只改变“待出库冻结”和“可用库存”，不改变账面库存，也不写库存台账。

## 2. 单据层级与基数

| 模型 | 业务名称 | 基数与职责 |
|------|----------|------------|
| `DispatchNotice` | 销售发货通知单 | 执行批次下的计划和仓库指令 |
| `OutboundOrder` | 出库/直拨发运管理单 | 一张销售发货通知对应一张；常规汇总库存冻结和多车出库，直拨承担过程跟踪占位 |
| `OutboundOrderLine` | 出库管理明细 | 按通知明细保存计划、冻结和累计实际出库 |
| `Waybill` | 物流运单 | 一张通知可以拆分多辆车 |
| `OutboundReceipt` | 车次出库作业单 | 一张销售运单一张有效作业，保存磅单、实际重量、差异和放行信息 |
| `OutboundReceiptAllocation` | 车次批次拣配 | 实际出库重量在一个或多个库存批次上的分配 |
| `SalesOutbound` / `SalesOutboundLine` | 销售出库单及明细 | 放行时生成的正式库存扣减凭证 |
| `InventoryLedger` | 库存台账 | 每个被扣减批次形成一条负数 `OUTBOUND` 记录 |

## 3. 库存口径

```text
账面库存 = InventoryLot.availableQuantity
待出库冻结 = 同库存主体、同仓库、同物料的有效 OutboundOrderLine 的 max(reservedQuantity - actualQuantity, 0)
可用库存 = 账面库存 - 待出库冻结
```

- 下达通知时按仓库、物料计算可冻结数量；库存不足仍允许下达并记录 `shortageQuantity`。
- `OutboundOrder.ownerPartnerId` 取销售合同我方签约主体；冻结和拣配只能使用 `InventoryLot.ownerPartnerId` 相同的库存，防止多个采购主体在同一仓库发生混库。
- “刷新库存预留”用于新库存入账后补充冻结。
- 库存总览按先进先出顺序将通知级冻结展示到库存批次，但正式批次扣减以车次拣配为准。
- 车次拣配会扣除其他未放行车次已经分配的批次数量，避免重复选择。
- 放行时再次以条件更新校验物理库存，任何批次不足都会使整个事务回滚，绝不形成负库存或部分出库。

## 4. 状态与阶段

### 出库管理单状态

`PENDING → PARTIAL → COMPLETED`，通知取消时进入 `CANCELLED`。

页面阶段由库存和下游单据计算：待物流安排、库存不足、待出库称重、待批次拣配、待差异处理、待放行、部分出库、已完成。

直拨占位单按物流运单计算：直拨待物流、直拨待发运、直拨运输中、直拨待完成、直拨已完成。

### 车次出库作业状态

```text
PENDING
  → READY（差异正常）
  → VARIANCE_PENDING（超出称重容差或通知剩余额度）
  → READY（完成短装/溢装处理）
  → POSTED

PENDING / READY / VARIANCE_PENDING → CANCELLED
```

短装处理支持“剩余后续补发”和“本车差额关闭”；溢装必须明确确认并填写处理意见。原通知计划数量不会被实际重量覆盖，计划、实际和差异独立保存。

## 5. 磅单与质检关联

- 创建磅单时可先用销售发货通知筛选，再必须选择具体物流运单。
- 最终关系为 `磅单 → 物流运单 → 销售发货通知 → 出库管理单`，防止多车通知下磅单归属不明。
- 待称重或称重中的磅单可以更换物流运单；完成称重、复核或被出库使用后锁定。
- 出库管理单自动展示所有运单及其磅单，不要求再次人工挂接。
- 质检单默认非必填；因质检单关联磅单，出库管理单会随磅单展示已有质检报告。

## 6. 放行事务

确认放行在同一数据库事务中完成：

1. 校验已复核出库磅单、差异处理结果和批次分配合计。
2. 为每个库存批次执行带余额条件的原子扣减。
3. 创建销售出库单、销售出库明细和负数库存台账。
4. 将车次作业置为 `POSTED`，累计出库管理单和明细实际数量。
5. 将物流运单置为 `IN_TRANSIT` 并记录实际发运时间。
6. 将销售发货通知从 `ISSUED` 更新为 `IN_PROGRESS`。

## 7. API

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/outbound-receipts/orders` | 查询通知级出库管理单 |
| GET | `/outbound-receipts/orders/:id` | 查询管理单、库存冻结和全部车次 |
| PATCH | `/outbound-receipts/orders/:id/refresh-reservation` | 刷新通知级库存冻结 |
| GET | `/outbound-receipts/eligible-waybills` | 查询已有复核磅单且待完善的车次作业 |
| GET | `/outbound-receipts/eligible-lots?waybillId=` | 查询扣除其他车次占用后的可拣配批次 |
| POST | `/outbound-receipts` | 为自动生成的车次作业补齐磅单、实际重量和批次分配 |
| PATCH | `/outbound-receipts/:id/variance` | 处理溢装或短装差异 |
| POST | `/outbound-receipts/:id/post` | 确认放行并原子完成库存扣减和运单发运 |
| PATCH | `/weigh-tickets/:id/waybill` | 复核前调整磅单关联物流运单 |

## 8. 权限和边界

- 查看使用 `inventory.view`，冻结刷新、拣配、差异处理、放行和附件操作使用 `inventory.manage`。
- 出库管理单通过 `dispatchNotice.order.contract` 继承销售合同数据范围；车次作业通过物流运单继承相同范围。
- `STANDARD` 支持常规仓库出库、单一物料运单、多车、多批次、部分出库和可选质检。
- `DIRECT` 当前支持通知下达自动生成占位单，以及物流、磅单、质检和签收进度展示；不生成我方库存业务。
- 直拨上下游通知绑定、采购应付与销售应收数量口径、多物料混装和合同溢短装独立审批仍作为后续增强。
