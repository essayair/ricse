# 内容运营中心

> 版本：v1.0
> 日期：2026-08-20
> 范围：产业链平台官网、氟萤直上小程序、数字大屏的数据与内容运营

## 1. 建设目标

在保持 `website` 官网和 `fyzs-mini-app` 小程序产品形态不变的前提下，将原 `website-admin-dashboard` 中自建的内容管理能力，以及 `hgchain-server`、`hgchain-server-17`、`fyzs-mini-app/server` 中与官网和小程序有关的后端能力，统一迁入 RICSE。

RICSE 新增一级菜单“内容运营”，进入后模块完整名称为“内容运营中心”，成为资讯、供需、价格、咨询、数据源、采集和 AI 能力的唯一管理入口。侧边栏中该模块与上方业务运营管理、下方基础管理分别成组。旧若依后台在迁移验收后停止使用，旧 Java/Nest 后端保留一段观察期后停止部署。

## 2. 产品边界

### 2.1 保持不变

- `website` 官网页面、交互和品牌展示保持不变，仅切换为 RICSE 新接口。
- `fyzs-mini-app` 小程序页面、交互和业务入口保持不变，仅切换为 RICSE 新接口。
- 官网和小程序继续使用现有 HTTPS 域名；微信合法域名不改变。

### 2.2 迁入 RICSE

- 产业资讯、栏目、封面、标签、发布状态和发布时间。
- 供应信息、采购需求、用户提交、平台代发和审核。
- 产品类型、地区规格、产品价格和区域均价。
- 官网合作咨询、联系人、联系方式、处理状态和跟进备注。
- 萤石数据文件、数据导入和数据源记录。
- 百川资讯行情采集、资讯同步、AI 清洗和执行日志。
- Business Analytiq 国际氢氟酸月度公开价格摘要采集、缓存和数字大屏展示。
- fluorspar.com 萤石价格趋势采集：华中 `cn_vp`、华东 `eu_fv`、北方 `eu_vp`，统一按美元/吨展示。
- 小程序微信登录、实时 AI 对话和公开内容查询接口。

### 2.3 不迁入

- 若依框架的用户、角色、菜单、字典、代码生成器及开源示例模块。
- `sci99` 已停用行情源，仅保留历史代码参考，不作为现行能力迁移。
- 与官网内容无关的若依支付、商城、IoT、CRM 等开源模块和通用任务。

## 3. 菜单设计

系统保持两级菜单，不新增三级导航。

| 一级菜单 | 二级菜单 | 主要能力 |
|---|---|---|
| 内容运营 | 资讯管理 | 资讯新增、编辑、发布、下线、栏目、封面和标签 |
| 内容运营 | 供需信息 | 供应/需求提交、审核、发布、驳回和下架 |
| 内容运营 | 价格行情 | 产品类型、地区规格、价格维护、区域均价和历史趋势 |
| 内容运营 | 官网咨询 | 合作咨询列表、状态、负责人和跟进备注 |
| 内容运营 | 数据源管理 | Excel 数据、外部数据源、导入记录和最近有效数据 |
| 内容运营 | 采集与 AI | 采集任务、AI 清洗、状态、日志、重试和暂停 |

栏目、产品类型等配置在相应页面内维护，不额外增加菜单层级。

## 4. 状态口径

### 4.1 资讯

`DRAFT 草稿 → PUBLISHED 已发布 → OFFLINE 已下线`

- 只有已发布且到达发布时间的资讯可由官网和小程序读取。
- 下线不删除历史数据；重新发布需要记录操作人和时间。
- 删除仅用于从未发布的错误草稿，并受内容删除权限控制。

### 4.2 供需信息

`PENDING 待审核 → PUBLISHED 已发布 / REJECTED 已驳回 → OFFLINE 已下线`

- 用户提交默认待审核。
- 公开接口不返回联系人、手机号、微信 OpenID 等敏感信息。
- 驳回必须填写原因；平台运营人员可直接创建草稿或发布。

### 4.3 官网咨询

`NEW 待处理 → FOLLOWING 跟进中 → COMPLETED 已完成 / INVALID 无效`

- 跟进过程保留处理人、处理时间和备注。
- 咨询提交接口必须限流并记录来源信息。

### 4.4 采集任务

`PENDING 待执行 → RUNNING 执行中 → SUCCEEDED 成功 / FAILED 失败 / CANCELLED 已取消`

- 同一数据源、同一业务日期的任务必须幂等。
- 失败按退避策略重试，超过上限进入人工处理。
- 查询端优先返回最近一次成功数据，采集失败不得清空有效数据。
- 国际氢氟酸行情由服务端采集，不允许大屏直接嵌入 Google Looker Studio；国内用户无需 VPN，页面必须显示数据期和来源。趋势基线仅使用 Business Analytiq 当前公开摘要及可核验的公开历史网页快照，不根据图像反算或虚构历史、预测数据。
- 萤石价格趋势由服务端每日采集三个区域年度接口；同日重复数据取来源返回的最后一条，异常大幅波动保留原值并记录质量标记，不做静默平滑。

## 5. 角色与权限

系统管理员固定拥有全部权限；其他角色通过“系统管理 → 用户与权限”配置。

| 权限 | 说明 |
|---|---|
| `content.article.view` | 查看资讯 |
| `content.article.manage` | 新增、编辑资讯和栏目 |
| `content.article.publish` | 发布、下线资讯 |
| `content.article.delete` | 删除未发布草稿 |
| `content.supply-demand.view` | 查看供需信息及联系方式 |
| `content.supply-demand.review` | 审核、驳回、发布、下架 |
| `content.price.view` | 查看价格与数据源 |
| `content.price.manage` | 维护产品价格与类型 |
| `content.contact.view` | 查看官网咨询 |
| `content.contact.manage` | 分配、跟进和关闭咨询 |
| `content.datasource.manage` | 上传数据和维护数据源 |
| `content.collection.manage` | 执行、暂停、重试采集与 AI 任务 |

## 6. 新旧接口切换

- RICSE 建立 `/api/v1/content/**` 后台接口，以及 `/api/v1/public/content/**`、`/api/v1/public/ai/**`、`/api/v1/public/wechat/**` 正式公开接口。
- 官网和小程序由我方同步升级并切换到新接口。
- 旧接口只保留为临时别名，调用同一应用服务和同一份数据，不复制业务逻辑。
- 官网旧接口建议保留 2～4 周；小程序旧接口保留 2～3 个月或直至访问量为零。
- 旧接口不增加新功能，仅修复安全问题和阻断性缺陷；到期后删除。
- “兼容”不仅指旧路径可访问，也包括切换后历史资讯、价格和走势继续可见。正式公开接口只读取 RICSE 统一内容库，Worker 负责从观察期旧服务幂等补迁；未完成数量和时间范围校验前不得停止旧服务。

## 7. 验收范围

- RICSE 可完成资讯、供需、价格、咨询和任务的完整管理。
- 官网和小程序切换新接口后无需改变页面行为。
- 历史文章 ID、图片、正文内嵌资源和发布时间保持有效。
- 小程序旧版本在兼容期仍可使用；新版本使用正式新接口。
- 百川或 DeepSeek 故障时，合同、库存、审批和物流接口仍正常。
- 采集失败可查看原因、重试，公开端继续展示最近一次有效数据。

## 8. 已实现范围（2026-08-20）

- RICSE 已增加一级菜单“内容运营”及资讯、供需、价格、咨询、数据源、采集与 AI 六个页面；进入模块后使用完整名称“内容运营中心”。
- 已实现内容栏目、资讯草稿/发布/下线、封面上传、供需审核、价格及产品类型、咨询跟进、数据源启停和任务重试。
- Excel 行情表通过数据源页面上传后进入异步导入队列；表头支持产品编码、产品名称、业务日期、地区、市场名称、价格、单位、涨跌和备注。
- 资讯同步、DeepSeek 清洗、百川行情及 Excel 解析均由独立 `content-worker` 执行。
- 官网和小程序 API 调用层已切换到正式接口；旧路径由兼容适配层临时转发到同一业务服务。
- 官网和小程序公开资讯统一以后台“已发布且已到计划发布时间”为唯一展示口径；客户端不得再按标题或正文长度过滤，手工资讯与采集资讯使用同一公开接口。
- 测试环境补充启动同步：历史资讯首次全量扫描、后续增量同步；行情在新采集凭据未配置时从旧行情服务回填，确保官网切换期间不出现历史数据空窗。
- 数字大屏主屏改为 RICSE 实时数据页；静态架构或演示页面明确标识“非实时数据”，未接入业务数据不再显示虚构数字。
- 国际氢氟酸采集任务 `HF_MARKET_SYNC` 每日检查一次公开月度摘要，按“月份 + 区域 + 来源”幂等入库；首次同步会写入 2023-05、2024-12、2025-03、2025-09、2026-02 五期可核验历史基线，之后按月累积，公开接口为 `/api/v1/public/content/market/hydrofluoric-acid/trend`。
- 萤石区域趋势采集任务 `FLUORSPAR_TREND_SYNC` 每日检查华中、华东、北方年度序列，公开接口为 `/api/v1/public/content/market/fluorite/price-trend`。
- 公开端的 AI、微信登录、咨询和供需提交已使用 Redis 分布式限流；用户供需提交与微信 OpenID 绑定。

## 9. 测试建议

1. 退出并重新登录 RICSE，确认管理员或具备任一 `content.*` 权限的角色可以看到“内容运营中心”。
2. 在资讯管理新增栏目和草稿，保存后编辑上传封面，再执行发布、下线和草稿删除。
3. 在供需信息创建平台信息，并验证小程序用户提交后为待审核、发布后公开端不泄露联系方式。
4. 在价格行情新增产品类型和手工价格，验证区域快照与市场趋势；在数据源管理上传一份标准行情 Excel，去任务列表查看异步结果。
5. 未配置第三方凭据时，微信、DeepSeek、百川任务应显示明确失败原因；合同、库存、审批和物流仍须正常使用。
6. 配置凭据后手工触发资讯同步和行情同步，验证失败重试、数据源停用和最近成功数据降级。
7. 手工触发“采集国际氢氟酸行情”，确认四个区域价格入库；关闭外网或模拟源站超时后，大屏仍展示最近成功数据并注明数据期。
8. 手工触发“采集萤石趋势”，确认华中、华东、北方均更新到来源最新日期，三张趋势图分别显示且单位为美元/吨。
