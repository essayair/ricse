# 出入库计量质检依据与结算依据方案（讨论稿）

- 版本日期：2026-10-31
- 状态：首期功能已实施；合同结构化阈值、会计与税务口径仍待业务、财务确认
- 关联文档：《2026-10-28_双侧计量质检与萤石矿品位结算方案》《库存双数量与业务单据联动方案》《合同质量结算规则与扣款接收方案（讨论稿）》《采购付款与质量结算联动产品及开发方案》

## 一、背景与目标

采购和销售业务中，同一车货通常存在发货侧、收货侧两套磅单和质检报告。双方数据存在差异时，业务上需要分别回答三个问题：

1. 我方库存按什么记账：实物收发以哪一侧的单据为准。
2. 货款按什么结算：结算数量、质量依据由谁、在什么环节确定。
3. 财务和税务存货按什么核对：货物、发票、金额如何保持一致。

本方案统一三类口径的边界，明确单据缺失时的处理方式，补充销售完成确认、结算依据选择、协商调整和财务存货核对等能力，并列出当前系统实现状态与差距。

## 二、四类数量口径

同一批货在不同环节存在四类数量，彼此不必相等，但差异必须可解释、可追溯。

| 口径 | 含义 | 来源 | 用途 |
| --- | --- | --- | --- |
| 实物数量 | 我方实际收发的货物重量（湿重） | 我方选定并复核的磅单净重 | 仓库管理、出库放行、盘点 |
| 计价数量 | 按物料计价口径换算的数量，例如折干 | 实物数量与最终采用质检报告的水分 | 业务库存价值、默认结算参考 |
| 结算数量 | 双方确认的货款结算数量 | 结算人员选定的依据及协商调整 | 应收应付、付款收款 |
| 发票数量 | 发票载明的数量与金额 | 发票 | 进项、销项税务及财务存货 |

示例（萤石粉采购，13 车）：

| 口径 | 数量 |
| --- | ---: |
| 我方实物入库（湿重） | 1153.95 吨 |
| 供应商折干数量 | 1049.38 吨 |
| 我方折干计价数量 | 1040.53 吨 |
| 双方协商结算数量 | 1044.88 吨 |
| 发票数量（应与结算一致） | 1044.88 吨 |

结算数量 1044.88 吨既不等于供应商数据，也不等于我方数据。系统必须支持在选定依据的基础上进行有依据的协商调整。

## 三、总体原则

1. 库存只记我方现场实际收发的实物与质量依据：采购入库采用我方收货磅单，销售出库采用我方发货磅单。商业结算依据由结算环节单独选定，不回写已过账库存。
2. 磅单与质检依据分别选定，默认同侧，允许有说明地不同侧。
3. 一份单据只承担一个事实：检测报告记录质量，不记录各车重量；各车数量永远取本车磅单。
4. 采用对方单据代替我方单据、结算偏离合同约定、协商调整，均须留痕：经办人、时间、理由、证据版本。
5. 已过账、已结算的单据不得因来源更正而静默重算，须走更正或复核流程。
6. 采购与销售规则对称。

## 四、采购入库

### 4.1 入库依据

采购入库以我方收货磅单和我方质检依据为准：

- 实物数量取我方复核磅单净重。
- 质量依据取质检任务最终采用的检测报告。
- 物料为折干计价时，必须有最终报告的水分实测值；物料为实物计价时，水分不参与数量计算，但仍须有质量判定结论。

### 4.2 同侧多张磅单与我方单据缺失

一车可以分别有多张发货、收货磅单。同一侧只有一张有效磅单时，复核后系统默认记为“采信发货磅单”或“采信收货磅单”；同侧出现多张时，必须由经办人选定该侧的采信磅单。改选填写原因并保留历史。

采购入库只采用我方采信收货磅单。供应商发货磅单可以作为发货事实或货款结算依据，不能直接代替我方入库磅单。若我方未过磅，不进入常规采购入库过账；直发、代储、港口等无我方现场的模式须另定专门流程，不借常规入库绕过。

补充要求：

- 采信选择与库存依据、货款结算依据分别留痕；我方采信收货磅单在尚未确认收货时同步为入库依据。
- 同侧多张未采信时，不得确认收货、入库过账或据此编制正式货款结算。
- 我方单据事后补录时，不自动改写已过账库存；如数量或质量需要变化，走库存更正流程。

### 4.3 质检依据

- 检测报告为独立单据，关联质检任务（车次）；混样报告逐项关联实际参与混样的车辆。
- 报告本身不提供重量，入库数量始终取本车磅单。
- 仅有对方质检报告时，不得把它自动冒充“我方检测”；能否作为例外质量验收依据仍需业务、质检明确审批口径。
- 允许磅单与质检来自不同侧（例如采用对方磅单、我方化验），须填写说明。

## 五、销售出库与销售完成

销售侧拆分为两个独立动作：出库扣减库存，销售完成确认关闭交易并作为应收依据。

### 5.1 出库占用（现状已实现）

- 销售发货通知下达后生成出库作业单，按计划数量占用库存，占用口径为仓库加物料，不锁定具体批次。
- 可用数量不足部分记为短缺数量。
- 占用数量不可被其他出库作业或生产领料使用，但不减少库存余额。

### 5.2 出库过账（现状已实现）

每车出库在货物离场前完成扣减，条件为：

- 关联我方已复核的出库磅单，且该磅单为运单当前选定的出库计量依据。
- 选定的来源入库批次分配数量之和等于磅单净重。
- 与计划数量的差异超出允许范围时，须先填写处理方式和原因。
- 放行确认后扣减库存：实物数量按磅单净重从所选批次扣减；计价数量按来源批次剩余比例同步扣减，批次清零时取计价余额尾差。
- 运单随后转为运输中。

### 5.3 出库质量例外放行（首版）

常规销售出库仍须采用我方已复核发货磅单。系统检查所分配来源库存批次的质量结论，以及本车是否有我方已确认的发货检测报告。来源批次结论不是“合格”或缺少本车我方发货报告时，不直接禁止出库；有 `inventory.manage` 权限的操作人必须填写原因，再确认放行。出库作业单保存异常事项、原因、操作人和时间；不修改原批次质检结论，也不替代合同质量争议处置。正常批次且有报告时无需填写例外原因。

### 5.4 销售完成确认（基础能力已开发）

- 客户签收后，明确选定一张已复核的客户收货磅单，并使用质检任务最终采用、已确认且标明“收货侧”的检测报告，形成销售完成确认。多张客户磅单时不得默认取第一张。
- 该动作不改变库存数量。
- 系统固化客户磅单、我方出库所用磅单、双方净重及重量差，供后续判定途耗或销售差异；不会回写已过账出库数量。差异的商业责任与结算金额仍待后续销售结算单确认，不因重量差自动生成扣款。
- 客户质检结论用于销售结算中的质量扣价或分档计价。
- 客户收货侧后续出现复磅时，未形成正式结算前可由经办人说明原因并改选采信磅单；同步更新销售交付数量与磅差快照，保留原选用历史。正式结算后不得直接覆盖。

### 5.5 存放期间重量变化

萤石粉等物料存放期间可能风干或吸潮，同一批次累计出库重量与入库重量会产生差异：

- 出库重量超过批次余额时，拦截出库，不允许负库存。
- 批次出完后仍有余量，或需补足短量时，通过盘点差异或损耗单据处理，须有依据和审批，不得在出库时静默抹平。

## 六、结算依据选择

采购应付与销售应收采用对称规则。

### 6.1 选择方式

1. 结算人员选择业务单据（执行批次或运单车次）。
2. 系统并列展示每车的发货侧、收货侧磅单和质检数据，以及双方差异对数量和金额的影响。
3. 结算人员分别选定重量依据和质量依据（水分、品位等），可选择不同侧，须填写说明。
4. 系统按合同固定价或分档价规则计算金额。

### 6.2 合同默认口径与审批

- 合同中的“结算数量约定”继续保留文本，不直接驱动库存或结算计算。结算经办人核对合同约定后，在结算单中明确选择依据；偏离约定时写明原因。允许磅差、质检差的系统阈值及结构化配置留待后续业务确认。
- 结算依据与合同约定一致且差异在允许范围内，按正常流程确认。
- 偏离合同约定、差异超出允许范围、或选用对我方不利的一侧时，须经风控或财务审批。
- 结算发起人与审批人分离。

### 6.3 协商调整

- 在选定依据的计算结果基础上，增加“协商调整”行，填写调整数量或金额、调整原因，并上传双方签章的结算确认单。
- 协商调整须经审批。
- 示例：以双方折干数量为参考，协商确定结算数量 1044.88 吨，单价 2920 元/吨，结算金额 3,051,049.60 元。

### 6.4 快照与锁定

- 结算确认后固化合同规则、所选磅单、所选报告、计算过程与调整明细。
- 已用于结算的磅单和报告锁定；来源单据更正时，结算单标记为待复核，不自动重算。
- 结算依据与库存依据不同时，结算单列示差异，不回写库存。

## 七、财务与税务存货

### 7.1 独立账簿

财务存货与业务库存分别记账：

- 业务库存：实物数量与计价数量，服务仓库管理和业务核算。
- 财务存货：以结算数量和发票为准，要求货物、发票、金额一致，服务成本核算和税务申报。

### 7.2 需要建设的能力

| 能力 | 说明 |
| --- | --- |
| 发票登记 | 进项、销项发票的数量、单价、金额、税额、品名规格，关联合同与结算单 |
| 三方匹配 | 入库（或出库）、结算、发票逐项核对，标识未到票、超开、品名不符等异常 |
| 暂估入库 | 已入库未到票时按结算或合同价暂估，发票到达后冲回暂估并按实际入账 |
| 差异核对 | 列示实物数量、计价数量、结算数量、发票数量之间的差异及原因 |
| 成本调整 | 业务计价与最终结算之间的差额进入存货成本或损耗的规则（待财务确定） |

## 八、其他需要覆盖的场景

| 场景 | 需要明确的问题 |
| --- | --- |
| 直发、背靠背（双边合同） | 货物不进我方仓库，我方无磅单和质检；是否做虚拟出入库；采购结算与销售结算分别采用哪一侧数据 |
| 第三方仲裁检验 | 双方质检差异超过合同阈值时由谁送检、结果是否替代双方数据、费用承担方 |
| 途耗与物流结算 | 发货与到货差额由谁承担；运费重量口径与货款依据的一致性（物流合同已有默认重量口径配置） |
| 混样报告 | 一份报告对应多车时，各车结算重量仍取本车磅单，结算页须正确展示共享报告 |
| 分次结算与尾差 | 预付、分批结算、最终结算之间数量累计不超、尾差可控 |
| 例外的批量处理 | 一批多车同时缺失我方单据时，确认、引用和后续更正支持整批操作 |

## 十、当前实施边界与待确认事项

1. 常规采购入库与销售出库已确定只采用我方侧采信磅单；直发、代储等无我方计量场景不套用常规出入库，须另行确定专门流程及授权岗位。
2. 常规销售出库的质量异常允许有 `inventory.manage` 权限人员填写原因后放行；是否要求事后补齐发货报告、二次复核以及销售合同质量争议的最终处理规则，仍待业务确认。
3. 销售交付完成确认首版要求客户已复核收货磅单及已确认收货侧检测报告；后续如存在客户无法提供报告的场景，再明确例外处理。
4. 合同结算口径的可选项及允许差异的默认值。
5. 结算审批使用独立的“采购销售结算”四节点配置，不改变付款申请既有三级审批；结算经办人与审批人是否强制分离、差异阈值仍待确定。
6. 结算单位：按车次结算、按批次汇总结算，还是两者均支持。
7. 财务存货的数量单位（湿吨或干吨）以及与业务库存差异的入账规则。
8. 首期已覆盖进项、销项发票登记与结算数量金额核对；正式财务存货账、税务申报和会计凭证仍待财务确认。

## 十一、建议实施顺序

1. 在试运行中核对同侧复磅采信、我方库存过账、双侧结算选择、销售交付与审批的实际业务操作；完善错误更正和批量处理。
2. 业务确认后，再把合同文本中的结算依据与容差改为结构化配置，补充自动差异识别、销售质量扣价与争议处置。
3. 按财务确认的口径建设业务库存—结算—发票三方匹配、暂估和成本差异；会计凭证及税务申报另立范围。

## 十二、交互草图与本轮实施说明

本轮先落地现场证据预览和不会混淆库存、货款的基础链路。所有图片附件在上传选择后显示本页缩略图；已存储图片通过原有权限校验接口获取缩略图，PDF 显示文件卡片，点击后在当前页面的预览层打开。

```text
采购运单 / 磅单信息
├─ 发货侧：供应商发货磅单（可追加、复磅）
├─ 收货侧：我方收货磅单（可追加、复磅）
├─ 库存入库依据：只采用我方收货采信磅单；供应商发货仅作发货事实与货款候选
└─ 采购货款依据：由结算经办人另选，不改写已入库数量

采购结算单
├─ 逐车对照：库存磅单/重量 ↔ 所选货款磅单/重量
├─ 质量依据：默认入库最终报告，可改选本车已确认的发货侧或收货侧报告；改选须说明原因
├─ 协商数量：不超过双方已复核磅单可支持的数量，填写原因
└─ 计算预览 → 结算草稿（上传签章确认单）→ 复核确认；来源变化时原单待复核

销售运单
├─ 我方发货采信磅单 → 销售出库过账，只扣一次库存
├─ 客户收货采信磅单 + 客户签收
├─ 最终检测报告 + 来源与差异说明 → 销售交付完成确认（不再次扣库存）
└─ 销售结算单：按客户收货磅单/报告默认试算，可分别改选我方发货磅单/报告；确认形成应收
```

新报告的“发货侧/收货侧”独立于检测机构类型。任务内报告从关联磅单取环节；独立报告录入时人工选。历史报告默认“未标明”，可核对原始附件后一次性补录，补录人、时间和原因留在业务操作记录及备注。结算另选报告时，若新报告触发合同扣款或拒收，现阶段先阻止直接确认，待独立的商务接收/风控审批流程建成后再开放。

仍需后续讨论的闭环包括：合同文本约定的结构化偏离判断、销售质量扣价/争议处置、完整的业务库存—结算—发票三方匹配与会计入账。当前协商数量、改用另一侧依据或额外加减项已进入结算审批，但并不等于已完成会计记账或税务申报。

## 十三、当前版本使用方法与边界

1. 物流运单进入“磅单管理”后，发货侧与收货侧分别登记、复核磅单。只有一张有效磅单时自动采信；同侧新增第二张后，若原选择是自动生成的，须在该侧人工确认一张“采信发货磅单”或“采信收货磅单”。人工改选须写原因；系统保留前次选择记录。
2. 采购入库只引用我方采信收货磅单，销售出库只引用我方采信发货磅单。已入库/出库过账不能直接更换库存依据；供应商或客户磅单只用于相应侧的事实记录和货款候选。
3. 客户签收后，在销售运单确认交付，核对客户收货采信磅单与最终客户收货检测报告。若未形成正式结算，客户复磅可以说明原因重新采信，销售交付数量和磅差快照相应更新；正式结算后不能直接覆盖。
4. 在“应收款计划 → 新建应收结算”编制销售逐车结算；“采购结算单”编制采购逐车结算。先选合同，再按执行批次查看车辆；系统默认勾选全部可结算车辆，允许按批次或逐车取消。发货侧、收货侧各有采信磅单，结算页可逐车选用，也可对当前筛选范围批量切换计量侧；同侧多张未采信时须先确认采信磅单。货款磅单只作为本张结算单的依据，不再即时写回运单，也不会改变已过账库存。改用发货侧或其他报告、填写协商数量及人工加减项均须说明原因。系统自动试算并在页面底部汇总车数、数量、金额；保存草稿后可从详情进入“编辑草稿”继续调整。协商数量或其他人工加减项确认前须上传双方签章的结算确认单。
5. 结算单选择协商数量、其他加减项、另一侧磅单或其他报告后，在详情点击“确认或提交审批”，系统按“系统管理→审批流程→采购销售结算”的四级角色链生成独立任务；小程序工作台的审批中心也显示结算审批。最后一个节点通过才形成正式应收/应付。审批期间来源磅单或检测报告变化会阻止继续审批，须复核原单。驳回单可作废后重新编制，不会自动重算或覆盖已确认单据。
6. 正式结算单详情可登记进项或销项发票，录入发票号码、日期、品名规格、数量、税率、税额与含税金额。系统只汇总有效发票，对照结算数量及金额提示未到票或差异；作废发票保留人、时间和原因。首版不生成会计凭证和税务申报数据。
7. 首期暂不自动作价的情况：销售检测报告不合格、质量扣价尚未确认、双方磅单范围外的协商数量。合同纯文本偏离无法可靠自动识别，结算经办人仍须逐单核对并说明。保存草稿不等于风控审批、开票或财务入账。
