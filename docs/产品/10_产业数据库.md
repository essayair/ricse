# 产业数据库

## 一 产品定位

产业数据库用于维护萤石和氟化工产业的静态基础资料，为产业研究、市场拓展和区域分布分析提供统一数据。它与运营管理后台中的合作伙伴主数据完全独立，不参与合同、物流、库存、应收应付和财务结算。

当前阶段以人工新增、编辑和维护为主。项目资料中的原始文件只作为字段、初始化数据和导入测试参考，不决定产品模块和数据模型。

## 二 导航位置

“产业数据库”是独立一级菜单，位于“内容运营”下方、“用户管理”上方。进入后完整名称为“产业数据库”。

二级功能包括：

1. 产业概览；
2. 萤石生产企业；
3. 氟化工生产企业；
4. 矿山与资源；
5. 产能与项目；
6. 产业园区。

## 三 功能范围

### 3.1 萤石生产企业

独立记录从事萤石开采、选矿和精粉生产的产业企业。企业的产业身份不等同于我方采购供应商，也不会自动同步到合作伙伴。

核心字段包括企业名称、简称、省市、地址、主要产品、设计产能、有效产能、产能单位、状态、数据年份、数据来源、简介和备注。

### 3.2 氟化工生产企业

记录无水氟化氢、氟化盐、制冷剂、含氟聚合物及其他氟化工生产企业。产品类别和主要产品支持多个标签。

### 3.3 矿山与资源

记录具体矿山、矿区、资源项目和待核实的资源分布点，包括运营企业、矿种、省、市、区县、详细地址、资源储量、平均品位、采选能力、经纬度及项目状态。行政区划用于检索和统计，经纬度用于地图定位，两者应同时保留。矿山与企业是不同的数据对象；仅有地区与坐标的资料应标记为“资源分布点”和“待核实”，不得直接视为已确认矿山或产能。原始地区名称与坐标反查结果不一致时，保留原始名称并在备注中标记人工复核。行政区划反查结果应记录所用数据源，本批点位使用 OpenStreetMap Nominatim 核验。

### 3.4 产能与项目

记录企业的生产基地、生产装置、产品和产能项目。一家企业可以维护多个基地、产品和年度口径，区分设计产能、有效产能与规划产能。

### 3.5 产业园区

记录氟化工产业园区的省市、地址、园区级别、重点产业方向和经纬度。坐标用于后续地图展示，录入前应先核实。

### 3.6 产业概览

汇总五类资料数量，并根据已维护的萤石生产企业生成省份分布。当前为静态统计，不包含行情、价格或预测。

## 四 操作规则

- 具有 `industry.database.view` 权限的账号可以查看产业资料；
- 具有 `industry.database.manage` 权限的账号可以新增、编辑和删除；
- 系统管理员和内容运营角色默认获得产业数据库权限；
- 无法确认的字段允许留空，状态选择“待核实”，并注明来源和备注；
- 企业名称、产能和坐标等数据发生冲突时，不得直接覆盖，应核实统计年份及口径后更新；
- 删除用于处理错误或重复资料，停产、停用企业原则上修改状态，不直接删除。

## 五 当前不包含

- 行情与价格数据库；
- 政策法规库；
- 行业标准库；
- 自动网络采集和自动更新；
- 与合作伙伴自动关联或同步；
- 工商、股权穿透及实时开工率；
- 对外企业自助维护。

上述功能根据数据积累和实际运营需求后续迭代。
