# 矿产供应链运营管理系统
## 03 物流运营 · 物流管理

---

## 角色定位

物流运营是**货物从供应商到仓库、从仓库到客户的组织执行方**，负责叫车调度、运输任务全程跟踪、入库与出库确认，以及与承运商的磅单核对、亏吨核算与运费结算。运营平台方是物流的组织方，承运商是被调度和履约的一方。

> **典型岗位**：物流对接、物流台账核对、采购对接（如蔡宇豪、李纯福）

> **系统角色**：`LOGISTICS_OPERATOR`（物流运营）。默认具有物流管理权限，以及合同、执行、质检、库存和主数据的必要查看权限；实际可见数据由该用户角色授权的数据范围决定。

### 一、物流运单管理

#### 1.1 创建运单

| 创建方式 | 说明 |
|---------|------|
| 由供应商发货指令发起 | 采购入库场景，关联采购执行批次和供应商发货指令 |
| 由销售发货通知单发起 | 销售发货场景，关联销售执行批次和销售发货通知单 |

#### 1.2 物流运单字段

**承运商信息**

| 字段名称 | 类型 | 说明 |
|---------|------|------|
| 承运商 | 下拉选择 | 从主数据选取，含资质和合同信息 |
| 车牌号 | 文本 | 执行本次运输的车辆 |
| 司机 | 文本 | 司机姓名 |
| 联系电话 | 文本 | 司机手机号 |

**运费信息**

| 字段名称 | 类型 | 说明 |
|---------|------|------|
| 运费承担方 | 单选 | 我方承担 / 供应商承担；选供应商承担时吨单价与总运费自动置灰 |
| 吨单价 | 数字（保留2位） | 元/吨，仅"我方承担"时可填 |
| 结算依据 | 下拉选择 | 按最小值（默认）/ 按我方磅单 / 按发货磅单 / 按协议固定值 |
| 协议固定值 | 数字（吨） | 仅选"按协议固定值"时显示 |
| 总运费 | 只读自动计算 | = 吨单价 × 结算重量；选"协议固定值"时可即时计算，其余在关联磅单后计算 |

**运输基础信息**

| 字段分组 | 字段名称 | 说明 |
|---------|---------|------|
| 提货信息 | 提货地点/时间 | 货物提取的地点与计划时间 |
| 提货信息 | 供应商发货指令/销售发货通知单号 | 关联的业务单据编号 |
| 送达信息 | 送达地点/预计到达时间 | 货物送达目的地与预计时间 |
| 运输信息 | 运输方式 | 汽运/铁运/船运等 |
| 运输信息 | 运输状态 | 待发运 / 在途 / 已到达 / 已签收 |
| 商品信息 | 物料/数量 | 运输的货物明细 |

#### 1.3 物流查询

对接第三方物流平台，查询货物在途实时状态。在第三方物流系统中获取当前位置、预计到达时间、在途异常信息。

### 二、运单称重与有效磅单
**优先级：P0**

运单详情按“发货称重、收货称重”展示一车两端的完整磅单。采购对应供应商发货和我方收货，销售对应我方出库和客户收货。两个节点均可在原凭证之外追加完整磅单，追加原因强制留痕。

#### 2.1 节点与业务含义

| 节点 | 采购业务 | 销售业务 |
|------|------|--------|
| 发货称重 | 供应商发货磅单 | 我方出库磅单 |
| 收货称重 | 我方收货磅单 | 客户收货磅单 |

#### 2.2 操作流程

```
运单详情 → 选择发货/收货节点 → 创建或追加完整磅单 → 完成称重并复核 → 分别选作入出库/结算依据
```

- 同一节点允许多张完整磅单，第二张及以后必须填写追加原因
- 一张完整磅单内部仍支持多次毛重/皮重复磅，两类“追加”不得混淆
- 入出库与结算可以选用不同磅单；更换已选用磅单必须填写原因
- 已完成库存入账后不允许更换入出库有效磅单

### 三、结算重量逻辑

结算中心优先读取运单当前 `SETTLEMENT` 有效磅单。下表为后续运费结算策略配置，不能替代有效磅单的选用审计：

| 结算依据 | 计算规则 | 备注 |
|---------|---------|------|
| 按最小值（默认） | min(我方入库重量, 供应商发货重量) | 两方均有磅单时取较小值；只有一方时取该方数值 |
| 按我方磅单 | 取我方入库磅单净重 | 需已关联我方磅单 |
| 按发货磅单 | 取供应商发货磅单净重 | 需已关联供应商磅单 |
| 按协议固定值 | 取填写的协议固定吨数 | 无需磅单即可计算 |

> **总运费** = 吨单价 × 结算重量（运费承担方为"我方承担"时计算，供应商承担时不计）

### 四、磅单对比与亏吨核算
**优先级：P1**

运单详情中展示三方重量对比与亏吨信息：

| 展示项 | 计算说明 |
|--------|---------|
| 我方入库磅单(吨) | 直接取关联磅单净重 |
| 供应商发货磅单(吨) | 直接取关联磅单净重 |
| 客户收货磅单(吨) | 直接取关联磅单净重 |
| 结算重量(吨) | 根据结算依据计算（见上节） |
| 亏吨数(吨) | max(我方, 供应商) − 结算重量；＞0 时以红色醒目展示 |
| 亏吨扣款额(元) | 亏吨数 × 吨单价；运费供应商承担时不计 |

### 五、运单结算校验

点击「提交结算」时，系统执行以下校验：

| 校验项 | 类型 | 处理方式 |
|--------|------|---------|
| 已关联我方入库磅单 | **强制** | 缺失则阻止结算，提示错误 |
| 已关联供应商发货磅单 | 警告 | 弹窗提醒，可选择继续 |
| 已关联客户收货磅单 | 警告 | 弹窗提醒，可选择继续 |
| 结算重量可计算 | **强制** | 根据结算依据无法得出有效数值时阻止结算 |

结算通过后，运单状态变更为「已结算」，生成结算单供财务处理。

### 六、物流入库单（采购到货确认）

#### 6.1 功能说明

采购物流运单确认发运、进入在途时即自动生成“待到货”入库作业单；运单到达时幂等补生成。该单同步跟踪到达、签收、过磅、质检、收货和入账，由仓管在最终质检合格后完成现场收货确认并触发库存形成流程。

**数据来源**：供应商发货指令 + 物流运单 + 地磅过磅数据

#### 6.2 操作流程

```
采购物流运单确认发运 → 系统自动生成待到货入库作业单
→ 到达/签收 → 磅单复核 → 质检确认合格并补齐最终验收依据
→ 仓管补齐实际收货信息 → 确认收货 → 库存入账
```

#### 6.3 关联关系

```
物流入库单 → 业务入库单（库存形成）→ 采购合同（履约跟踪）
```

> **注意**：物流运营无需手工创建入库单。采购运单确认发运时自动生成待到货入库作业单；合格质检只负责补齐最终验收依据，仓管确认收货后再生成业务入库和库存。

**场景三：退货处理**


### 九、物流对账
**优先级：P1**

#### 9.1 页面结构

| 展示字段 | 说明 |
|---------|------|
| 承运商 | 承运方名称 |
| 当期车次 | 本期运输车次数 |
| 合计吨数 | 本期运输总量（吨） |
| 总里程(km) | 本期总里程 |
| 应付运费 | 按吨单价×结算重量合计 |

| 实付金额 | 应付运费 − 亏吨扣款 |

支持「发起对账」（跳转到运单明细并筛选该承运商）和「查看结算单」操作。

**Tab 二：运单明细**

以单条运单为粒度展示对账明细，支持按承运商、结算状态、运费承担方、时间段筛选：

| 展示字段 | 说明 |

| 承运商 / 司机 | 本次承运信息 |
| 吨单价 | 元/吨 |
| 结算依据 | 按最小值/我方磅单/发货磅单/协议固定值 |
| 我方磅单(吨) | 我方入库过磅净重 |
| 发货磅单(吨) | 供应商发货过磅净重 |
| 结算重量(吨) | 根据结算依据计算 |

## 完整操作流程

**采购入库运输标准流程**：

```
① 接收采销系统的供应商发货指令
② 创建物流运单（关联供应商发货指令；填写承运商、运费承担方、吨单价、结算依据）
③ 叫车派车（选择承运商/车辆/司机）
④ 在途跟踪（监控轨迹；异常预警）
⑤ 车辆到厂（电子围栏触发预警通知现场）
⑥ 地磅过磅（现场一线操作，数据回流物流运单）
⑦ 在运单详情中关联磅单（我方入库磅单为必须项；可补充供应商发货磅单）
⑧ 核查结算重量与亏吨信息
⑨ 提交结算（通过校验后状态变更为「已结算」）
⑩ 在物流对账页批量生成结算单 → 通知财务审核付款
⑪ 运单确认发运时已自动生成入库作业单；质检合格后补齐验收依据 → 仓管确认收货并生成业务入库（库存正式形成）
```

**销售出库运输标准流程**：

```
① 销售发货通知下达后，系统自动生成出库管理单并冻结待出库库存
② 创建物流出库运单（关联销售发货通知单；系统自动归入出库管理单并生成车次作业）
③ 叫车派车
④ 仓储库管备货/拣货
⑤ 过磅出库（地磅数据确认出库数量）
⑥ 磅单通过物流运单自动归入出库管理单；复核前允许调整关联运单
⑦ 按已复核磅单实际重量选择库存批次，必要时处理溢装/短装差异
⑧ 确认车辆放行，系统同步生成销售出库单、扣减库存并将物流运单置为在途
⑨ 出库管理单持续汇总多车实际出库和剩余任务
⑩ 提交结算 → 物流对账归集运费
⑪ 客户签收 → 回单归档
```

## 下游任务流：你的操作触发

| 下游角色 | 触发事项 | 说明 |
|---------|---------|------|
| 现场一线（地磅） | 车辆进厂 | 电子围栏推送预警，现场准备过磅 |
| 仓储库管 | 采购运单确认发运并自动生成入库作业单 | 提前展示待到货任务；合格质检补齐验收依据后通知库管确认收货并入账 |
| 仓储库管 | 物流出库单确认 | 库存扣减，出库完成 |
| 财务结算 | 运费结算单 | 运费数据归集到成本核价；亏吨扣款体现在实付金额中 |

## 权限与企业数据范围

- 物流查看与物流管理权限分别控制浏览和创建、调度、状态流转、附件增删。
- 运单通过执行通知和执行批次继承合同参与企业范围；列表、调度看板、详情和附件保持一致。
- 外部企业员工可查看本企业参与交易形成的全部关联运单，不按调度人、司机或创建人拆分。
- 当前承运商主数据身份不自动获得合同穿透权限；未来开放承运商门户时需增加参与方映射和价格字段隔离。

统一口径见[权限与数据范围规范](./权限与数据范围规范.md)。
