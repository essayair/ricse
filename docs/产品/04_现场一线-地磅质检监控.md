# 矿产供应链运营管理系统
## 04 现场一线 · 地磅管理 / 质检化验 / 监控录像

---

## 角色定位

> **系统角色**：`QUALITY_OPERATOR`（地磅质检）。默认可以管理磅单、质检单和相关影像，并查看其上游合同、执行批次、物流运单及下游库存信息。

现场一线岗位是**货物进入仓库前的质量与数量关卡**，也是整个业务链中数据可信性的核心保障。过磅数据是结算数量的原始依据，质检数据是验收与扣款的法定依据，监控影像是防作弊与争议追溯的证明链。

本角色覆盖三个紧密协作的子模块，通常由玉门现场团队协同完成：
- **过磅/检斤岗**：地磅管理（郑学）
- **取样/检测岗**：质检化验（郑小明、徐主任）
- **现场留存**：监控录像（配合地磅和质检操作）

> **典型岗位**：过磅员、取样员、化验员、现场负责人（如郑学、郑小明、徐主任、陈飞祥）

## 核心功能模块

---

### 第一部分：地磅管理

#### 模块定位
采集进出场过磅数据，作为**数量结算的源头依据**。通过设备防作弊与影像关联，保证"磅不可造假"与采购/入库偏差可追溯。

一期方案：电脑Web端将本地磅单数据上传到线上系统（共用地磅设备，不共用本地数据，由现场操作上传）。

#### 功能清单

| 功能 | 说明 |
|------|------|
| 过磅数据采集 | 车辆进出场自动称重；基础为毛重、皮重各一次，允许多次复磅并完整保留历史记录；重量统一精确到 0.001 吨，重量框不响应鼠标滚轮增减 |
| 磅单管理 | 磅单生成、存储、查询与关联；从多次记录中分别指定有效毛重、有效皮重并自动计算净重 |
| 完整凭证信息 | 保存磅单日期、编号、车辆司机、货物规格、发收货单位、包/袋数、有效称重时间、打印时间、司磅员和备注 |
| 结算重量口径 | 默认按本次毛重与皮重计算的称重净重结算，可切换为发货重量、客户收货重量、第三方重量或手工确认重量 |
| 双磅单采集 | 同时采集供方磅单（供应商/矿山端）与我方现场磅单，用于对账核实 |
| 多完整磅单 | 同一运单的发货、收货节点均允许追加完整磅单，追加必须填写原因，原凭证不覆盖 |
| 结算入库磅单选用 | 从同一运单的已复核完整磅单中统一选择一张，净重同时用于库存执行与结算；更换时留存原因、操作人和时间 |
| 偏差预警 | 出厂重量 vs 到厂重量比对；偏差超阈值自动锁单并推送异常 |
| 防作弊机制 | 设备离线/人工录入打"非可信数据源"标签；阻断自动流转，转人工复核 |
| 影像关联 | 过磅时自动抓拍车头/车厢/空厢影像，与磅单自动关联 |
| 异常处理 | 磅差超限、设备离线、人工录入等异常场景的标记与处理流程 |

#### 关键操作步骤

```
① 车辆入厂 → 检查车厢（有无加水/夹带）
② 车辆过磅（毛重）→ 系统自动取重 + 抓拍车头/车厢影像
③ 卸货
④ 卸货后检查残留，拍照留存
⑤ 车辆出场过磅（皮重）→ 计算净重
⑥ 磅单生成 → 水印照片/磅单数据实时推送工作群
⑦ 回磅复检（必要时）→ 数据异常时发起复核
```

#### 多次称重与有效记录规则

以下规则描述的是“一张完整磅单内部”的毛重/皮重复磅，不等同于追加另一张完整磅单。

- 每张磅单至少需要一条毛重和一条皮重记录，基础作业即两次称重。
- 新增称重时默认提供两条基础录入行：采购入场先毛重后皮重，销售出场先皮重后毛重；首次称重默认取系统当前时间，后续称重默认在上一时间基础上随机增加 30–40 分钟并精确到秒，所有时间均可手动调整；允许先保存当前已完成的一次称重。
- 同一磅单可以追加任意多条毛重或皮重复磅记录，新增记录不覆盖、不删除历史记录。
- 系统分别指定一条有效毛重记录和一条有效皮重记录；新增同类型记录时默认选为最新有效记录，操作人员可以重新选择。
- 收货净重按 `|有效毛重 - 有效皮重|` 自动计算。毛重、皮重不完整时不能完成称重。
- 完成称重后不能再追加或更换有效称重记录，须在完成前处理复磅结果。

#### 同一运单的多张完整磅单

- 每辆车按“发货称重、收货称重”两个节点归档。采购通常对应“供应商发货磅单 + 我方收货磅单”，销售通常对应“我方出库磅单 + 客户收货磅单”。
- 每个节点可有多张有效完整磅单；第二张及以后必须填写追加原因，例如客户复磅、凭证更正或第三方复核。
- 一张物流运单在管理列表中只形成一条“磅单信息”，打开详情后按发货、收货两个节点展示其下全部完整称重磅单。
- 用户只选择一张已复核的“结算入库磅单”，其净重同时作为库存执行与结算依据，不允许两个下游分别选不同磅单。更换必须填写变更原因，历史选用记录不删除。
- 采购和销售均默认首次采用已复核的发货称重磅单；收货或追加磅单完成后可按合同约定、对账或争议处理结果人工改选。

#### 结算重量口径

| 口径 | 取值规则 |
|------|---------|
| 收货称重 | 默认口径，取本磅单按有效毛重和皮重计算的收货净重 |
| 发货重量 | 取发货环节确认的重量，需人工填写 |
| 客户收货重量 | 取客户确认的收货重量，需人工填写 |
| 第三方重量 | 取第三方计量机构确认的重量，需人工填写 |
| 手工确认重量 | 争议处理或特殊场景下的最终确认重量，需人工填写并保留审核依据 |

无论采用何种结算口径，系统均保留收货净重和磅差数据。所选口径缺少对应重量时，磅单不能完成。

#### 防作弊关键规则

| 场景 | 处理方式 |
|------|---------|
| 设备正常自动取重 | 磅单标记为"可信数据源"，可自动流转到入库流程 |
| 设备离线/人工录入 | 磅单打"**非可信数据源**"标签，**阻断自动流转**，需人工复核确认后才可继续 |
| 进出场重量偏差超阈值 | 系统自动**锁单**并推送异常给现场负责人，等待人工处理 |
| 人工录入的备降磅单 | 需上级确认标注原因，留存审计记录 |

#### 磅单关联链

```
磅单 → 关联物流运单 → 关联供应商发货指令/销售发货通知单 → 关联采购/销售合同
     ↓
   关联质检单（同一车次）
     ↓
   关联监控影像（过磅时刻抓拍）
```

### 第二部分：质检化验

#### 模块定位
管理入厂货物的取样、化验、报告与质检规范，提供**质量数据作为验收与结算依据**。核心是确定性：过程的确定性、结果的确定性、异常处理的确定性。

质检数据可能来自**我方检测机构、合作方检测机构、第三方检测机构或其他机构**。物流运单确认到达后，系统自动生成一条**到货质检任务**，管理列表一行对应一辆车的一次到货质检；任务详情内归集一份或多份独立的机构检测报告，并形成唯一的任务级最终质检结论。

#### 功能清单

| 功能 | 说明 | 优先级 |
|------|------|--------|
| 取样管理 | 卸货后规范取样并登记，记录精确到秒的取样时间、取样人、取样方法；默认计划3份，实际允许1份或更多 | P0 |
| 附件上传 | 取样照片、化验单/质检报告照片上传；系统自动OCR识别结构化数据 | P0 |
| 到货质检任务 | 物流到货后自动生成，统一由拥有质检管理权限的人员处理和跟踪 | P0 |
| 化验数据录入 | 化验指标结果录入系统（一期手工录入，可对接设备直采） | P0 |
| 质检报告 | 出具质检报告，支持多行检测指标；按规范自动判定合格/不合格/熔断 | P0 |
| 质检规范管理 | 维护质检指标模板和判定标准；按物料配置指标项和阈值（系统管理员操作） | P2 |
| 指标争议处理 | 处理质检结果争议（熔断场景下人工介入） | P2 |
| 质量预警 | 基于化验数据推送质量趋势预警（二期模型能力） | P2 |

质检业务中的取样时间、送检时间、化验时间和报告时间均采用 `年-月-日 时:分:秒` 口径。录入时先选择日期，再依次选择小时、分钟和秒；纯日期字段选中后自动收起，日期时间字段在时间选择完成前不得提前关闭。

到货质检任务列表支持按任务编号、检测机构、报告编号、物料、车牌、物流运单及执行批次名称/编号进行关键词检索，并可组合任务状态、最终结论和任务日期范围筛选。每辆到货车辆对应一行，直接展示报告进度、磅单进度、当前处理人和最终结论；具体机构报告在任务详情中展开。

#### 多机构化验数据管理

| 检测机构类型 | 数据录入方式 | 说明 |
|--------|------------|------|
| **我方检测机构** | 化验室手动录入系统 | 在到货质检任务内追加一份机构检测报告 |
| **合作方检测机构** | 手动录入或上传扫描件 | 每份报告作为任务下独立子记录 |
| **第三方检测机构** | 手动录入或协商让第三方自行上传 | 每份报告作为任务下独立子记录和争议依据 |
| **其他检测机构** | 手动录入 | 记录其他合法检测来源 |

多机构报告通过同一到货质检任务归组，原始检测值互不覆盖。实际报告至少一份，默认计划三份且允许继续追加。有效报告少于计划数量时必须填写提前判定原因并二次确认；任务最终结论确认后才驱动入库和结算。

#### 关键操作步骤

```
① 物流运单确认到达 → 系统幂等生成到货质检任务（待取样）
② 磅单完成称重或复核 → 质检管理人员进入任务追加机构检测报告
③ 规范取样并填写样品编号；默认计划3份，实际允许1份或更多
④ 分别录入各检测机构报告、指标和附件并确认报告有效
⑤ 至少一份有效报告后选择执行口径报告，二次确认最终质检结论
⑥ 合格结论补齐入库作业和结算质量依据；超标扣款或熔断进入异常处理
```

#### 质检结论处理

| 质检结论 | 后续动作 |
|---------|---------|
| **合格** | 触发业务入库，货物进入库存，可正常结算 |
| **不合格（折价）** | 通知采销业务员与供应商协商折价，双方确认后按折价结算 |
| **熔断（拒收）** | 通知采销业务员与客户协商退货，冻结该批次不可入库 |

#### 质检结果对结算的影响

- **扣水**：实测水分超过合同约定水分基准，按合同扣水公式计算扣重数量
- **扣杂**：实测杂质超标，按合同扣杂公式计算扣重数量
- **结算数量** = 磅单所选结算重量 - 扣水数量 - 扣杂数量（默认结算重量为收货称重净重）
- 扣重数量作"结算利息"单独处理（财务结算模块）

> **重要**：化验合格才结算开票，质检结果与结算、发货节点强联动。

### 第三部分：监控录像

#### 模块定位
对过磅、卸货、仓库等关键环节进行**视频监控与存证**，与磅单/单据关联，提供防作弊与争议追溯能力。

一期：视频影像本地硬盘存储，关键影像与磅单关联。切片上云、上链放在二期。

#### 功能清单

| 功能 | 说明 |
|------|------|
| 过磅抓拍 | 过磅时自动抓拍车头/车厢/空厢影像，与磅单自动关联；多角度抓拍 |
| 卸货监控 | 卸货过程录像与关键帧抓拍；卸货后抓拍"空厢"，防夹带/未卸净 |
| 仓库监控 | 仓库关键摄像头画面，堆场变动存留 |
| 影像关联 | 影像+磅单+单据打包，作为收货确认与争议追溯证据 |
| 影像存储 | 关键影像数据上云（一期本地存储）；设置保存期限；支持按单据/日期检索 |
| 查看权限 | 按权限控制影像查看，不同角色对不同业务线影像有不同权限 |
| 实时监控 | 关键点位实时视频流查看；对接摄像头/NVR设备 |

#### 关键操作触发链

```
① 车辆过磅 → 自动触发抓拍 → 影像自动关联磅单
② 卸货 → 录制卸货过程 → 卸货后抓拍空厢（防夹带/未卸净）
③ 影像+磅单+质检报告打包归档 → 作为收货确认与争议追溯证据
```

## 三模块协同操作全流程

```
车辆预计到达 → 现场准备
      ↓
车辆入厂检查（查车厢、有无加水）
      ↓
【地磅】进场过磅（毛重）→ 抓拍车头/车厢 → 【监控】记录影像
      ↓
卸货（卸货过程录制）→ 【监控】拍摄空厢
      ↓
【质检】规范取样 → 化验（测水分/品位等）→ 数据录入
      ↓
【地磅】出场过磅（皮重）→ 计算净重 → 磅单生成
      ↓
磅单+化验数据+影像 实时推送工作群（每日18:00前完成数据汇总）
      ↓
现场负责人核对数据 → 确认无误 → 通知采销发起结算
      ↓
【质检合格】→ 通知仓储库管生成业务入库单
```

## 下游任务流：你的操作触发

| 下游角色 | 触发事项 | 说明 |
|---------|---------|------|
| 仓储库管 | 采购质检确认合格后 | 补齐在运单发运时已生成的入库作业单最终验收依据，通知库管补齐收货信息并确认入库 |
| 采销业务员 | 质检结果出具后 | 扣水扣杂结果影响结算单计算 |
| 财务结算 | 磅单净重确认 | 磅单净重是结算数量的唯一源头依据 |
| 物流运营 | 磅差超阈值 | 触发物流运单异常，需物流运营跟进处理 |

## 模块关联关系

| 关联模块 | 关系说明 |
|---------|---------|
| 物流管理 | 关联运单/车辆（地磅）；到货/卸货影像关联车次（监控） |

| 采销系统 | 质检结果影响验收与结算；通过供应商发货指令或销售发货通知单逐级关联执行批次与合同 |
| 财务结算 | 磅单净重和质检扣重结果共同决定结算数量 |
| 主数据管理 | 物料、质检规范取自主数据 |

## 异常处理说明

| 异常场景 | 处理方式 |
|---------|---------|
| 磅差超阈值（进出场重量差异过大） | 系统自动锁单，推送异常给现场负责人，等待人工核实和定责 |
| 地磅设备离线 | 人工录入磅单，标记"非可信数据源"，阻断自动流转，转人工复核 |
| 同车不同机构质检结论不一致 | 分别保留各机构独立质检单和附件，立即报告现场负责人，使用留样复检并协商处理 |
| 质检结论为熔断 | 冻结批次，通知采销协商折价或退货，人工介入处理 |
| 视频设备故障 | 记录设备故障时段，磅单/质检单标注影像缺失，留存书面记录 |

## 权限与企业数据范围

- 磅单、质检单和影像附件通过物流运单逐级继承合同参与企业范围。
- 外部企业员工可查看本企业关联车辆形成的完整称重、质检和证据数据，不限现场操作人或报告录入人。
- 查看与管理权限分开：可见数据不代表可以录入称重、复核磅单、确认质检结论或增删附件。
- 列表、详情、可选上游单据、同车其他质检报告和附件查看地址均执行相同范围校验。

统一口径见[权限与数据范围规范](./权限与数据范围规范.md)。
