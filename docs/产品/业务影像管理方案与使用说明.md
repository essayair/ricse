# 业务影像管理方案与使用说明

> 更新：2026-11-18。状态：首版本地开发及验证完成，纳入本次功能集成提交；线上生效以云效部署结果为准。菜单占位已升级为实际资料库。

## 一、定位与入口

一级菜单“影像监控”下依次为“业务影像”“视频监控”。视频监控沿用原点位、平台配置和实时预览，不改变原功能。

业务影像集中归集合同、磅单、检测报告、车辆照片、现场照片、签收交接凭证、出入库凭证、结算凭证及其他资料。它是**文件资料库**，不替代运单、磅单、检测报告等业务单据，也不会因上传图片自动完成过磅、质检、签收或结算。

- 资料库：`/dashboard/business-images`。
- 归档页面：`/dashboard/business-images/new`。
- 面包屑：首页 / 影像监控 / 业务影像 / 归档资料。

## 二、先归档，再按需关联

| 项目 | 首版规则 |
| --- | --- |
| 归档合同 | 必选；支持按合同编号、标题搜索 |
| 执行通知 | 可选；只能选择该合同下可见的通知 |
| 影像类型 | 添加文件前必须在顶部选择，整批统一；每行只显示类型，不支持逐文件修改。归档前可在顶部整体修正 |
| 具体业务单据 | 上传时不必选择；归档后再关联，也允许一直不关联 |
| 仅归档 | 已归入合同资料，但未挂到具体业务单据，不是待办或异常 |
| 已关联 | 已作为具体单据的附件，或本来就从原单据上传 |

因此，业务影像的资料范围可以大于原业务单据附件：它包含仅归档资料，也集中呈现有权查看的原单据附件。

## 三、上传操作

1. 进入“业务影像”，点击“归档资料”，选择合同，按需选择执行通知。
2. 先选择本批影像类型，再添加多个 JPG、PNG、WEBP 或 PDF 文件。支持文件选择、拖入以及剪贴板粘贴；未选择类型时添加/粘贴按钮禁用，拖入或直接粘贴也会提示并拒绝添加。剪贴板按钮需要浏览器支持并授权。
3. 一个文件一行：直接显示大幅缩略图和本批类型，名称默认带入原文件名，可修改名称、填写逐文件备注（选填，最多1000字，支持多行），不再提供逐文件类型选择。
4. 逐份核对文件，勾选“名称已核对”。归档前在顶部修改影像类型会同步所有待归档文件，并清除核对状态，须重新确认；更改文件名也须重新核对。
5. 点击“确认归档”。成功项保留在页面中，不立即关闭；可以继续上传，失败项可单独重试。
6. 归档部分文件后，合同与通知锁定，避免同一批文件误归入其他合同。需要归档其他合同的资料时返回资料库重新进入。

本批有任一资料归档成功后，影像类型也锁定，避免成功文件与后续上传类型不一致。全部完成（或移除未完成文件）后可点“开始新一批”，清空上传列表与类型重新选择，已归档文件继续保留；仍可沿用当前合同和通知。重复内容按原规则去重，不修改既有资料的类型；若既有类型不同，会明确显示其已保存类型。

重复提交同一请求不会再次保存；同一合同中已归档的相同文件内容会提示已存在，不重复归档。此去重不追溯合并历史原单据附件，也不自动判断内容相似但字节不同的照片。

归档文件名在同一合同内唯一，包含仅归档与已关联的归档资料，不按类型或执行通知另行放宽；忽略首尾空格和大小写，包含扩展名。页面检查本批次重名，服务器检查已归档资料，数据库防止并发重名，改名也执行相同校验。不同合同允许同名；存量原单据附件不批量改名或补造归档元数据。不同文件重名需修改名称，相同文件的成功重试仍按幂等处理。

未完成归档时，关闭或刷新页面会提示；点击侧栏或面包屑离开时也会确认。未上传文件不保存到服务器，离开前应完成归档。

## 四、查询与查看

- 可按文件名称、合同、执行通知、影像类型、仅归档/已关联、上传日期筛选。
- 每行展示缩略图、名称、备注摘要、归档合同/通知、关联状态、原单据入口、上传人、上传时间和文件大小。
- 列表显示当前筛选的总份数及总大小，每页 30 份。
- 图片直接显示缩略图，PDF 显示首页缩略图；点击缩略图可在当前页面查看完整原件，不另开标签页。
- 点击资料名称或“查看”进入资料信息，展示完整备注和缩略图，并可继续查看原件；未填写时显示“未填写备注”。历史原单据附件不补造备注。
- 未关联归档资料可在“编辑”中补充、修改或清空备注。关联到原单据后，备注仍保留并可查看；修改门禁沿用原规则。
- 备注属于逐文件归档信息，不改变原单据、文件内容或名称唯一性。同合同相同文件重试或重复上传不覆盖已保存的备注，页面显示实际保留的备注。
- 预览生成失败不影响文件归档，仍保留原件查看入口。
- 旧附件未记录上传人的，显示历史资料信息，不补造操作人员。

## 五、与原单据互通

归档资料可关联：合同、物流运单、磅单、检测报告、入库单、出库单、采购/销售结算单、付款申请单、收付款单。

1. 在资料行点击“关联单据”，选择类型及同合同下的目标单据。
2. 如果归档时指定了执行通知，运单、磅单、检测报告和出入库单必须属于该通知；混样报告可通过有效质检任务关联匹配。合同、汇总结算及资金单只校验合同，因为它们可能覆盖多个通知。
3. 双边合同需要确认采购合同、销售合同或其他附件类别；运单需要选择签收单、现场照片或其他交接凭证类别。
4. 不可操作的目标置灰并说明原因。关联还需要原业务的操作权限，不能凭归档权限修改已审批或已锁定的单据。
5. 关联后原单据直接使用同一条附件、同一个存储文件，不再复制上传；原单据修改附件显示名称时，资料库同步显示。
6. 原业务允许删除附件时，可在资料库“解除关联”，文件继续作为仅归档资料保存。已审批合同、已复核磅单、已确认报告、已过账出入库单等不能借解除关联移走凭证。

仅归档资料可编辑名称、类型、通知和备注，也可删除。已关联资料的修改遵循原单据规则。**若直接通过原单据的删除附件功能删除同一附件，该文件也会从资料库消失；如需保留归档资料，应使用“解除关联”。** 首版不是不可删除的法定档案系统，不包含附件版本替换或恢复站。

原单据集中查询还包括过磅任务、质检任务、样品照片、物流结算及库存更正凭证。它们保留原操作入口，本版不增加集中关联这些额外类型的操作。独立主数据附件、车辆司机资料、未关联贸易合同的物流合同和待认领资金资料暂不纳入合同资料库。

## 六、文件大小、压缩与原件

| 内容 | 处理方式 |
| --- | --- |
| 单文件大小 | 上传前不超过 20 MB，前后端均校验；压缩不能用于绕过原始文件大小限制 |
| 文件类型 | JPG、PNG、WEBP、PDF，并检查文件签名，不只相信扩展名 |
| 合同、磅单、检测报告及 PDF | 不压缩上传原件；预览图是独立派生文件 |
| 普通车辆照片、现场照片 | 用户可选适度压缩，默认开启；小于 512 KB 不处理，长边最多 2560 像素、JPEG 质量 86，只有变小才采用 |
| 压缩失败 | 回退上传原照片，不阻断归档 |
| 存储记录 | 保留来源文件名、实际名称、原始大小、保存大小及是否压缩 |
| PDF 预览 | 仅渲染首页缩略图；完整 PDF 仍从原件查看 |

普通照片采用压缩时，保存的是压缩版本，不另存一份上传前照片。需要保留原照片时取消压缩。现有业务单据上传入口不因此被统一改为压缩，保持原规则。

## 七、权限与留痕

- 新增“查看业务影像”“归档维护业务影像”两项权限；视频监控权限不能替代。
- 数据范围同时受影像权限、合同查看权限、顶层业务单元归属约束；原单据附件另校验所属模块查看权限及数据范围。
- 归档维护权限不等于合同编辑、物流、质检、库存或资金操作权限。关联/解除关联还要检查原权限和单据状态。
- 首版仅内部账号开放资料库，外部企业继续从原业务页面按原权限访问。
- 上传、改名、备注修改、关联、解除、删除记录操作人和时间；关联/解除同时写入原单据记录。普通用户不展示后台审计轨迹，管理员可在资料详情查看。
- 文件私有存储；服务端鉴权后才提供临时签名地址，不开放公开文件列表。

## 八、本版不包含

OCR 自动录单、批量自动关联、跨合同共用一份归档文件、独立手机归档页面、档案借阅/保管期限、文件版本恢复、电子签章、病毒扫描及监管级不可篡改存证均不在本版范围。小程序已有的业务附件继续通过原单据同步集中展示，不改变现场操作流程。
