# 合同适用规格与逐车品位取价

日期：2026-11-20。范围：CaF₂ 品位分档合同、物流运单、采购/销售结算及小程序。

## 业务规则

合同可以同时覆盖“碎屑、统矿”，但一辆车只运输一种规格。本次不支持同车混装两种规格，也不据此创建新物料或拆分库存。

合同价格条款分为两个独立字段：

- **合同适用规格**：多选碎屑、统矿，至少选择一种；不是实际车辆的规格。
- **规格计价方式**：新合同默认统一计价，同一档只填写一套元/度价格；按规格分别计价时，每个适用规格均需逐档填写价格。

品位区间继续默认提供八档，可增删修改；价格不预填。采购、销售价格条款各自维护，不因统一规格计价而合并采销价格。

例：30≤CaF₂<35，统一价22.70元/度，两种规格均用22.70。分别计价时可以碎屑22.70、统矿24.00。同样32.5%品位，对应737.75、780.00元/吨（不含税），再乘本车按合同扣水后的计价数量。原有税率、免扣水分、质量异常及回收率条款不变。

## 操作方法

1. 新建/编辑合同，在“按CaF₂品位分档计价”中勾选适用规格，选择统一或分别计价，逐档填写含税/不含税价格（另一列自动换算）。
2. 同价仅填统一价格；切换到分别计价后可逐规格修改。分别计价改为统一时，若两价不同，系统要求确认按首个适用规格的价格覆盖其他规格，不能静默覆盖。
3. 从Excel粘贴：统一价使用“下限、上限、单价”三列；两规格分别计价使用“下限、上限、碎屑价、统矿价”四列。统一模式拒绝两列不同价格。
4. 执行通知仍可覆盖两种规格，不要求预先分配每车。创建运单时，逐车填写“本车货物规格”，也可稍后在运单详情补充。Web与小程序均提供入口，仅物流管理权限可保存。
5. 一个运单只保存一个规格值，不接受多选或混装。选项根据所选合同明细过滤；双边直拨取采购、销售适用规格的交集。
6. 结算逐车展示本车规格，按本方向合同价格表计算。分别计价且有多个适用规格时，未填本车规格的车辆不能正式计算；页面提示补充并提供运单入口。只有一种适用规格或统一价格时无需猜测不同价格，允许自动取唯一适用价格。

## 补填与更正

- 首次补填可在运输后操作；不改变已过账数量。
- 已填规格改为另一规格或清空，必须填写原因，记录操作人、时间、原值、新值及原因。
- 已有有效货款结算单（含草稿、审批中及已确认，作废除外）时锁定规格。应先作废原结算再更正、重新计算，不静默修改结算快照。
- 直拨有效交付或复核已存在时，已填规格的更正需先撤销交付；未填过且尚未结算时允许首次补填，避免分别计价后无法完成结算。
- 取消运单不允许修改。整车直拨转仓时保留原车实际规格。

## 兼容与边界

历史规则没有新计价方式字段时，继续按原`selectedSpec`单规格取价，不自动扩为两种，也不自动统一不同价格。查看、复制不会擅自改历史规则；编辑适用规格或计价方式后才写入新结构。

新规则沿用JSON快照版本1，新增`applicableSpecs`和`specPricingMode`（UNIFIED/BY_SPEC）；每档仍保留两种规格价格，统一模式服务端强制校验适用规格价格相同。运单新增可空`cargoSpec`，历史运单不猜测回填。结算签名在实际规格非空时纳入规格，防止预览后规格变化仍保存旧价格；旧空值签名不额外增加字段。

本次仅开发及应用本地数据库字段迁移，不修改线上合同、主数据或已执行单据。生产发布时先应用迁移、生成Prisma客户端，再部署后端和Web；小程序需重新编译上传。不能只更新前端。
