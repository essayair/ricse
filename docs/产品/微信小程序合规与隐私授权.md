# 微信小程序合规与隐私授权

## 一、适用范围

本规范适用于“氟萤直上”微信小程序的微信身份登录、手机号授权、企业账号关联以及现场业务功能。

当前协议版本：

- 《用户服务协议》：`2026.09.17`
- 《隐私政策》：`2026.09.17`

## 二、手机号授权流程

1. 用户进入“我的”页面时，可以分别打开并完整查看《用户服务协议》和《隐私政策》。
2. 同意项默认不勾选；用户未主动勾选时，系统不得调用微信 `getPhoneNumber` 能力。
3. 用户勾选后，点击登录入口才会唤起微信手机号授权窗口。
4. 用户拒绝微信手机号授权时，不创建已验证手机号，不保留本次临时登录状态。
5. 授权成功后，RICSE 保存手机号、手机号验证时间、两份协议版本和同意时间。
6. 协议发生实质更新时，应升级版本号；旧版本本地同意状态自动失效，用户需要重新阅读和同意。

## 三、手机号用途

手机号仅用于：

- 微信用户身份校验；
- 匹配或辅助关联企业运营管理后台账号；
- 保障账号安全；
- 提供与用户主动使用功能相关的必要服务联系。

不得默认用于无关营销，不读取用户通讯录，不得绕过微信官方接口获取手机号。

## 四、产品与技术约束

- 前端同意状态只用于控制交互，后端仍必须校验 `accepted=true` 和协议版本。
- 合规留痕保存于 `WechatIdentity.serviceAgreementVersion`、`privacyPolicyVersion` 和 `consentedAt`。
- 《用户服务协议》和《隐私政策》在登录后仍应长期保留可访问入口。
- 微信公众平台后台还需要配置并发布《小程序用户隐私保护指引》，其收集信息类型和用途应与小程序页面保持一致。
- 每次提审前，应使用全新微信用户或清除本地缓存，确认同意项默认未勾选、协议可打开、拒绝授权不会登录、同意后才能获取手机号。
