# 物流运单与调度 — 使用指南

> ✅ Iteration 6 调度执行闭环完成（2026-07-18）

## 功能概述

物流运单是车辆/车次级运输单据，必须关联已下达或执行中的供应商发货指令或销售发货通知单。一个执行通知可以拆分多张物流运单。

## 创建与调度

1. 进入「物流管理 → 运单管理」，点击「新建物流运单」。
2. 如已收到微信、短信或调度文字，可粘贴到“文字信息自动识别”窗口并点击“识别并填入”。系统可识别通知号/批次号/合同号、车牌、司机、电话、承运单位、运输数量、起讫地和计划时间；识别只回填表单，不自动创建。
3. 选择已下达或执行中的执行通知。
4. 填写本车运输数量，累计数量不得超过通知数量。
5. 可在创建时选择车辆，也可以先创建待发运运单，再到运单详情或调度看板分配车辆。
6. 自有运力从车辆主数据选择；第三方承运可以填写承运单位、车牌、司机和电话。
7. 填写计划发运时间和预计到达时间，用于调度计划和超时判断。
8. 确认发运前必须具有车牌和司机信息；第三方承运还必须填写承运单位。

物流运单编号格式为 `WB-年月日-流水号`。

## 运输状态

```text
待发运 → 在途 → 已到达 → 已签收
  └→ 已取消
```

- 系统在工作台中将 `PENDING` 运单进一步区分为“待调度”和“待发运”：缺少车牌或司机为待调度，资料完整后为待发运。
- “待发运”阶段可以修改车辆调度信息。
- “在途”以后保留运输快照，不允许更换车辆。
- 运单进入“在途”时，对应执行通知进入“执行中”。
- 调度工作台按待调度、待发运、在途、已到达、已签收五列展示运单。

## 调度工作台

- 汇总有效运单、待调度、在途车辆、已签收和调度异常数量。
- 支持按运单、通知、批次、合同、车牌或司机搜索，并可按采购/销售运输筛选。
- 运单卡片展示物料数量、运输方式、线路、计划时间以及完整上游单据链。
- 可在卡片上直接确认发运、到达和签收；待调度运单进入详情补充车辆信息。
- 超过计划发运时间仍未发运、超过预计到达时间仍在途，或车辆司机资料缺失时，显示异常提示并支持“只看异常”。

## 运单详情

- 详情顶部展示运单创建、发运、到达和签收进度。
- 展示计划发运、预计到达、实际发运、实际到达和签收时间。
- 待发运阶段支持选择车辆、手工填写车牌司机，以及配置自营或第三方承运信息。
- 状态变化后运输信息作为执行快照展示，便于后续磅单和物流对账追溯。
- 运单到达或签收后，详情出现“关联磅单”板块；尚无有效磅单时可从此直接创建，已有磅单时可查看称重和结算重量。
- 运单到达后，详情出现“物流收货附件”板块，可上传签收单、收货现场照片或交接凭证。
- 至少存在一份物流收货附件才能确认签收；已签收运单的收货附件保留为履约凭证，不允许删除。
