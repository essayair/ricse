# 结算中心 — 使用指南

结算中心包含两个二级模块：

- 应收管理：管理销售业务应收结算、应收确认和回款状态。
- 应付管理：管理采购业务应付结算、付款申请和付款状态。

> ⬜ 当前为导航和占位页面，结算业务数据与接口尚未开发。

## 功能概述

生成结算单，关联合同和执行批次，完成业务结算。

## 前置条件

- 已有可结算的合同履约数据、磅单/质检结果和出入库凭证

## 权限与数据范围（开发约束）

- 应收、应付的查看和管理分别受结算模块功能权限控制。
- 结算单必须从合同或对应业务出入库来源继承企业范围，不能仅按结算单创建人过滤。
- 外部企业员工应能查看本企业参与交易形成的结算数据，同企业员工范围一致。
- 结算附件、发票、付款和收款必须继续沿结算单继承相同范围。
- 当前模块尚未落地，以上规则是后续开发和验收的强制约束。
