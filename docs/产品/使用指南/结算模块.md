# 应付管理与应收管理 — 使用指南

资金结算用于把已生效合同的业务金额转化为应收、应付，并记录实际收付款、预收预付与核销关系。

```text
销售合同 → 应收确认 → 出纳登记收款 → 业务认领 → 财务确认 → 核销 → 已结清
采购合同/执行批次 → 付款申请草稿 → 业务确认 → 财务提交审批 → 出纳创建付款单 → 财务确认 → 核销 → 已结清
```

## 菜单与口径

原“资金结算”菜单按资金方向拆为两个一级菜单。侧边栏与页面顶部切换的入口和顺序一致，面包屑按实际入口展示，例如“首页 → 应付管理 → 采购结算单”。

**应付管理**（付出去的钱、收进来的票）

- **付款申请单**：所有对外付款的唯一入口，包括采购货款、物流运费、销售客户退款和保证金退回；承载业务准备、财务提交和付款审批。
- **采购结算单**：按合同、已选磅单及最终质检依据编制和确认本次采购货物的实际应付金额；它是金额确认依据，不是付款计划，也不是执行批次。
- **付款单**：记录实际付出的资金、银行凭证、财务确认及核销。
- **进项发票**：汇总采购结算单和物流结算单上登记的进项发票，并列出待到票的结算单。
- **应付台账**：按合同汇总应付结算、付款、核销、未结、预付及逾期情况。

**应收管理**（收进来的钱、开出去的票）

- **销售结算单**（原“应收款计划”）：按实际货物确认本次应向客户收取的金额。
- **收款单**：记录实际到账、业务认领、财务确认和核销。
- **销项发票**：汇总销售结算单上登记的销项发票，并列出待开票的结算单。
- **应收台账**：按合同汇总应收结算、收款、核销、未结、预收及逾期情况。

收付合并的整体视图后续在工作台提供。
- **结算单**回答“应该收付多少钱”；**资金流水**回答“实际收付了多少钱”；**核销**建立两者的对应关系。
- 运费仍在「物流管理 → 运费结算单」独立归集，不与采购货款混为同一张业务结算单。

## 前置条件

1. 合同已审批生效，状态为已审批、执行中、已完成或已关闭。
2. 合同已经维护我方签约主体、交易对手方和业务单元（事业部）。
3. 经办人具有 `settlement.view`；结算创建/确认、收款登记/认领、付款申请/审批/执行、资金确认和核销分别使用专项权限。
4. 正式结算前，业务人员仍需核对磅单、质检结论、入出库凭证和合同结算口径。

## 创建并确认结算单

采购方向通过「应付管理 → 采购结算单」进入，也可从应付管理页面顶部的“采购结算单”标签进入。点击“新建采购结算”后选择合同，页面默认选用全部可结算车辆；可按执行批次筛选、整批取消或逐车调整。发货侧与收货侧磅单分列，采购优先选用已采信的发货磅单；缺少可用发货磅单时沿用收货侧。两侧净重不同时，页面用警示色标出较低一侧、逐车差值及差异车辆汇总，不自动按低值结算。可对当前范围内已选车辆统一切换磅单口径，也可逐车切换；同侧多张磅单须先在磅单管理确认采信的一张。切换后本次数量按选定净重及适用的计价口径重算，选择发货侧应核对页面带出的依据说明。顶部实时汇总车辆数、两侧净重、选用净重、结算数量和后端试算金额；逐车明细可调整本次数量或单价，也可改选检测报告并填写依据；整单协商在“最终结算”操作。质量扣款及含税金额由系统试算；保存草稿后在详情“确认形成应付”。无需整个批次全部完成，提前付款仍使用预付款或阶段款申请。缺少可追溯磅单或水分时不得伪造数据。

表格标题下方的操作行与列一一对应：在“批次 / 运单”列筛选批次并全选或全取消；在“发货磅单”“收货磅单”列批量切换当前范围内已选车辆的计量依据；在“检测报告”列批量选默认、发货侧或收货侧报告。若多车共用同一检测报告，也可直接选择该共用报告。同侧有多份报告、缺水分等无法安全自动判断的车辆保持原选项，须逐车确认。

批量选择栏持续显示当前实际选用口径，不在选择后退回占位文字：检测报告显示发货侧、收货侧、默认或共用报告；逐车不一致时显示“混合口径”。磅单统一选用一侧后，相应按钮高亮并标记已选；筛选批次、逐车改选或批量仅部分成功时，状态随实际已选车辆重新计算。取消依据说明确认不会误标为切换成功。

同一运单在同一货款方向仅能加入一张未作废的结算单，草稿、待审批、已驳回和已确认单据均占用。已占用运单保留在依据列表中并置灰，显示“已创建结算单”和关联单号，不能因少结数量、换磅单或换报告重复选择。编辑原草稿时排除本单占用；需要重做时先处理关联付款、核销等记录，再按原规则作废原结算单。采购货款、销售货款和运费结算分别核对，不互相占用。

列表底部增加合计：逐车依据表统计当前筛选中已勾选车辆的发货净重、收货净重、选用净重、折干及本次数量；逐车明细统计全部已选车辆的数量、加减项和计算后金额。结算详情、结算列表、物流结算选车与明细、物流结算列表及合同台账也展示对应合计。列表金额合计注明含草稿、不含作废，区别于页面顶部正式应收应付余额；单价、水分、品位不直接相加，不同计费单位分开统计。缺失重量显示“—”，不作为零重量参与合计。

依据表直接显示所选磅单净重、所选报告实测水分和据此折算的干基重量；报告选择框下方分别显示检测机构、结论、CaF₂ 品位及有数据时的选矿回收率。结算磅单与出入库磅单不同时标注差异。逐车结算明细可展开查看计价口径、累计已结和剩余数量、品位档与元/度价、质量扣款、税前净额、税率及税额；未完成试算的数据标为“待试算”，失败时显示原因，不显示旧报告的计算值。

依据表采用固定列宽并支持横向滚动，左侧批次／运单列固定，便于对照车辆。磅单编号与重量分行显示；本次结算数量与可结算数量分行标注。下方明细将净重、水分、折干分别展示，依据与调整说明支持多行填写。顶部汇总按网格排列，数量与金额分开展示。

### 逐车调整与最终结算

- 默认按选定磅单、检测报告与合同价格计算，各车汇总为“明细合计”。
- 仅调整某车时，勾选该车“数量调整”或“单价调整”，填写调整后的值及说明。单价是含税元/吨，不是本车总金额的加减数；品位分档合同仍保留原档位、元/度价与合同换算单价供核对。数量与单价互斥，切换需确认恢复另一项。质量扣款按适用规则另行计算，不重复填写。
- 如双方协商整批结果，在明细下方“最终结算”选择“调整总干基”或“调整总金额”。两种方式互斥，也不能叠加逐车数量、单价或历史金额调整；切换前弹窗确认，取消则保留原值。
- “调整总干基”：只改整单干基数量，系统按调整后数量 × 合同含税单价同步重算金额，并同步适用的每吨质量扣款。仅支持同一合同物料、同一价格及同一每吨扣款的干基货物；多物料、多档单价或扣款不同须逐车调整，避免虚构统一单价。不得超过所选计量依据支持的可协商数量。
- “调整总金额”：直接填写双方确认的整单含税金额，保留明细数量、价格及各车金额不变。必须填写整单调整说明。
- “按明细合计”恢复系统汇总；最终调整不回摊各车，不修改磅单、质检、库存或合同价格。明细合计与最终结算同时展示，预览、保存、打印及后续付款、发票对账均以最终结算数量、金额为准。
- 人工调整沿用现有确认、依据附件与审批规则，不自动确认应收应付。历史单据保留原快照，不因上线新功能追溯重算；历史加减项只能查看或主动取消，不自动转换成单价。

### 溢短装数量差异（线下签章）

- 系统按合同物料行累计核对本次数量与既往有效结算及草稿占用，不重复计入正在编辑的本单。超出合同溢装上限时提示；只有勾选“本次为最终结算”才核对短装下限，未选择的合同物料也纳入最终核对。
- 数量超出范围不阻断金额计算和预览。点击保存结算草稿时，弹出“确认溢短装数量差异”，展示合同数量、允许范围、累计数量和差额。
- “数量差异说明”必填，依据附件选填；点击“确认按实际数量生成”后正常生成草稿，不强制修改合同，不截断本次数量，也不改动磅单、质检或库存。此项溢短装确认不新增线上审批；改用其他业务依据、逐车或整单人工调整的既有审批规则不变。
- 说明及差异进入详情和打印件“备注／双方确认事项”，供双方线下签字盖章。系统保留经办人及时间；打印件不带出账号或内部审批信息。结算确认后可在详情“结算依据与双方盖章文件”补传扫描件，已确认附件不允许删除。
- 如累计结算数量或合同允许范围在生成、确认之间发生变化，须重新编辑草稿核对，不允许沿用旧差异确认。附件上传失败不重复创建草稿，可在详情补传。
- 合同详情的“结算记录”直接读取关联结算单，采购、销售及双边合同统一展示单号、日期、方向、状态、数量金额；有溢短装时展开查看差异和双方确认说明，点击单号进入结算单查看附件。右侧“结算执行”可快速定位该板块。草稿标明未确认，作废记录保留但不进入有效汇总；采购应付与销售应收分别汇总，不混加。查看受结算权限和事业部数据范围控制，不回写合同原备注或原条款。

萤石矿品位分档合同的预计单价不用于正式应付。页面按选用的检测报告中 CaF₂ 实测百分数数值命中合同价格档，显示不含税元/度、税前单价和计算过程；税率取合同价格行锁定的税率，系统据此计算税额和含税金额，经办人预览核对后保存。存量分档合同未记录税率的，由经办人填写并确认本次结算适用税率；合同已有税率时不得改填其他税率。品位超出档位、水分超过合同上限、缺报告，或分档价同时叠加尚未明确含税顺序的质量扣价时，系统拒绝自动结算，提示人工复核。库存入库依据保持已过账记录，货款结算可单独选择经确认的发货或收货侧磅单及检测报告，不回写库存。

合同约定选矿回收率扣价时，检测报告须录入“选矿回收率”指标（编码 `RECOVERY` 或名称含“回收率”，单位 %），报告附件即为回收率依据；混样报告关联多车时，各车共用同一回收率实测值、各取本车磅单重量。结算时系统按 `实测度数 × max(0, 基准 − 实测回收率) × 每点扣价` 计算每吨扣价（不含税），档位原单价不变，扣价按合同税率计税后列入“质量扣款”，税额按扣价后的不含税货款计算。报告缺回收率实测值时该车转人工确认，不自动生成金额。回收率指标的标准值可不填；若填写且仅回收率未达标，销售结算不再按“报告不合格”重复拦截，差额以合同扣价体现。

预付款和发货等阶段备款直接创建付款申请，不需要为了备款重复确认一笔货物应付。已配置合同质量规则的采购合同应使用实际货物结算；历史未映射应付须先人工复核，避免同一货物按合同阶段与实际批次重复确认。

以下合同阶段等口径保留销售及历史业务说明；新采购最终货款不再按“合同总额减累计结算”自动补余额，防止补回质量扣款或将未执行数量视为尾款。

1. 进入「应收管理 → 销售结算单」或「应付管理 → 采购结算单」。
2. 点击“新建销售结算单”或“新建采购结算单”。
3. 选择合同。系统自动带出我方签约主体、交易对手方、业务单元、合同金额、累计结算、剩余可结算和预收预付参考余额。
4. 选择结算口径：
   - **执行批次结算**：可选择一个或多个草稿、已确认、执行中或已完成的有效执行批次，逐行确认数量、单价和结算加减项金额；已取消批次不可选择；
   - **合同阶段结算**：填写阶段名称，并按阶段比例或金额结算；
   - **合同最终结算**：系统按“合同金额－累计有效结算”自动计算；
   - **调整结算**：用于业务确认后的补充调整，必须填写原因。
5. 保存后状态为“草稿”；复核无误后在详情中点击“确认形成应收/应付”。
6. 确认后不能直接修改金额，只能继续收付款核销，或在尚未核销时作废。
7. 已确认、部分结清或已结清的结算单，可在详情点击“打印存档”，进入独立的 A4 结算单页面；核对后打印，由供应方、采购方按实际管理要求签字盖章并归档。

系统会校验合同和执行批次的累计已结金额、数量，阻止重复或超额结算。同一合同可按多个执行批次分次结算，也可进行合同阶段及最终结算。

### 打印与归档

- 采购方向打印单据标题为“采购方名称＋采购结算单”，销售方向为“供应方名称＋销售结算单”。打印件仅展示供需双方需确认的合同和结算编号、业务明细、数量、价格、金额、备注及双方签字盖章区；不印 RICSE 品牌、内部事业部、系统状态、操作人、资金核销或打印日志。
- 实际货物采购结算打印件按车辆列示入库日期、车牌、物料、实测水分、毛重、皮重、净重、参考干基、本次结算数量、含税单价、加减项和含税金额。各车的结算数量、价格和金额由正式结算快照自动填入；合计与备注列明经双方确认的数量差异，不把差额静默摊到某辆车。A4 横向排版，供双方打印、签字、盖章。
- 参考纸单中逐车干基合计为 1049.38 吨，双方确认结算量为 1044.88 吨，两者相差 4.50 吨；备注提到的发货与到货干基差 8.85 吨是另一种比较口径，不可混为同一差额。统一合同单价时，可在“最终结算”调整总干基至 1044.88 吨并填写说明，由系统重算金额，不必将差额拆到每辆车；打印保留明细合计、最终结算和说明。保存后整张运单仍被本单占用，不能按差额另建结算单。修正时编辑原草稿，或按状态及关联资金规则作废重做，不改写库存。
- 采购结算中，交易对手方为供应方、我方签约主体为采购方；销售应收结算中，我方签约主体为供应方、交易对手方为采购方。
- 草稿尚未形成正式应收应付，已作废单据不再有效，二者均不能打印存档。
- 打印动作会写入结算单操作记录，管理员可查看打印操作人和时间；系统留痕不能代替双方按合同及公司制度完成的签字、盖章和档案保管。
- 打印件中的供需双方名称取自结算单；合同编号、金额和逐车来源均按已确认结算单留存的业务数据展示。旧单据若缺少历史磅单重量快照，对应格显示“—”，不能据当前变化后的源单据补造历史打印数据。

### 结算加减项与到期日

- 结算金额按“结算原金额＋结算加减项”计算；正数增加结算金额，负数扣减结算金额。
- 加减项适用于质量扣款、升贴水、价格补差、溢短装金额调整和商务折扣等场景。金额不为 0 时必须填写调整原因。
- 执行批次结算在各批次明细中填写加减项；合同阶段、合同最终和调整结算在单头填写。
- 执行批次是否完成不作为结算申请的硬性前提。预付款、发货款、到货款和尾款可按合同约定在不同履约阶段发起；页面同时展示批次状态、批次数量、剩余可结算数量与金额，申请人应依据合同及当前业务凭证填写。
- 系统继续校验批次必须属于当前合同和采购/销售方向、批次未取消、数量与金额不超过剩余可结算值；是否实际付款由付款申请审批流程判断。
- 结算详情实时展示关联执行批次的当前状态，并可进入批次详情；付款申请审批人可从申请详情进入关联结算单，核对批次状态及结算明细后决定是否批准。
- 采购结算填写“约定付款到期日”，应收结算填写“约定收款到期日”。到期日当天仍属于履约期限，次日仍未核销才计入逾期未结。
- 到期日不同于实际收付款日期，也不同于银行承兑、信用证等票据的到期日期。

## 收款登记、认领和确认

1. 出纳进入「应收管理 → 收款单」，点击“登记收款”。
2. 先选择实际到账的我方收款主体和银行账户；当时不能确定业务归属时，不必选择合同，但必须按银行流水填写实际付款方。
3. 选择支付方式：银行转账、银行承兑、商业承兑、信用证、融资支付、现金或其他。
4. 填写金额、发生日期、双方银行账户、银行流水号；票据类付款补充票据编号和到期日。
5. 上传银行回单；第三方代付必须填写实际付款方和代付原因。
6. 对应业务人员在详情中新增认领明细，选择销售合同，可进一步选择执行批次、款项类型和本次认领金额。一笔到账允许拆分认领到多个合同或批次。
7. 全部到账金额认领完成后，状态进入“待财务确认”；财务人员复核双方、金额、账户、认领明细和回单后点击“财务确认”。
8. 确认后才形成可核销余额；每个合同只能使用认领到该合同且已确认的金额，预收款可以早于结算单登记。

收款登记允许暂不关联合同，但必须固化我方法律主体、到账账户、实际付款方、金额和银行流水。合同、客户、业务单元及执行批次在认领时确定；我方收款主体必须与被认领合同的我方签约主体一致，避免资金串户。

## 应付管理和付款执行

### 物流付款

1. 进入「应付管理 → 付款申请单」，新建申请，业务类型选择「物流付款」。
2. 按我方付款主体、交易对手筛选，在付款依据中选择已复核的「物流结算单」。不需要再选择采购或销售合同，不混用采购结算单。
3. 自动带出物流结算确认的本次付款主体（默认货主，可在结算草稿中通过修改按钮调整并留原因）、承运方、业务单元（事业部）及有效银行账户；原业务货主保留不变。展示结算总额、已登记运费、其他有效申请占用和可申请余额。第三方收款须填写原因并审批。
4. 填写本次金额、付款用途、条件和附件，保存业务草稿或确认资料交财务。草稿不占额度，业务确认后计入占用；财务沿用付款申请审批流程提交，移动端也可以审核物流付款。
5. 审批通过后创建付款单、上传付款凭证、财务确认。在付款单详情点击「核销付款」，只可核销到本申请关联的原物流结算单。有专项权限的人员可填写原因撤销运费核销。
6. 同一物流结算可分次申请、分次付款；已登记付款与申请剩余额度不重复计算。不能超额申请、不能跨结算核销，运费不计入采购货款已付或抵扣。

当前仅支持结算款、尾款。物流结算须归属一个已维护的承运方和一个事业部，混合承运方或事业部时需先拆分物流结算。已有有效付款申请或核销的物流结算不能直接作废。物流预付款、代开票税费拆分及跨承运方分摊不在本次范围。

付款申请新建和草稿编辑使用独立页面，按“申请归属 → 本次付款依据 → 业务进度与质量 → 金额与抵扣 → 账户与附件”顺序填写。支持先按我方主体和供应商筛选合同，也可直接选择合同；阶段款可指定批次及相关车辆。

新建采购货款申请时，只显示仍有可申请付款余额的合同，已全部付款或额度被有效申请占满的合同不再列入候选，我方主体、交易对手筛选也采用同一范围。余额按“适用货款上限－已登记净付款－有效申请未执行部分”实时回算，不重复计算部分付款；驳回、退回草稿、作废或退款等处理释放额度后，重新进入页面即可再次选到。若付款单作废后原审批申请仍有效，额度回到原申请继续处理，不因此开放重复申请。

合同已确认最终结算时，付款上限采用累计正式结算货款，质量扣价形成的差额不补回合同预计金额。已有草稿、驳回单保留原合同用于编辑，历史付款申请、付款与核销记录不隐藏；销售客户退款、保证金退回及独立履约保证金不受采购货款已付清过滤影响。

新申请的结算款、尾款须关联已确认采购结算单；预付款和阶段款可按合同或批次申请，不统一要求到货、质检或入库完成。本次勾选发货、到货、质量、入库等条件时，系统检查对应的具体来源；见票付款由财务核对上传依据。允许先保存业务草稿，正式金额占用从“确认资料并交财务”开始。

1. 业务人员进入「应付管理 → 付款申请单」，新建付款申请，选择“采购付款”或“销售客户退款/保证金退回”。采购付款可关联已确认采购结算单，预付款允许暂不选择结算单；客户退款必须选择原收款单。
2. 可直接选择合同，也可先按我方主体、交易对手筛选合同；系统展示合同剩余可申请金额。需要细分到具体履约时，再选择执行批次，批次选项同时展示状态。
3. 填写款项类型、申请金额、计划付款日、支付方式和付款用途；从主数据银行账户中选择我方付款账户和对方收款账户。账户户名、开户行、账号作为业务快照随单保存，详情页每行均可点击复制，便于录入企业网银。
4. 保存后是业务草稿，可修改、删除和补充附件。业务人员复核无误后点击“确认资料并交财务”；此动作不进入审批。
5. 财务人员复核付款资料，可退回业务修改，也可点击“提交审批”。只有财务提交后，系统才按照「系统管理 → 审批流程 → 付款申请」的启用节点生成审批任务。默认路径为“风控/财务经理 → 业务责任人 → 总经理”，其中业务责任人按付款申请所属业务单元匹配；管理员可调整节点角色、会签/或签、人员范围和启停状态。
6. 当前节点审批人批准后才进入下一级；任一节点驳回后申请退回，修改或补充依据后须重新完成业务确认和财务提交，并保留每轮审批记录。
7. 全部节点通过后，出纳可从付款申请详情点击“创建付款单”，也可在付款单列表点击“新建付款单”后选择已审批且尚未付清的付款申请。两种入口都进入同一个独立创建页面，不允许脱离付款申请登记付款。
8. 页面自动带出申请基本信息、计划付款账户和计划收款账户。上传图片或 PDF，或直接粘贴银行回单截图后，系统识别电子回单号、付款/收款户名、账号、开户行、金额、币种、付款时间和用途；识别结果必须人工核对，OCR 不代替出纳确认。
9. 实际账户与申请账户不同时，页面同时校验该账号是否属于同一企业的其他有效账户。正常换用同主体其他账户允许继续，但必须填写账户差异说明；账号已登记在其他企业名下时禁止提交。申请账户快照保持不变，付款单保存真实发生账户。
10. 一张付款申请允许分次创建多张付款单，系统展示申请金额、累计已付和剩余待付，并阻止超额付款、重复电子回单号以及付款账号、收款账号、金额和时间完全相同的疑似重复登记。
11. 付款凭证随付款单创建并归档，付款单进入“待财务确认”；会计确认实际付款事实后，普通采购付款才可用于应付核销，客户退款则同步占用原收款单的可退余额。
12. 实际收款方与合同交易对手不一致时，必须在申请阶段标记第三方收款并填写原因；创建付款单时不得绕过审批修改收款方。

收付款单列表分别展示“付款方”和“收款方”：付款单按银行凭证显示我方实际付款户名与实际收款户名；收款单按凭证显示实际付款户名与我方实际收款户名。涉及第三方代付/代收时，实际资金往来方与合同交易对手分别标示。

付款申请由采销业务员或运营经理发起。审批通过或已创建付款单的申请可进入独立详情页执行“打印存档”；打印版按 A4 排版，包含合同与付款双方、申请金额及用途、银行账户、审批轨迹、附件目录和签字栏，每次发起打印均写入操作记录。草稿、审批中、已驳回和已作废申请不得作为正式归档件打印。

结算单、付款申请、收款单和付款单均从列表进入独立详情页，不再以窄弹窗承载完整信息。付款单创建因包含申请选择、凭证预览、OCR 识别、账户校验和人工核对，也使用独立页面；仅简单编辑、核销等短操作继续使用弹窗。

资金结算中的日期字段统一通过日期面板选择，点击字段或日历图标打开，选择后点击面板内“确认”写入；打开业务弹窗时不会自动弹出日期面板。付款依据、银行回单等附件上传或删除后，当前详情页保持打开，可继续上传、查看和执行下一步，直至用户主动关闭。

## 查看应付台账、应收台账

1. 进入「应付管理 → 应付台账」或「应收管理 → 应收台账」。两张台账各自只含本方向，原“结算台账”地址自动打开应付台账。
2. 可按结算状态、合同编号、合同标题、法律主体、业务单元和交易对手筛选；单击行打开合同。
3. 台账展示合同金额、草稿金额、正式结算金额、结算加减项、累计付款（收款）、已核销、未核销资金、预付（预收）余额、未结和逾期金额。
4. 台账只用于查询和追踪，不直接修改汇总数；发现差异时应回到结算单、付款申请、收付款单或核销记录修正源单据。

## 发票登记与进项、销项发票

发票登记在结算依据上完成，进项发票、销项发票页面负责跨单据查询和核对：

| 发票类型 | 在哪里登记 | 可登记时机 | 开票方 → 收票方 | 核对口径 |
|---|---|---|---|---|
| 货款进项 | 采购结算单详情，或「进项发票 → 待到票核对」 | 结算单已确认 | 供应商 → 我方签约主体 | 数量与含税金额 |
| 运费进项 | 物流结算单详情，或「进项发票 → 待到票核对」 | 物流结算单已复核 | 承运方 → 付款主体 | 仅含税金额 |
| 货款销项 | 销售结算单详情，或「销项发票 → 待开票核对」 | 结算单已确认 | 我方签约主体 → 客户 | 数量与含税金额 |

1. **发票明细**：按开票日期、类型（货款/运费）、状态和关键字查询已登记发票；底部合计只统计有效发票。单击行打开对应结算单或物流结算单。
2. **待到票核对 / 待开票核对**：列出已确认（复核）的结算依据及其到票状态——未到票、部分到票、数量不符、发票超额、已匹配。默认只看未匹配，可点“登记发票”直接补登。
3. 登记时填写发票号码、开票日期、品名规格和含税金额，数量、税率、税额等按票面选填。运费发票默认带出“运输服务*运输费”和 9% 税率，须按实际票面核对。同一开票方的同一发票号码不能重复登记。
4. 发票录错时在对应结算单或物流结算单详情中作废并填写原因，记录保留。结算单或物流结算单存在有效发票时不能作废，须先作废发票。
5. 登记运费发票需要物流结算维护权限或资金结算创建权限；历史物流结算单缺少承运方或付款主体时不能登记，须先补齐。
6. 系统只做数量、金额核对，不做发票验真、认证抵扣，也不生成会计凭证或税务申报数据。

## 核销

1. 可从结算单发起：打开一张已确认或部分结清的结算单，点击“核销收款/付款”。
2. 也可从已确认的付款单发起：进入「应付管理 → 付款单」，打开状态为“待核销”或“部分核销”的付款单，点击详情页右上角“核销付款”。系统仅列出同一合同、同一法律主体、同一交易对手且仍有未结金额的采购结算单。
3. 从结算单发起时，系统只列出匹配的可用资金流水；从付款单发起时，选择匹配的采购结算单。
4. 输入本次核销金额并确认。
5. 系统同步更新结算单已核销金额和资金流水已分配金额；支持部分核销、多次核销和一笔资金核销多张结算单。
6. 核销错误时，管理员在核销记录点击“撤销核销”并填写原因，系统同步恢复两边余额并保留完整痕迹。

核销金额不得超过结算单未结金额，也不得超过资金流水可用余额。结算金额全部核销后，状态自动变为“已结清”。

## 状态

| 状态 | 说明 |
|---|---|
| 草稿 | 可复核后确认，也可直接作废 |
| 待收付 | 已确认形成正式应收/应付，尚未核销 |
| 部分结清 | 已核销部分金额 |
| 已结清 | 结算金额已全部核销 |
| 已作废 | 不再参与汇总 |

## 数据权限和审计

- 结算单和资金流水继承关联合同的数据范围，同时受用户业务单元归属上限控制。
- 法律主体用于应收应付和收付款归属，业务单元用于经营责任与利润统计，两者分别保存。
- 管理员可通过单据详情审计入口查看创建、确认、打印存档、核销和作废等操作轨迹。
- 已有有效核销记录的结算单或资金流水不能直接作废；必须先撤销核销。
- 保证金、退款和保证金退回独立展示，不允许误核销贸易货款结算单。

## 采购质量扣款、预付抵扣及移动审批（2026-10-17）

- 质量结算沿用合同规则快照和质检任务最终采用报告；使用运单已选的结算口径磅单，入库数量与结算数量分别展示。
- 检测结果为扣款待确认时，具有“确认合同扣款接收”权限的结算制单或付款申请人员，可在质量依据表格或验收详情明确确认商务接收。确认时核对报告版本并留原因，不修改检测值，也不额外增加审批节点。
- 拒收、待人工判定和未完成检测的货物不进入正常质量结算；同批其他已合格货物可以先处理。单车混装多物料暂不自动套用同一检测结果。
- 质量价格扣款独立列示，不能在“其他加减项”中重复填写。合同可分车、分批结算，同一运单不得拆到多张未作废结算单；系统继续控制来源数量及合同溢装范围。分次付款、核销仍在同一结算单下处理。
- 货物应付金额不减预付款；财务在付款申请的余额区域将已确认预付款“核销抵扣本结算”，或明确“保留至其他批次”。用途指定不等于核销，可解除尚未使用的用途。
- 已登记但待财务确认的付款也占额度；部分付款时，已登记部分和申请剩余部分共同占用，不能重复申请。驳回、作废、撤销核销按实际记录回算。
- 质保金按尾款处理，在阶段名称或付款用途注明“质保金”，沿用尾款申请、审批、付款和核销；独立履约保证金仍与货款分开。
- 已确认结算与审批保存质量依据及资金摘要快照。磅单改选、报告更换或质检重判后，原依据失效时提示复核并阻止继续登记付款，不静默改写历史金额。
- 小程序工作台“待审批/业务审批”增加付款申请，支持按合同、付款申请筛选，查看质量、账户、预付抵扣、附件与审批记录并同意/驳回；财务制单和付款登记仍在Web完成。
