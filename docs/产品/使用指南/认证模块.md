# 认证与登录 — 使用指南

> ✅ 已完成 JWT 登录认证和多角色授权基础。

## 功能概述

系统使用账号密码登录并签发访问令牌。登录后的菜单和接口操作由有效角色权限控制，业务数据同时受用户角色授权的数据范围限制。

## 前置条件

- 管理员已经创建有效账号；
- 外部员工账号已经绑定外部企业，且该企业已关联合作伙伴；
- 账号至少存在一项有效角色授权。

## 登录和授权

1. 在登录页输入登录用户名或员工手机号，以及账号密码。
2. 登录成功后进入 `/dashboard` 系统外壳，左侧菜单根据账号可用功能展示。
3. 系统在每次业务接口请求中重新核对账号状态、有效角色、功能权限和数据范围。
4. 账号停用、角色停用、授权过期后，对应权限不再生效。

## 管理员开通账号

系统管理员可从两个入口开通员工账号：

1. 「组织数据 → 用户账号 → 新建」：依次选择企业和未开通账号的员工；
2. 「组织数据 → 员工管理 → 员工详情 → 开通账号」。

两个入口均须明确填写或确认：

- 员工手机号：必须为 11 位中国大陆手机号，新建员工时必填、员工范围内唯一，可在员工详情中修改，也可作为登录凭据；前端限制输入位数，后端和数据库继续执行格式与重复校验；
- 登录用户名：选择员工后默认带入员工手机号，管理员可修改；它与员工手机号独立保存，两者均可登录。用户名以字母或数字开头，支持字母、数字、点、下划线和短横线，长度 3-50 位；
- 登录密码：至少 6 位；
- 确认密码：必须与登录密码一致。

密码输入默认隐藏，可临时切换显示以便核对。后端只保存 bcrypt 哈希，不返回或展示原始密码。开通后由管理员在「系统管理 → 用户与权限」中继续配置角色和数据范围。

管理员重置密码时同样需要输入两次确认；重置成功后会清除该账号的刷新令牌，原登录会话需要重新认证。

## 多角色与数据范围

- 一个账号可以同时具有多个角色。
- 功能权限决定是否可以查看或管理模块。
- 数据范围决定可以访问哪些企业、部门或本人数据。
- 内部员工可配置全部、本企业、指定企业、部门、部门及下级或本人范围。
- 外部员工强制使用所属企业全部关联数据范围，同企业员工范围一致，不限创建人。
- 外部企业未关联合作伙伴时不能访问业务数据。

详细口径见[权限与数据范围规范](../权限与数据范围规范.md)。

## 常见问题

- **登录成功但看不到某个菜单**：账号角色没有该模块功能权限，或角色已经停用/过期。
- **无法开通员工账号**：检查该员工是否已经关联其他账号，用户名是否重复或不符合格式，以及两次密码是否一致。
- **能进入模块但找不到一张单据**：该单据不在当前授权数据范围内，或其上游合同与当前企业无关联。
- **外部员工为什么能看到同事创建的单据**：外部数据范围按企业共享，不按创建人拆分。
- **外部员工为什么不能审批或修改**：企业级数据范围只决定可见数据，具体操作仍需角色包含相应权限。
