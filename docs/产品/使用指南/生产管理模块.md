# 生产管理 — 使用指南

## 1. 功能概述

生产管理用于把库存中的原材料按生产方案转化为新的产成品库存，支持自营生产和委外加工两种方式。系统完整保留“生产方案 → 生产任务 → 原料库存批次 → 实际耗用 → 完工申报 → 质量确认 → 产成品库存批次”的追溯链。

一期定位是大宗贸易平台中的轻量生产执行管理，不建设工序级 MES、设备联网、班组排班和复杂成本核算。

## 2. 使用前置条件

开始生产前应先完成：

1. 在“主数据管理 → 物料品类”分别维护投入物料和产出物料。加工前后物料含义发生变化时必须使用不同物料编码。
2. 在“主数据管理 → 仓库库位”维护原料仓库和成品仓库。
3. 维护内部库存主体。库存始终按“主体 + 仓库 + 物料 + 批次”独立核算。
4. 委外加工时，先把加工企业维护为具有供应商角色的合作伙伴，再在“主数据管理 → 服务生态 → 加工服务商”建立专业档案。
5. 给相关员工授予生产管理员、仓储库管或质量岗位权限。

## 3. 菜单与页面

左侧一级菜单“生产管理”包含：

- 生产任务：新建、查询和执行生产任务。
- 生产方案：维护标准投入、产出、收率、偏差及质量要求。
- 生产台账：从已入库产成品反查生产任务和实际原料批次。

## 4. 标准操作流程

### 4.1 建立生产方案

进入“生产管理 → 生产方案 → 新建生产方案”，填写：

| 字段 | 说明 |
|---|---|
| 方案名称 | 业务人员可识别的方案名称 |
| 库存主体 | 该方案适用的内部货权主体 |
| 产出物料 | 加工后形成库存的物料编码 |
| 基准产量 | 标准投料比例对应的产出基数 |
| 标准投入 | 每个基准产量需要的主料、辅料和包装物数量 |
| 目标收率 | 用于分析计划和实际收率，不直接改变库存 |
| 产量允许偏差 | 控制累计完工申报的最大数量 |
| 质量控制 | 勾选后，完工申报必须确认合格才能入库 |
| 工艺/质量要求 | 任务详情中的作业参考说明 |

例如：基准产量为 100 吨、主料标准投入为 108 吨。新建计划产量 200 吨的任务时，系统自动生成 216 吨计划主料。

方案列表提供编辑入口。方案一旦被任务引用，库存主体、产出物料和基准产量锁定；仍可维护名称、投料标准、工艺质量说明和启停状态，修改仅影响后续新任务。

### 4.2 创建并下达生产任务

进入“生产管理 → 生产任务 → 新建生产任务”：

1. 选择生产方案，系统自动带出库存主体、产出物料和计划投入。
2. 选择自营生产或委外加工；委外时必须选择有效加工服务商。
3. 选择原料仓库、成品仓库，填写计划产量、负责人和计划时间。
4. 可记录销售需求单号作为来源参考。
5. 保存后任务为“草稿”；复核无误后进入详情点击“下达任务”。

任务下达不会立即扣减库存，而是开放原料批次预占。

### 4.3 原料批次预占与领料

在任务详情“原料批次预占”区域：

1. 系统仅展示与任务库存主体、原料仓库和投入物料一致的可用库存批次。
2. 可点击“按入库顺序分配”，也可以手工填写各批次预占数量。
3. 全部投入物料达到计划用量后，任务进入“待领料”。
4. 点击“确认领料”后，系统原子扣减原料库存并写入“生产领料”库存台账；任务进入“加工中”。

生产预占与销售待出库冻结共同占用库存可用量。在库总览分别展示销售预占和生产预占，避免同一库存被重复使用。

### 4.4 记录耗用与退料

领料后，在每个原料批次行内记录实际耗用。已领但未耗用的数量可以退回原库存批次，系统恢复库存并生成“生产退料”台账。

任务关闭前，所有已领数量必须已经耗用或退回。

### 4.5 完工、质检与入库

1. 至少记录一次实际投料耗用后，才能点击“完工申报”。
2. 一项生产任务可以分多次完工；每次完工形成独立完工单。
3. 需要质检时，具有生产管理或质量管理权限的人员选择“合格、返工、报废”。返工或报废必须填写原因。
4. 合格完工单进入“待入库”，点击“生产入库”后生成新的产成品库存批次和生产入库台账。
5. 累计合格入库量达到任务计划产量后，任务进入“已完工”。余料处理完成后关闭任务。

每次完工入库独立形成一个产成品库存批次，以便后续销售出库、质量和成本追溯。

## 5. 状态流转

```text
草稿 → 已下达 → 待领料 → 加工中
                         ├→ 待质检 → 待入库 → 部分完工/已完工 → 已关闭
                         ├→ 返工 → 加工中
                         └→ 报废（不形成库存）
```

- 草稿、已下达和待领料且尚未领料的任务可以取消。
- 已领料或开始加工后不能直接取消，应处理耗用、退料和完工结果。
- 只有质量合格的完工申报可以生产入库。
- 完工入库是库存过账动作，不是普通状态修改。

## 6. 自营与委外口径

| 项目 | 自营生产 | 委外加工 |
|---|---|---|
| 执行主体 | 内部生产人员 | 服务生态中的加工服务商 |
| 原料货权 | 始终属于任务库存主体 | 发往加工方后仍属于任务库存主体 |
| 库存处理 | 领料扣减原料批次，完工增加产成品批次 | 委外发料同样进入在制台账，完工回库增加产成品批次 |
| 加工费 | 可不填 | 可记录加工费单价，后续结算中心引用 |

## 7. 权限与数据范围

| 权限 | 能力 |
|---|---|
| `production.view` | 查看生产方案、任务和生产台账 |
| `production.manage` | 维护方案、创建/下达任务、预占、耗用、完工和质量确认 |
| `production.post` | 生产领料、退料和完工入库过账 |

系统预置“生产管理员”角色。仓储库管可以查看任务并进行库存过账，质量岗位可以查看生产任务并按其质量权限参与确认。系统管理员拥有全部权限。

内部账号按任务创建人、所属企业对应库存主体或全局数据范围查看；外部加工企业仅能查看分配给本企业加工服务档案的委外任务，操作能力仍取决于其角色权限。

## 8. 一期边界

当前不包含：工序路线、设备/工位、班次报工、BOM 多版本审批、领料单打印、加工费应付单自动生成、原辅料及制造费用成本归集、生产退库冲销和质检任务模块自动关联。上述能力后续在实际生产场景稳定后扩展。
