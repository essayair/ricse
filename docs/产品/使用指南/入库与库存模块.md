# 入库与库存模块使用指南

## 1. 功能概述

入库与库存模块承接采购物流发运后的业务闭环：采购运单确认发运、进入在途时，系统自动生成“待到货”入库作业单；同一张单持续跟踪运输到达、签收、过磅、质检、现场收货和库存入账。仓管补齐实际收货信息并确认收货后，再生成业务入库单、库存批次和库存台账。

## 2. 前置条件

- 物流运单方向为采购；确认发运后即可生成入库作业单。
- 运单到达后才能进入现场过磅和质检节点。
- 正式确认收货和库存入账前，必须存在一张“已复核”磅单以及一张被选为最终验收依据的“已确认且合格”质检单。
- 主数据中已维护启用状态的入库仓库。
- “超标扣款”“熔断”或“待判定”的货物不可入库，也不能生成库存批次和库存台账。

## 3. 标准操作流程

### 3.1 自动生成入库作业单

无需人工新建物流入库单：

1. 采购物流运单确认发运、状态进入“在途”时，系统自动生成“待到货”入库作业单。
2. 运单确认到达时，系统再次检查并补生成漏单。
3. 同一运单不存在其他未作废入库作业单。
4. 后续磅单与质检单均关联并更新这张既有作业单，不重复创建。

系统初始带出运单、合同、执行批次、计划数量、物料、供应商、车牌及目标仓库；磅单、最终验收质检单、质量扣减和最终入库数量在后续作业中逐步补齐。

同一车辆可以存在多张独立质检单。第一张被确认且结论为“合格”的质检单自动成为最终验收依据；待入库阶段可以改选同一运单下其他已确认合格质检单。超标扣款、熔断和待判定质检单只展示为异常或处理中，不允许成为库存入账依据。

最终入库数量优先取质检单的结算重量；质检单未单独给出时取磅单结算重量。

### 3.2 上传收货附件

物流入库单处于“待入库”时，可在详情页上传现场照片、签收凭证或 PDF：

- 支持 JPG、PNG、WEBP、PDF。
- 单个文件不超过 20MB。
- 待入库状态支持查看、增加和删除；确认收货后附件锁定，只允许查看。

### 3.3 确认收货与入账

1. 核对物流、磅单、质检和附件，补齐仓库、实际收货时间、收货人后点击“确认收货”。
2. 已收货状态点击“生成业务入库并入账”。
3. 系统自动生成业务入库单、库存批次和一条入库台账，并增加可用库存。

服务端会在最终验收依据绑定、确认收货和正式入账环节重复校验质检状态与结论。历史“超标扣款”待入库单或已收货单不能继续入账，应完成复检，并在待入库作业单中改选新的已确认合格质检单；无法修复的异常单再作废处理。

## 4. 状态流转

```text
待到货 → 已到达待过磅 → 过磅处理中/待复核 → 已过磅待质检
→ 质检处理中/质检异常 → 合格待收货 → 已收货待入账 → 已入账
                                       └──作废────────→ 已作废
```

- 作业中：由采购运单确认发运自动生成，通过细分阶段展示待到货、过磅、质检和合格待收货。
- 已收货：现场收货已确认，可生成业务入库并入账。
- 已入账：业务入库单、库存批次、库存台账已经形成。
- 已作废：不再参与后续业务；运单仍处于有效执行状态时，可由系统补生成新的入库作业单并重新完成验收。

## 5. 库存查询

进入“库存管理”可查看：

- 库存批次总数、物料数、仓库数和当前可用库存总量。
- 每个批次的业务入库单、物料、供应商、仓库、初始数量、可用数量和质量结论。
- 库存台账中的业务类型、业务单号、数量变动和变动后余额。

## 6. 常见问题

- 没有自动生成入库作业单：检查是否为采购运单且是否已经确认发运；确认到达操作还会再次补生成。
- 无法确认收货：只有待入库状态可以确认，并且必须先补齐仓库、实际收货时间和收货人。
- 无法上传附件：只有待入库状态允许增删附件。
- 无法生成库存：必须先确认收货、验收依据必须已确认且合格，并且一个物流入库单只能入账一次。

## 7. 权限与数据范围

- 查看入库单、库存批次、库存台账和附件需要“库存查看”权限；创建、确认、作废、入账及附件增删需要“库存管理”权限。
- 物流入库单从采购运单继承合同企业范围，业务入库、库存批次和库存台账继续继承该来源。
- 外部企业员工可查看本企业参与采购合同形成的入库与库存数据，不限收货人或单据创建人。
- 库存总览和库存台账均在服务端过滤企业范围，汇总数字只统计用户可见批次。

通用口径见[权限与数据范围规范](../权限与数据范围规范.md)。
