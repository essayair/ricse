# 入库与库存模块使用指南

## 1. 功能概述

入库与库存模块承接采购物流到货后的业务闭环：从符合条件的物流运单创建物流入库单，选定一张已确认质检单作为最终质量验收依据，确认收货后生成业务入库单、库存批次和库存台账。

## 2. 前置条件

- 物流运单方向为采购，状态为“已到达”或“已签收”。
- 运单至少存在一张“已复核”磅单。
- 选定磅单至少存在一张“已确认”且结论为“合格”的质检单。
- 主数据中已维护启用状态的入库仓库。
- “超标扣款”“熔断”或“待判定”的货物不可入库，也不能生成库存批次和库存台账。

## 3. 标准操作流程

### 3.1 创建物流入库单

进入“物流管理 → 入库管理”，点击“新建物流入库单”：

1. 在候选列表选择采购到货运单。
2. 选择该运单下的已复核磅单。
3. 选择一张已确认质检单作为本次最终质量验收依据。
4. 选择入库仓库，填写收货时间、收货人和备注。
5. 保存后进入物流入库单详情。

最终入库数量优先取质检单的结算重量；质检单未单独给出时取磅单结算重量。

### 3.2 上传收货附件

物流入库单处于“草稿”时，可在详情页上传现场照片、签收凭证或 PDF：

- 支持 JPG、PNG、WEBP、PDF。
- 单个文件不超过 20MB。
- 草稿状态支持查看、增加和删除；确认收货后附件锁定，只允许查看。

### 3.3 确认收货与入账

1. 核对物流、磅单、质检、仓库和附件信息后点击“确认收货”。
2. 已收货状态点击“生成业务入库并入账”。
3. 系统自动生成业务入库单、库存批次和一条入库台账，并增加可用库存。

服务端会在创建、确认收货和正式入账三个环节重复校验质检状态与结论。历史“超标扣款”入库草稿或已收货单不能继续入账，应作废后完成复检，取得已确认合格结论后重新创建。

## 4. 状态流转

```text
草稿 ──确认收货──> 已收货 ──生成业务入库并入账──> 已入账
  └──作废──> 已作废
```

- 草稿：可上传/删除收货附件，可确认或作废。
- 已收货：现场收货已确认，可生成业务入库并入账。
- 已入账：业务入库单、库存批次、库存台账已经形成。
- 已作废：不再参与后续业务，同一运单可重新创建物流入库单。

## 5. 库存查询

进入“库存管理”可查看：

- 库存批次总数、物料数、仓库数和当前可用库存总量。
- 每个批次的业务入库单、物料、供应商、仓库、初始数量、可用数量和质量结论。
- 库存台账中的业务类型、业务单号、数量变动和变动后余额。

## 6. 常见问题

- 看不到采购运单：检查是否已到达/签收，磅单是否已复核，并确认至少存在一张已确认且合格的质检单。
- 无法确认收货：只有草稿状态可以确认。
- 无法上传附件：只有草稿状态允许增删附件。
- 无法生成库存：必须先确认收货、验收依据必须已确认且合格，并且一个物流入库单只能入账一次。

## 7. 权限与数据范围

- 查看入库单、库存批次、库存台账和附件需要“库存查看”权限；创建、确认、作废、入账及附件增删需要“库存管理”权限。
- 物流入库单从采购运单继承合同企业范围，业务入库、库存批次和库存台账继续继承该来源。
- 外部企业员工可查看本企业参与采购合同形成的入库与库存数据，不限收货人或单据创建人。
- 库存总览和库存台账均在服务端过滤企业范围，汇总数字只统计用户可见批次。

通用口径见[权限与数据范围规范](../权限与数据范围规范.md)。
