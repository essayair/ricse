# 双边直拨使用指南

> 本地开发版本，更新于2026-11-12。尚未部署。适用一采一销、同一内部签约主体、供应商直接发给下游客户；原地交割暂不支持。

## 1. 我该从哪里开始

| 岗位 | 页面/操作 | 前置 | 完成后 |
|---|---|---|---|
| 业务运营 | 合同管理 → 新建/编辑双边合同 | 内部主体、供应商、客户和物料已维护 | 两向合同资料提交既有审批 |
| 业务运营 | 双边合同详情 → 新建直拨执行 | 合同已审批或执行中 | 两向批次、配对通知同时下达 |
| 物流运营 | 配对通知 → 创建物流运单 | 通知已下达 | 一车一张共享运单，采购方向也可查看 |
| 现场/质检 | 磅单管理、质检管理 | 运单正常到货作业 | 复核采信磅单、确认报告、完成最终判定 |
| 库存操作人员 | 运单详情 → 直拨交付 | 已签收、签收附件、有效磅单、最终报告 | 两向交付同步完成，不形成仓库库存 |
| 运营经理 | 同一运单 → 复核通过/退回 | 经办人选择提交复核 | 通过后生成配对业务单据，或退回重做 |
| 财务/结算 | 采购结算单、销售结算单 | 存在有效直拨交付；采购另需同车销售结算已审批 | 先做销售结算并完成审批；采购结算的磅单、报告、数量自动跟随销售结算（不能改选），金额按采购价格计算；之后继续原收付款、发票、核销 |

账号还须具有对应业务单元（事业部）的数据范围，只有查看权限不会出现操作入口。小程序现场操作也按关联后台账号权限执行。

## 直拨进出与待交付入口（2026-11-12）

- **库存管理 → 直拨进出**：按每车每次交付版本一行，同时查看采购业务入库、销售出库单号，实物/计价数量、合同三方、事业部、磅单与报告依据、经办人和确认时间。点击“查看记录”展开交付说明与撤销原因；有物流查看权限时可进入原运单的直拨交付区。
- 支持按单号、合同、车牌、物料、企业或事业部搜索，按有效/已撤销状态及交付确认日期筛选，支持分页。顶部汇总为筛选范围内全部有效交付，不是仅本页；采购与销售数量相同，只累计一次，撤销记录不累计。
- **物流管理 → 运单管理 → 待直拨交付确认**：显示客户已签收、尚未确认直拨交付的车次，待运营经理复核的车次也保留。拒收退回、已转仓、已取消、交付已完成及合同已结束的车次不进入该待办。小程序工作台待直拨交付数量使用同一条件。
- 直拨发货单位默认是上游供应商、收货单位默认是下游客户。原凭证不被覆盖；系统空白单与手动追加时都按直拨三方关系带出主体。
- 直拨只确认发货/收货两侧采信磅单，不将其当作我方仓库出入库磅单；任一侧完成采信后过磅任务正常完成。交付选择在运单中办理，货款口径在结算时处理。常规采购、销售库存规则不变。
- 小程序直拨确认也默认选择与最终报告同侧的磅单；跨侧时选择“磅单协商”或“只有一方出质检单”，未选择原因不能确认或提交复核。

直拨进出为内部只读记录，沿用 `inventory.view` 和业务单元范围；不形成仓库库存，不提供手工补账或删除入口。业务更正仍从运单撤销直拨交付，再重新确认，历史版本保留。

双边合同和附件由内部运营维护。外部供应商、客户只读查看本方方向，即使误配合同写权限也不能维护整份双边合同。

## 2. 合同与执行

1. 双边合同保留上游/下游独立价格；分别填写采购和销售外部合同号、签订日期及收付款约定。
2. 附件分别标为“采购合同”“销售合同”，提交审批时两类各至少一份；缺资料可先存草稿。审批后不能直接改分类、换附件。
3. 品位价可复制采购档位到销售侧，再修改价格；差价对照用于提醒，不替代审批判断。
4. 审批后在详情点击“新建直拨执行”。选择货物、数量，选用已有确认批次或新建两向批次；页面显示各方向剩余可通知数量。
5. 起运地/目的地可手填，也可选择合同供应商、客户、我方主体收发货地址或仓库地址，带出联系人后仍可修改。填写计划日期和备注，提交后进入销售配对通知。
6. 从采购配对通知进入建运单会自动指向共享销售通知，不要重复建两张车单。运输组织方式在建车单时选择；供应商承运、客户自提不形成我方运费结算。

## 3. 现场及交付

1. 正常确认发运、送达、上传签收单/照片等并签收。
2. 发货、收货只需有一侧有效磅单及至少一份有效报告。两侧都有时保留原始资料，不能相互覆盖。同侧多磅单须先选定采信磅单。
3. 在质检任务中关联报告，最终采用一份并完成判定；没有任务时可从到货运单补建归集任务，不强制重复送检。
4. 运单“直拨交付”并列显示两侧证据。系统默认选中与最终报告同一侧的采信磅单；如因磅单协商或只有一方出质检单而改用另一侧磅单，须选择对应原因。采用任务最终报告，填写采用依据/差异说明。异常质量如确认接收，显式勾选并说明。
5. 点击“预览交付数量”：实物取净重；物料折干时使用采用报告水分计算辅助数量。无水分会明确报错，不按零水分处理。
6. 核对后“确认销售交付并同步采购”，或“提交运营经理复核”。成功后看到采购业务入库、销售出库编号，实物和辅助数量各自一致。

这些是直拨业务单据，不是仓储收货，不增加库存总览、库存批次或可用库存。该车完成不代表整份合同的所有车、货款和发票都已完成。

## 4. 小程序

企业工作台增加“待直拨交付”，也可从业务查询进入对应运单。可预览/确认交付、提交/处理复核、撤销、取消、整车拒收、转我方仓库。原因直接在页面填写，报错后保留填写内容；取消、撤销等均校验下游占用。

未选为采信的磅单、未被任务最终采用的报告不能直接用于交付。先回磅单或质检任务完成选择，再返回操作。Web 为创建配对执行的主要入口，小程序不新增独立创建配对执行页。

## 5. 结算与纠错

- 两向结算分别创建：先做销售并完成审批。销售默认采用交付确认的磅单和报告，可按约定改选商业依据、协商数量并保留说明；采购的磅单、报告、数量跟随同车已审批销售结果，不可改选，金额按采购价格计算。销售未审批时，采购仅可预览、不能保存。
- 销售整单调整总干基时，采购须勾选完全相同的车辆，系统自动带入同一总干基及原因，不自行分摊到各车。少选、多选或混选多个整单调整组均提示分开处理；不同单价不能统一调总干基，应逐车或按同价组处理。
- 商业结算数量可以不同于两向共同交付数量；不得为结算方便回改磅单或已确认交付。
- 交付选错：先处理有效结算/资金/发票等下游引用，再撤销交付，调整依据后重新确认。系统保留旧版、新版和原因，不覆盖历史。
- 未有效交付的车单可取消重做。整车拒收须已到达、填写原因并有附件；未到货取消运输使用“取消运单”。
- 直拨改入我方仓库：选择仓库、转运地点和原因，系统生成后续常规采购通知/运单；按后续运单重新到仓、计量质检和入库。销售须重新从库存安排，不会自动完成。
- 有有效下游单据时按提示先处理，不用删除数据来绕过。

## 2026-11-12 补充操作

- **双侧凭证快照**：交付预览、确认记录、小程序直拨页及“直拨进出”的展开记录中，可对照发货/收货采信磅单及报告中的品位、水分。差异为收货净重减发货净重，仅提示，不自动改变采用数量。同侧多张未采信时不擅自取最新一张。确认后保留当时数据，历史记录未保存双侧快照的显示未记录，不用当前资料冒充历史。
- **合作方检测机构**：任务中新增报告选择“合作方”，可选择该合同供应商或客户，不要求额外创建质检服务生态，也不强迫客户具有供应商角色。“第三方”仍须选择已维护的有效质检机构。小程序任务录入与 Web 一致。
- **独立报告**：选择“合作方”时先选择合同筛选出具单位。此时合同仅作机构筛选，不产生报告归属；报告首次关联任务后锁定合同、供方和事业部，全部解除有效关联后释放范围。已作最终依据或被入库、交付使用的报告须先按业务更正流程处理。
- **新单据编号**：执行批次为 `CGDD/XSDD+日期+流水`，通知为 `PI/SD-日期-流水`，运单为 `WB-日期-流水`；直拨采购/销售业务单据为 `ZBCG/ZBXS-日期-流水`。日期取北京时间，与常规建单共用防并发流水；历史编号不变。

## 6. 兼容与试用提醒

历史 DIRECT 不会被自动补配对或补账，需单独核查。普通采购入库、仓储销售出库继续原库存流程；本次不把普通采购的唯一供应商磅单自动当作我方入库依据。关闭质检自动建任务不代表免除最终报告要求。

本地自动化已覆盖主流程和异常；页面视觉、外部打印/导出、安卓/iOS 真机仍需人工试用。暂未向生产部署，也未上传小程序体验版。
