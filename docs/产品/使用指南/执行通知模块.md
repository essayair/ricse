# 执行通知管理 — 使用指南

> ✅ Iteration 6 第一版完成（2026-07-17）

## 功能概述

执行通知承接已确认的合同执行批次：采购方向生成“供应商发货指令”，销售方向生成“销售发货通知单”，并向下拆分物流运单。

## 创建规则

- 一个执行批次可以拆分多张执行通知，累计通知数量不得超过批次数量。
- 采购执行批次只能生成供应商发货指令，编号格式为 `PI-年月日-流水号`。
- 销售执行批次只能生成销售发货通知单，编号格式为 `SD-年月日-流水号`。
- 销售常规出库必须选择发货仓库；直拨业务可以不选择仓库。
- 执行通知一期不设置审批，由有权限的业务人员直接下达。
- 已取消通知释放占用数量；已有有效物流运单的通知不能取消。

## 操作流程

1. 进入「采销管理 → 执行通知」，点击「新建执行通知」。
2. 选择已确认或执行中的合同执行批次。
3. 填写本次通知数量、执行模式、计划日期和起讫地点。
4. 销售常规模式选择发货仓库。
5. 创建后检查通知明细，点击「下达通知」。
6. 已下达通知可以创建一张或多张物流运单。

## 状态

```text
草稿 → 已下达 → 执行中 → 已完成
  └→ 已取消 ←┘
```

第一张物流运单进入“在途”时，通知自动进入“执行中”。所有有效物流运单签收后，通知才能完成。

## 权限与数据范围

- 查看执行通知需要“执行查看”权限；创建、下达、完成、取消和删除需要“执行管理”权限。
- 执行通知通过执行批次继承合同企业范围，候选批次和通知详情执行相同校验。
- 外部企业员工可查看本企业参与合同下由其他员工创建的通知，不可查看无关企业通知。

通用口径见[权限与数据范围规范](../权限与数据范围规范.md)。
