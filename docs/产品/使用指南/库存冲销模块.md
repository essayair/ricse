# 库存冲销模块使用指南

## 1. 功能概述

库存冲销用于纠正已经入账的业务入库或销售出库。系统不删除、不修改原库存台账，而是创建冲销单，经审批后在原库存批次生成方向相反的库存台账，确保全部历史可追溯。

## 2. 冲销与作废的区别

| 场景 | 处理方式 |
|------|----------|
| 业务单据尚未入账 | 作废原单，不生成库存冲销 |
| 业务入库已经形成库存 | 创建入库冲销单，减少原批次库存 |
| 销售出库已经扣减库存 | 创建出库冲销单，恢复原出库使用的库存批次 |

已经入账的原单不得删除或直接修改数量。

## 3. 入库冲销

入库冲销减少原业务入库批次的初始数量和当前可用数量。可冲销数量取以下两者的较小值：

```text
原业务入库数量 − 已冲销及审批中预留数量
当前库存批次可用数量
```

例如业务入库100吨，已经销售出库30吨，批次剩余70吨，则当前最多只能冲销70吨。若需要冲销全部入库，应先冲销相关销售出库。

## 4. 出库冲销

出库冲销严格按照原销售出库明细恢复库存：

```text
原销售出库：
  批次A -20吨
  批次B -10吨

本次冲销15吨：
  批次A +10吨
  批次B +5吨
```

系统不允许把恢复数量增加到其他库存批次。每个批次累计冲销量不能超过该批次原销售出库数量。

## 5. 操作流程

### 5.1 创建冲销单

进入“库存管理 → 库存冲销”，点击“新建冲销单”：

1. 选择“入库冲销”或“出库冲销”。
2. 从可冲销列表选择原业务入库单或销售出库单。
3. 按原库存批次填写本次冲销数量，也可填写最大可冲销量。
4. 填写冲销原因和备注。
5. 创建冲销单。

### 5.2 上传附件

草稿状态可上传业务撤销说明、纠错凭证、现场照片或 PDF。提交审批后附件锁定，只允许查看。

### 5.3 提交、审批和过账

1. 申请人在详情页点击“提交审批”。
2. 系统管理员或审批人审核，可以通过或驳回；驳回原因必填。
3. 审批通过后点击“冲销过账”。
4. 系统再次校验累计冲销量和实时库存。
5. 校验通过后，生成反向库存台账并更新原单状态。

## 6. 状态流转

```text
草稿 → 待审批 → 审批通过 → 已过账
  │       └──> 已驳回
  └──> 已取消
```

原业务入库单和销售出库单根据累计冲销结果变为“已入账”“部分冲销”或“已冲销”。

## 7. 库存台账方向

| 冲销类型 | 库存台账 | 批次处理 |
|----------|----------|----------|
| 入库冲销 | 负数 | 减少原批次初始数量和可用数量 |
| 出库冲销 | 正数 | 恢复原销售出库使用的批次可用数量 |

冲销过账、批次余额更新、原单状态更新和库存台账创建在同一个数据库事务中完成；任一步失败都会整体回滚。

## 8. 权限与注意事项

- 普通用户可以创建、提交和过账审批通过的冲销单。
- 系统管理员和审批人可以审核冲销单；系统管理员可以处理所有冲销审批。
- 审批中的冲销数量会被预留，防止重复申请超出原单数量。
- 已过账冲销单不能直接撤回；如冲销本身有误，应通过新的受控业务进行纠正。
- 已进入结算的原单，后续结算模块需要同步生成结算调整记录。
- 冲销列表、可选原单、详情和附件均继承原业务入库或销售出库的企业范围。
- 外部企业员工可查看本企业关联原单的冲销记录，但创建、提交、审核和过账仍分别受功能权限及角色限制。
- 审核读取有效多角色授权；具有 `APPROVER` 或 `ADMIN` 角色即可审核，系统管理员可处理全部冲销审批。

通用口径见[权限与数据范围规范](../权限与数据范围规范.md)。
