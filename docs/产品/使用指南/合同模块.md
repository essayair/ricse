# 合同管理 — 使用指南

> ✅ Iteration 3 已完成；履约进度板块于 2026-07-17 补充。

## 功能概述

管理采购合同、销售合同的全生命周期，从创建到完成。

合同是履约业务的上游依据，标准单据链路为：

> 合同 → 合同执行批次 → 供应商发货指令/销售发货通知单 → 物流运单 → 磅单/质检单 → 物流出入库单 → 业务出入库单 → 结算单

采购合同生成采购执行批次，销售合同生成销售执行批次；双边合同保留为一份合同，并在合同下分别生成采购执行批次和销售执行批次。完整口径以[单据关系与术语规范](../单据关系与术语规范.md)为准。

## 前置条件

- 已完成主数据配置（供应商、物料等）
- 已启用对应合同类型的审批流程，并为所有启用节点配置有效审批人

## 创建、草稿与提交审批

- 新建页面第一次保存或提交时创建一份草稿合同，同一次新建请求具有唯一标识；网络重试、后续保存和再次提交始终返回或更新同一份草稿，不重复生成合同。
- 点击“提交审批”时，系统先保存合同，再检查对应合同类型的审批流程、金额条件、审批节点和审批人是否有效；检查通过后上传附件并发起审批。
- 审批流程未启用、节点或审批人配置不完整时，合同保留为草稿，并提示“合同已保存为草稿，不会重复创建”。
- 修复审批配置后可继续提交原草稿，无需重新新建合同。
- 审批任务生成与合同进入“待审批”状态在同一事务中完成，任一环节失败都不会留下没有任务的待审批合同。
- 合同创建人或系统管理员可以撤回待审批合同；撤回后未处理审批任务取消，合同回到草稿状态。

## 作废与删除

- 合同不能直接删除，必须先执行“作废”。
- 普通业务用户、业务员、经理和系统管理员可以在允许作废的合同状态下操作作废。
- 待审批合同作废时，当前未处理及等待中的审批任务一并取消。
- 只有系统管理员可以删除已作废合同；普通用户不显示删除入口，接口也会拒绝越权删除。
- 删除采用软删除方式，合同不再出现在业务列表中，但数据库审计记录仍保留。

## 履约进度

合同详情右侧展示“履约进度”板块，用于集中查看合同向下游业务单据的执行情况：

- 按“待执行、执行中、已执行”三个口径展示对应数量和金额；
- 根据有效执行批次状态自动计算总体履约百分比；
- 展示执行批次总数和已完成数量；
- 列出该合同关联的采购执行批次、销售执行批次、金额和状态；
- 点击执行批次号可直接进入具体执行批次详情；
- 已通过或执行中的合同可从该板块直接新建执行批次，并自动带入当前合同；
- 物流运单、出入库执行和结算执行作为后续单据关联入口预留。

已取消执行批次不计入总体履约进度。合同关闭或完成后，总体进度显示为 100%。

履约数量和金额由合同及执行批次实时计算，不人工填写：已完成执行批次计入“已执行”，执行中的执行批次计入“执行中”，合同总量/总额扣除上述两项后的余额计入“待执行”。草稿和已确认批次仍属于待执行范围；已取消批次不占用合同量。双边合同按采购端和销售端分别统计，防止两端执行数据重复累计。

## 权限与数据范围

- 查看、新建、修改、提交、审批、作废和删除分别受合同模块功能权限控制。
- 外部企业员工可查看本企业合作伙伴作为卖方、买方或签约主体的全部合同，不限合同创建人。
- 同一外部企业员工共享企业级合同范围，但修改、提交或作废仍需对应角色权限。
- 合同必须先作废，才能由系统管理员软删除；系统管理员可处理所有当前审批节点。
- 合同附件使用与合同相同的企业范围，不能通过附件接口查看无权合同的文件。

完整规则见[权限与数据范围规范](../权限与数据范围规范.md)。
