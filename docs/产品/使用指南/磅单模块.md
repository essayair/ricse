# 磅单管理 — 使用指南

> ✅ 第一版完成（2026-07-20）

## 功能概述

磅单用于归集一辆车在发货方、收货方形成的多张完整称重凭证，并从中确定库存执行与结算共同采用的净重。磅单必须关联物流运单：发货称重可在运单待发运、在途、到达或签收阶段录入，收货称重需在运单到达后录入。

## 管理层级

```text
物流运单（一条磅单信息）
├── 发货称重：第一张完整磅单、追加完整磅单……
└── 收货称重：第一张完整磅单、追加完整磅单……
    每张完整磅单 └── 多条毛重/皮重记录
```

“磅单管理”列表按物流运单展示，一辆车一行。打开“磅单信息”详情后，可以同时查看供应商/我方发货称重与我方/客户收货称重，再打开某张完整磅单处理内部称重记录、附件和复核。

## 创建磅单

1. 进入「质检影像 → 磅单管理」，点击「新建称重磅单」；也可以从物流运单或磅单信息详情创建。
2. 选择物流运单。系统自动带出执行批次名称、运单编号、车牌、运输数量和采购/销售方向。
3. 结算重量口径默认选择“收货称重”，磅差容差默认 `0.5%`。
4. 如改选发货重量、客户收货重量、第三方重量或手工确认重量，必须填写对应重量。
5. 至少上传一份现场磅单照片、设备导出磅单或扫描件，支持 JPG、PNG、WEBP 和 PDF，单个文件不超过 20 MB。系统兼容手机、扫描软件使用的常见文件类型标识。
6. 确认后系统生成 `PD-年月日-流水号` 格式的磅单编号，并将附件关联到磅单。

创建时系统从物流运单、合同、物料主数据和当前用户自动带出车牌、司机、货物名称、规格型号、发货单位、收货单位及司磅员。操作人员需要核对并补充包/袋数；散装货物填写 `0`。

## 完整磅单字段

磅单列表和详情统一展示：序号、磅单日期、磅单编号、车牌号、货物名称、规格型号、发货单位、收货单位、毛重、皮重、净重、包/袋数、毛重时间、皮重时间、打印时间、司机姓名、司磅员和备注。

- 磅单日期和业务主体信息在创建时保存为快照，不随上游主数据后续修改而变化。
- 毛重时间、皮重时间取当前选定的有效毛重/皮重记录；更换有效记录后时间同步变化。
- 点击“打印磅单”时系统记录最新打印时间，然后打开浏览器打印窗口。

同一物流运单允许在发货、收货两个节点分别维护多张完整磅单。每个节点第二张及以后属于追加磅单，必须填写追加原因；原磅单不会被覆盖。

## 称重与复磅

1. 磅单详情“新增称重记录”默认生成毛重、皮重两条基础录入行。采购入场按“毛重 → 皮重”排列，销售出场按“皮重 → 毛重”排列。
2. 每行填写重量、数据来源、称重时间和备注。首次称重时间默认取打开录入页面时的系统时间，后续称重默认以上一次时间为基准随机增加 30–40 分钟，随机精确到秒；所有默认时间都可以手动修改，并按日期、小时、分钟、秒完整保存，列表和详情固定显示到秒。
3. 基础称重可分阶段保存：只填写并保存当前已经完成的称重，未填写重量的基础行不会提交；再次进入时系统继续提供尚未完成的基础称重。
4. 毛重和皮重均存在后，系统自动计算 `收货净重 = |有效毛重 - 有效皮重|`。
5. 需要复磅时点击“追加称重记录”，选择毛重或皮重并继续录入。每条记录保留序次、来源、时间、操作人和备注，不覆盖历史数据。
6. 新增记录默认成为该类型的最新有效记录。如需采用其他结果，在记录表分别选择有效毛重和有效皮重，点击“保存有效毛重/皮重”。
7. 检查净重、磅差和结算重量无误后点击“完成称重”。

完成称重前，必须同时选择有效毛重和有效皮重，且当前结算口径必须有可用重量。完成后不能再追加复磅或更换有效记录。

磅单详情可以继续补充附件。待称重或称重中的附件可以删除；完成称重后附件作为业务凭证锁定，不可删除。

## 结算重量口径

| 口径 | 使用方式 |
|------|---------|
| 收货称重 | 默认；取本磅单有效毛重和皮重计算出的净重 |
| 发货重量 | 输入发货环节确认重量 |
| 客户收货重量 | 输入客户签收确认重量 |
| 第三方重量 | 输入第三方计量机构确认重量 |
| 手工确认重量 | 输入争议协商或特殊流程最终确认重量 |

切换结算口径不会删除收货净重和其他重量。系统同时保留计划数量、收货净重、磅差、磅差率和最终结算重量，方便追溯。

## 选择结算入库磅单

1. 打开运单级“磅单信息”详情，同时核对发货、收货及追加的完整磅单。
2. 只有状态为“已复核”且存在有效净重的完整磅单可以选用。
3. 点击“选为结算入库磅单”后，系统把同一净重同时同步给库存执行与结算，不能分别选择两张。
4. 首张发货称重磅单复核后，系统会在尚无选择时自动建立默认口径；后续收货或追加磅单不会自动覆盖。
5. 改选其他磅单必须填写原因。若相关入库/出库已经过账，或出库已完成批次拣配，系统禁止更换。

系统仍保留库存、结算两条技术选用记录以兼容下游模块，但它们由一次操作原子生成，磅单编号与数量始终相同。

## 状态与复核

```text
待称重 → 称重中 → 待复核 → 已复核
   └──────────────→ 已作废
```

- 新建后为“待称重”，新增任一称重记录后进入“称重中”。
- 毛重、皮重和结算重量完整后可以完成称重，进入“待复核”。
- 收货净重相对运单计划数量的偏差超过容差时标记“磅差异常”。
- 磅单进入“待复核”后，详情页顶部直接显示复核操作区。磅差异常时该区域以红色边框突出显示，同时展示磅差、偏差率和容差。
- 异常磅单复核必须填写偏差原因、核查过程和处理意见，按钮在意见为空时不可提交；正常磅单的复核意见可选。
- 已复核磅单不能修改结算口径或直接作废。

## 常见问题

- **为什么创建收货磅单时看不到某张运单？** 运单尚未到达；发货称重不受此限制。同一节点已有磅单时仍可追加，但必须填写原因。
- **复磅会覆盖第一次数据吗？** 不会。每次复磅新增记录，只改变默认选择的有效记录。
- **为什么不能完成称重？** 检查是否已有有效毛重、有效皮重，以及所选结算口径是否存在对应重量。
- **选择其他结算重量后还保留净重吗？** 保留。结算口径只决定最终传给结算的重量，不改变现场收货净重。
- **为什么附件选择后不能上传？** 检查扩展名是否为 JPG、JPEG、PNG、WEBP 或 PDF，文件是否为空或超过 20 MB；不符合要求的文件会在创建磅单前直接提示。

## 权限与数据范围

- 查看磅单信息、完整磅单和附件需要“质检磅单查看”权限；创建、称重、复核、作废、附件增删及统一选用结算入库磅单需要“质检磅单管理”权限。
- 磅单通过物流运单逐级继承合同企业范围；可选运单、磅单列表和详情范围保持一致。
- 外部企业员工能查看本企业关联车辆形成的完整磅单及证据附件，不限司磅员或创建人。
- 无权查看上游合同的账号不能通过磅单号或附件 ID 绕过隔离。

通用口径见[权限与数据范围规范](../权限与数据范围规范.md)。
