# 主数据管理 — 使用指南

> 版本：v1.1 | 日期：2026-07-03 | 对应 Iteration 2

## 功能概述

主数据管理是全平台的基础档案中心，包含：
- **合作伙伴**（供应商 / 客户）
- **物料分类与物料**
- **仓库**
- **车辆**

---

## 一、合作伙伴管理

### 1.1 查看合作伙伴列表

进入 **主数据管理 → 合作伙伴** 页面，默认显示所有状态的合作伙伴。

**筛选条件**：
- 角色：全部 / 供应商 / 客户
- 状态：有效 / 停用 / 黑名单
- 搜索：编码、名称、简称、联系人模糊搜索

### 1.2 新建合作伙伴

点击右上角 **「新建合作伙伴」** 按钮，填写以下信息：

**基本信息（必填）**

| 字段 | 说明 |
|------|------|
| 企业名称 | 企业完整法定名称（与营业执照一致） |
| 统一社会信用代码 | 18位信用代码，与名称联合校验唯一性 |
| 业务角色 | 多选：供应商 / 客户（可同时勾选） |
| 单位性质 | 外部单位（编码 6 位数字自动生成）或内部企业（编码 4 位字母数字手动录入） |
| 合作伙伴编码 | 根据单位性质自动确定格式，外部可切换手动指定 |

**补充信息（选填）**

| 字段 | 说明 |
|------|------|
| 简称 / 别名 | 系统内显示的简短名称 |
| 搜索简码 | 拼音首字母，用于快速检索 |
| 法定代表人 | |
| 联系人 / 联系电话 | 主要对接人 |
| 注册地址 / 办公地址 | |
| 主要货源地 | 供应商适用，填写原材料或商品的主要来源地区 |
| 拟合作品种 / 业务 | 与本方预计开展的具体商品或业务类型 |
| 授信额度 | 结算预警用 |
| 纳税人类型 / 发票类型 | 税务信息，影响结算开票 |
| 备注 | |

> **注意**：统一社会信用代码 + 企业名称必须全平台唯一，重复提交将被系统拒绝。

### 1.3 管理银行账户

在合作伙伴详情页，切换到 **「银行账户」** 标签，可添加多个账户：

| 字段 | 说明 |
|------|------|
| 开户名称 | 与合同/发票一致 |
| 银行账号 | |
| 开户行全称 | |
| 联行号 | 用于跨行转账 |
| 账户类型 | 基本户 / 一般户 |
| 是否默认 | 结算时自动带出 |

### 1.4 停用合作伙伴

在列表中点击 **「停用」**，停用后：
- 该合作伙伴不可在新合同/单据中被引用
- 已有历史单据不受影响
- 可随时重新启用

## 二、物料管理

### 2.1 物料分类

先维护物料分类（支持两级），再在分类下建立物料档案。分类名称可按业务需要自由定义。

### 2.2 新建物料

| 字段 | 说明 |
|------|------|
| 物料编码 | 系统自动生成，格式：MATxxxx |
| 品名 | 物料名称 |
| 大类 | 选择已有分类 |
| 计量单位 | 默认：吨 |
| 包装方式 | 散装 / 吨袋 / 小包装等 |
| 规格指标 | 动态添加质量指标行（指标名称 / ≥≤= / 数值 / 单位） |
| HS 编码 | 海关报关用，可选 |
| 税务商品编码 | 增值税发票商品编码，可选 |
| 质检模板 | 关联质检指标模板，入库时自动触发质检任务 |
| 虚拟物料 | 委托加工成品/中间品，不参与实物库存 |

## 常见问题

**Q：一家企业可以同时是供应商和客户吗？**
A：可以。创建时同时勾选供应商和客户两个角色即可，系统内只有一份档案。

**Q：运输公司怎么建档？**
A：将其作为供应商（提供运输服务）建档，在主营业务字段注明货运/运输即可。内部车队若属于集团子公司，选择「内部企业」性质建档。

**Q：合作伙伴编码可以修改吗？**
A：编码一经生效不可修改。内部企业编码由管理员手工确定；外部单位编码由系统自动生成（6位数字），如需手动指定，输入前系统会校验是否已存在。

**Q：物料停用后，历史合同怎么处理？**
A：停用仅影响新建单据，历史已创建的单据中引用的物料信息保持不变。

**Q：外部合作伙伴和内部企业有什么区别？**
A：区别在于编码规则和使用场景。外部单位（供应商/客户）编码为6位数字自动生成；内部企业（集团子公司等）编码为4位字母数字手动录入，主要用作我方合同签约主体。两者都可在合同、单据中被引用。
