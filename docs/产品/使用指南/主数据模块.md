# 主数据管理 — 使用指南

> 版本：v1.1 | 日期：2026-07-03 | 对应 Iteration 2

## 功能概述

主数据管理是全平台的基础档案中心，包含：
- **合作伙伴**（供应商 / 客户）
- **物料分类与物料**
- **仓库**
- **车辆**

---

## 一、合作伙伴管理

### 1.1 查看合作伙伴列表

进入 **主数据管理 → 合作伙伴** 页面，默认显示所有状态的合作伙伴。

**筛选条件**：
- 合作伙伴角色：全部 / 供应商 / 客户
- 状态：有效 / 停用 / 黑名单
- 搜索：编码、名称、简称、联系人模糊搜索

### 1.2 新建合作伙伴

点击右上角 **「新建合作伙伴」** 按钮，填写以下信息：

**基本信息（必填）**

| 字段 | 说明 |
|------|------|
| 企业名称 | 企业完整法定名称（与营业执照一致） |
| 统一社会信用代码 | 18位信用代码，与名称联合校验唯一性 |
| 合作伙伴角色 | 多选：供应商 / 客户（可同时勾选） |
| 单位性质 | 外部单位（编码 8 位数字自动生成）或内部企业（编码 6 位字母数字手动录入） |
| 合作伙伴编码 | 根据单位性质自动确定格式，外部可切换手动指定 |

**补充信息（选填）**

| 字段 | 说明 |
|------|------|
| 简称 / 别名 | 系统内显示的简短名称 |
| 搜索简码 | 拼音首字母，用于快速检索 |
| 法定代表人 | |
| 联系人 / 联系电话 | 主要对接人 |
| 注册地址 / 办公地址 | |
| 主要货源地 | 供应商适用，填写原材料或商品的主要来源地区 |
| 拟合作品种 / 业务 | 与本方预计开展的具体商品或业务类型 |
| 授信额度 | 结算预警用 |
| 纳税人类型 / 发票类型 | 税务信息，影响结算开票 |
| 备注 | |

> **注意**：统一社会信用代码 + 企业名称必须全平台唯一，重复提交将被系统拒绝。

### 1.3 管理银行账户

在合作伙伴详情页，切换到 **「银行账户」** 标签，可添加多个账户：

| 字段 | 说明 |
|------|------|
| 开户名称 | 与合同/发票一致 |
| 银行账号 | |
| 开户行全称 | |
| 联行号 | 用于跨行转账 |
| 账户类型 | 基本户 / 一般户 |
| 是否默认 | 结算时自动带出 |

### 1.4 停用合作伙伴

在列表中点击 **「停用」**，停用后：
- 该合作伙伴不可在新合同/单据中被引用
- 已有历史单据不受影响
- 可随时重新启用

### 1.5 编辑合作伙伴

在详情页点击 **「编辑」**，进入编辑表单。编辑页与新建页面结构一致，便于运营人员按相同逻辑完成修改。

**不可修改字段（创建后锁定，编辑页灰色展示）**

| 字段 | 原因 |
|------|------|
| 合作伙伴编码 | 全平台唯一标识，合同/执行批次/结算均引用 |
| 统一社会信用代码 | 与编码、名称构成防重体系 |
| 内部/外部性质 | 决定编码规则体系 |

**可修改但有限制**

| 字段 | 限制 |
|------|------|
| 企业名称 | 允许修改（企业更名），但 `税号+名称` 联合唯一校验须通过 |
| 合作伙伴角色 | 仅允许追加，禁止移除已有合作伙伴角色（防止执行中合同失去交易方向） |

**可随时修改的运营数据**

基本信息、法人/实控人、工商登记、联系人/地址、税务/发票、特殊资质、业务信息、授信额度、备注 — 全部可在编辑页面直接修改。

**影像附件管理**

编辑页面支持：查看已有附件列表、删除过期附件、追加新文件。

**状态变更**

| 操作 | 校验 |
|------|------|
| 停用 | 系统自动检查无进行中合同，存在则拦截 |
| 加入黑名单 | 二次确认弹窗 |

> **注意**：停用前系统会自动检查是否存在进行中的合同（草稿/待审批/已通过/执行中），如有未完结合同将拒绝停用。

## 二、物料管理

### 2.1 物料分类

先维护物料分类（支持两级），再在分类下建立物料档案。分类名称可按业务需要自由定义。

### 2.2 新建物料

| 字段 | 说明 |
|------|------|
| 商品分类 | 选择已维护的一级或二级分类 |
| 商品名称 | 只读，以所选分类名称为基础，再拼接形态和核心规格 |
| 商品形态 | 精粉、原矿、块矿等 |
| 核心规格 | 指标 + 比较符 + 数值 + 单位，如 `CaF₂≥97%` |
| 包装方式 | 散装、吨袋、500kg吨袋、1吨吨袋等；可不填写重量前缀，直接选“吨袋” |
| 参考类型 | 默认“贸易商品（TRD）”，也可选“原材料（RAW）”、“半成品（SFG）”、“产成品（FGD）”等；只用于编码、统计和检索 |
| 计量单位 | 默认：吨 |
| 物料编码 | 系统自动生成：贸易商品 `TRD`、原材料 `RAW`、半成品 `SFG`、产成品 `FGD`等 + 6 位流水号 |
| 商品名称 | 不手工填写，系统按“所选分类名称 + 形态 + 核心规格”自动拼接，如“萤石精粉-CaF₂≥97%”；包装方式单独显示 |
| 规格标准定义 | 单独板块常驻显示；第一行为核心规格，可追加水分、杂质、粒度等其他指标 |
| HS 编码 | 海关报关用，可选 |
| 税务商品编码 | 增值税发票商品编码，可选 |
| 质检模板 | 关联质检指标模板，入库时自动触发质检任务 |
| 虚拟物料 | 委托加工成品/中间品，不参与实物库存 |

**操作流程**：进入“主数据管理 → 商品物料 → 新建商品物料”，选择分类并填写形态、核心规格、包装等信息，核对系统拼接的商品名称后保存即可。标准商品匹配、查重、标准编码和物料编码均由系统后台完成。

### 2.3 查看商品物料详情

在商品物料列表点击商品名称或“详情”，可查看商品基本信息、物料/平台标准编码、规格标准定义、包装、质检模板、税务编码及创建更新时间。

> 创建后，分类、品名、形态、核心规格、包装和单位不直接修改，防止改变历史合同和库存的商品含义。可继续维护状态、质检模板、HS/税务/内部编码和备注；需要加工后产成品时，可使用“基于此物料创建产成品”快捷入口。

## 四、车辆管理

| 字段 | 说明 |
|------|------|
| 车牌号 | 全平台唯一 |
| 车型 | 自卸车 / 罐车 / 挂车 |
| 品牌型号 | |
| 整备质量（皮重） | 车辆档案参考值，实际业务仍以磅单称重为准 |
| 核定载重（吨） | |
| 车牌颜色 | 黄牌 / 绿牌 / 蓝牌 / 黑牌 / 其他 |
| 归属类型 | 自有（SELF）/ 外协（OUTSOURCED） |
| 所属单位 | 自有车辆可选择内部主体；外协车辆必须选择服务生态中有效的物流承运商 |
| 证件期限 | 行驶证号、年检、交强险和商业险到期日 |
| 实际车主 | 车主姓名和手机号，可与司机不同 |
| 关联司机 | 一名主驾和多名副驾；司机取自所属物流服务商司机档案 |
| 定位设备 | 北斗 / GPS / 暂不绑定，维护终端编号和安装日期 |
| 使用状态 | 启用 / 维修停用 / 已退役；只有启用车辆可用于新调度 |
| 引用运单 | 列表展示车辆已被物流运单引用的数量 |

操作流程：进入“主数据管理 → 车辆管理”，点击“新建车辆”，填写车牌、车型、核定载重及归属信息后保存。车牌号在全平台唯一，系统自动去除空格并转换其中的字母为大写。车辆可按车牌、品牌、司机、手机号或所属单位搜索，也可按归属类型和状态筛选。

车辆列表支持按车牌、司机、承运商、车主、证件或定位设备编号模糊检索，并按归属、承运商、车型和档案状态筛选。“空闲/在途”由有效运单实时计算，不允许人工修改；围栏和定位状态只有接入真实北斗/GPS平台后才展示。

车辆详情提供车辆档案、GPS轨迹占位、历史磅单和运输统计。车辆资料用于提高调度录入效率，不替代运单执行快照。物流运单选择车辆后优先带入该车主驾，也可改选同承运商其他司机或手工填写临时司机；发运后保留当时的车辆、司机和承运单位快照。已有运单引用的车辆不能删除，应根据实际情况改为维修停用或已退役。

## 五、物流司机管理

司机档案按“物流承运商 → 司机”维护。进入“主数据管理 → 服务生态 → 物流承运商”，在承运商行内点击“司机”，可新增和维护司机姓名、手机号、身份证号、驾驶证号、准驾车型、驾驶证有效期、状态及备注。

- 同一物流承运商下司机手机号不得重复。
- 司机列表支持按姓名、手机号、身份证号、驾驶证号和物流服务商模糊搜索。
- 停用司机不会出现在新运单候选项中，历史运单不受影响。
- 已被运单引用的司机不得删除，应改为停用。
- 司机与车辆相互独立；车辆上的默认驾驶员用于快捷回填，运单上的实际司机以本车次调度结果为准。

## 常见问题

**Q：一家企业可以同时是供应商和客户吗？**
A：可以。创建时同时勾选供应商和客户两个角色即可，系统内只有一份档案。

**Q：运输公司怎么建档？**
A：先将运输公司建立为具有供应商角色的合作伙伴，再到“服务生态”创建物流承运商档案。维护外协车辆时从有效物流承运商中选择所属单位；内部车队车辆选择“自有车辆”，并可关联所属内部主体。

**Q：合作伙伴编码可以修改吗？**
A：编码一经生效不可修改。内部企业编码由管理员手工确定；外部单位编码由系统自动生成（8位数字），如需手动指定，输入前系统会校验是否已存在。

**Q：物料停用后，历史合同怎么处理？**
A：停用仅影响新建单据，历史已创建的单据中引用的物料信息保持不变。

**Q：外部合作伙伴和内部企业有什么区别？**
A：区别在于编码规则和使用场景。外部单位（供应商/客户）编码为8位数字自动生成；内部企业（集团子公司等）编码为6位字母数字手动录入，主要用作我方合同签约主体。两者都可在合同、单据中被引用。

## 权限与外部账号边界

- 主数据新增、修改、停用和附件维护属于内部平台管理能力，应由具有主数据管理权限的内部账号执行。
- 外部企业“本企业全部关联数据”指合同及其下游业务单据，不自动包含全平台合作伙伴、银行账户、组织员工等主数据。
- 外部企业专属主数据只读视图尚未完成；外部账号正式开放测试前，不应授予主数据管理权限，并需完成主数据接口范围复核。
- 历史业务单据保存业务发生时的名称快照，主数据权限变化不会改变历史凭证。

统一口径见[权限与数据范围规范](../权限与数据范围规范.md)。
