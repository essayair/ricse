# 主数据管理 — 使用指南

> 版本：v1.0 | 日期：2026-07-03 | 对应 Iteration 2

## 功能概述

主数据管理是全平台的基础档案中心，包含：
- **往来单位**（供应商 / 客户 / 承运商 / 内部企业）
- **物料分类与物料**
- **仓库**
- **车辆**

---

## 一、往来单位管理

### 1.1 查看往来单位列表

进入 **主数据管理 → 往来单位** 页面，默认显示所有状态的往来单位。

**筛选条件**：
- 角色：全部 / 供应商 / 客户 / 承运商 / 内部企业
- 状态：有效 / 停用 / 黑名单
- 搜索：编码、名称、简称、联系人模糊搜索

### 1.2 新建往来单位

点击右上角 **「新建往来单位」** 按钮，填写以下信息：

**基本信息（必填）**

| 字段 | 说明 |
|------|------|
| 企业名称 | 企业完整法定名称 |
| 统一社会信用代码 | 18位信用代码，与名称联合校验唯一性 |
| 角色 | 多选：供应商 / 客户 / 承运商 / 内部企业 |
| 合作伙伴编码 | 内部企业：手工录入 4 位字母数字；外部企业：系统自动生成 6 位数字，可切换手动 |

**补充信息（选填）**

| 字段 | 说明 |
|------|------|
| 简称 | 系统内显示的简短名称 |
| 法定代表人 | |
| 联系人 / 联系电话 | 主要对接人 |
| 注册地址 / 经营地址 | |
| 货源地 | 供应商适用，如"金华"、"武义" |
| 授信额度 | 结算预警用 |
| 备注 | |

> **注意**：统一社会信用代码 + 企业名称必须全平台唯一，重复提交将被系统拒绝。

### 1.3 管理银行账户

在往来单位详情页，切换到 **「银行账户」** 标签，可添加多个账户：

| 字段 | 说明 |
|------|------|
| 开户名称 | 与合同/发票一致 |
| 银行账号 | |
| 开户行全称 | |
| 联行号 | 用于跨行转账 |
| 账户类型 | 基本户 / 一般户 |
| 是否默认 | 结算时自动带出 |

### 1.4 停用往来单位

在列表中点击 **「停用」**，停用后：
- 该往来单位不可在新合同/单据中被引用
- 已有历史单据不受影响
- 可随时重新启用

## 二、物料管理

### 2.1 物料分类

先维护物料分类（两级），再在分类下建立物料：

```
萤石粉
  ├── CaF₂≥97%（物料档案）
  └── CaF₂≥95%（物料档案）
萤石块矿
  └── CaF₂≥85%（物料档案）
萤石砂
  └── CaF₂≥90%（物料档案）
```

### 2.2 新建物料

| 字段 | 说明 |
|------|------|
| 物料编码 | 系统自动生成，格式：MT-xxxxxx |
| 品名 | 物料名称 |
| 分类 | 选择已有分类 |
| 品级 | 质量等级描述，如"CaF₂≥97%" |
| 计量单位 | 默认 TON（吨） |
| 规格 | 粒度等参数，如"-200目" |
| 产地 | 主要来源地 |
| 包装方式 | 散装 / 吨袋 / 小包装 |

## 常见问题

**Q：一家企业可以同时是供应商和客户吗？**
A：可以。创建时同时勾选 SUPPLIER 和 CUSTOMER 两个角色即可，系统内只有一份档案。

**Q：往来单位编码可以修改吗？**
A：编码一经生效不可修改。内部企业编码由管理员手工确定；外部企业编码由系统自动生成（6位数字），如需手动指定，输入前系统会校验是否已存在。

**Q：物料停用后，历史合同怎么处理？**
A：停用仅影响新建单据，历史已创建的单据中引用的物料信息保持不变。

**Q：车辆归属外协承运商，承运商需要先建好吗？**
A：是的，需要先在往来单位中建立角色为 CARRIER 的承运商档案，再在车辆中关联。
