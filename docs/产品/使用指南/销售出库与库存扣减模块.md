# 销售出库与库存扣减使用指南

## 1. 功能概述

销售出库模块承接销售发货通知和待发运物流运单，完成出库过磅、库存批次拣配、物流离场确认、销售出库入账及库存扣减。

## 2. 前置条件

- 销售执行批次已生成并下达“销售发货通知单”。
- 常规出库的销售发货通知单已经选择发货仓库。
- 已创建待发运物流运单并完成车辆、司机信息。
- 待发运销售运单已经创建出库磅单，且磅单状态为“已复核”。
- 发货仓库存在对应物料的可用库存批次。

一期销售出库支持常规仓库出库和单一物料运单；直拨业务、多物料混装在后续迭代处理。

## 3. 标准操作流程

### 3.1 创建出库磅单

进入“质检影像 → 磅单管理”，从待发运销售运单创建磅单。系统自动将方向设为“出库”。完成毛重、皮重、有效记录、附件和异常复核后，磅单进入“已复核”。

### 3.2 创建物流出库单

进入“库存管理 → 出库单管理”，点击“新建物流出库单”：

1. 选择待发运的销售常规运单。
2. 选择该运单已经复核的出库磅单。
3. 填写离场时间、出库操作人和备注。
4. 按库存批次填写本次分配数量，或点击“按入库时间自动分配”。
5. 分配数量合计必须等于出库磅单结算重量。
6. 保存后进入物流出库单详情。

### 3.3 上传出库附件

草稿状态可上传装车照片、门岗放行凭证或 PDF：

- 支持 JPG、PNG、WEBP、PDF。
- 单个文件不超过 20MB。
- 草稿状态支持增删；确认货物离场后锁定，只允许查看。

### 3.4 确认离场并扣减库存

1. 核对物流、磅单、仓库、客户、库存批次和附件。
2. 点击“确认货物离场”。
3. 点击“生成销售出库并扣减库存”。
4. 系统在一个事务中生成销售出库单、逐批次扣减库存并写入出库台账。
5. 完成库存扣减后，物流运单才允许确认发运。

## 4. 状态流转

```text
草稿 ──确认货物离场──> 已确认离场 ──生成销售出库并扣减库存──> 已扣减库存
  └──作废──> 已作废
```

- 草稿：可上传/删除附件，可作废。
- 已确认离场：批次分配和附件锁定，等待库存扣减。
- 已扣减库存：销售出库单和库存负数台账已经形成。
- 已作废：不占用库存，同一运单可重新创建。

## 5. 库存分配规则

- 只能选择销售发货通知指定仓库中的同物料库存。
- 只能选择状态为“可用”且可用数量大于零的批次。
- 自动分配按入库时间从早到晚执行，方便落实先进先出。
- 后端在扣减时再次校验库存；发生并发占用时整单回滚，不会部分扣减。
- 可用数量扣完后，库存批次自动变为“已耗尽”。

## 6. 常见问题

- 看不到销售运单：检查运单是否仍为待发运、是否为常规销售出库，以及出库磅单是否已复核。
- 看不到库存批次：检查发货仓库、物料和库存批次可用数量。
- 无法确认物流发运：必须先完成销售出库入账和库存扣减。
- 提示库存不足：库存可能被其他出库操作先行扣减，请重新创建或调整批次。
