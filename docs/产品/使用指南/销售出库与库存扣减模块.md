# 出库管理与销售出库使用指南

## 1. 自动生成规则

1. 销售发货通知处于草稿时，不冻结库存，也不生成出库管理单。
2. 下达销售发货通知后，系统自动生成一张管理单：常规出库编号为 `OOM-`，直拨发运编号为 `DFM-`。
3. 常规模式按发货仓库和物料冻结当前可用库存；库存不足不会阻止下达，而是显示已冻结数量和库存缺口。
4. 直拨模式不经过我方仓库，不冻结或扣减我方库存；占位单先用于跟踪物流、磅单、质检和签收。
5. 常规模式创建物流运单后，系统自动在管理单下生成一条车次出库作业；一张通知可以对应多辆车。

## 2. 标准测试与操作流程

### 2.1 下达通知并检查冻结

1. 创建销售执行批次和销售发货通知，常规模式必须选择发货仓库。
2. 将通知从“草稿”下达。
3. 进入“库存管理 → 出库管理”，应看到自动生成的 `OOM-` 出库管理单。
4. 核对通知数量、待出库冻结、库存缺口和物料明细。
5. 打开“在库总览”，确认账面库存不变、待出库冻结增加、可用库存相应减少。
6. 如果后续有新库存入账，可在管理单点击“刷新库存预留”。

### 2.2 创建物流和磅单

1. 从销售发货通知创建一张或多张物流运单；每张运单会自动形成 `OWO-` 车次作业。
2. 进入磅单新建页，可先选择销售发货通知筛选车次，再选择具体物流运单。
3. 在“发货称重”节点创建我方出库磅单，默认先皮重、后毛重；完成称重、附件和复核。客户收货后可在“收货称重”节点补录客户磅单。
4. 待称重或称重中的磅单可在详情“关联业务 → 调整运单”修改；复核后锁定。
5. 质检单不是出库必填项；如果创建，出库管理单会随磅单展示质检编号和结论。

### 2.3 拣配和差异处理

1. 磅单复核后，管理单车次显示“拣配库存”。
2. 进入车次作业，选择运单当前“入出库有效”的已复核发货磅单，并按先进先出自动分配，或手工调整批次。
3. 分配合计必须等于该磅单有效净重；若需改选整张磅单，先在物流运单详情填写原因并完成选用变更。
4. 实际重量在容差内时，保存后进入“待放行”。
5. 超出容差时进入“待差异处理”：短装选择“剩余后续补发”或“本车差额关闭”；溢装选择“确认溢装并按实际出库”，所有处理都必须填写原因。

### 2.4 确认放行

点击“确认放行”后，系统一次完成：

- 按实际重量生成销售出库单；
- 按选择批次扣减库存并写负数台账；
- 更新出库管理单累计实际数量；
- 将物流运单更新为在途并记录实际发运时间；
- 将销售发货通知更新为执行中。

已正式出库的数据不能删除或修改数量，错误必须通过库存冲销处理。

### 2.5 直拨发运占位流程

1. 创建销售直拨通知并下达，进入“库存管理 → 出库单管理”，应看到 `DFM-` 直拨发运管理单。
2. 页面显示“直拨，不经过我方仓库”，冻结数量和库存缺口均不适用。
3. 创建关联通知的物流运单后，管理单自动展示车牌、运单状态、磅单、质检单和签收进度。
4. 当前版本不在直拨管理单中生成我方入库、出库、库存批次或库存台账；上下游通知绑定和独立结算口径留待后续完善。

## 3. 状态说明

- 待物流安排：通知已下达，尚无物流运单。
- 库存不足：通知计划数量尚未完全冻结。
- 待出库称重：已有车次，尚无已复核磅单。
- 待批次拣配：磅单已复核，尚未完成库存分配。
- 待差异处理：实际重量超过容差或通知剩余额度。
- 待放行：所有前置条件已经满足。
- 部分出库：已有车辆放行，还有剩余任务。
- 已完成：通知和全部车次履约完成。
- 直拨待物流/待发运/运输中/待完成：按直拨物流运单的创建、发运、运输和签收状态计算。

## 4. 关键口径

```text
账面库存：仓库实际尚未出库的数量
待出库冻结：已下达销售通知占用但尚未正式扣减的数量
可用库存：账面库存减去待出库冻结
```

- 冻结不产生库存台账，放行后才扣减账面库存。
- 通知计划、运单计划、冻结数量和实际出库分别保存，实际称重不会覆盖上游计划。
- 库存不足不能通过差异确认绕过，也不允许生成负库存。

## 5. 常见问题

- 看不到管理单：确认销售发货通知已经下达；常规模式还必须选择发货仓库。
- 看不到车次：确认物流运单关联的是该销售发货通知。
- 看不到“拣配库存”：出库磅单必须已复核且运单仍待发运。
- 库存缺口一直存在：先确认新库存已经正式入账，再点击“刷新库存预留”。
- 无法放行：检查磅单、差异处理、批次分配和物理库存是否全部满足。
