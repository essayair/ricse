## 使用指南文档模板

每个模块文档包含以下内容：

### 1. 功能概述
一句话说明这个模块做什么，业务价值是什么。

### 2. 前置条件
使用前需要先完成哪些配置（如：先配好主数据才能创建合同）。

### 3. 操作步骤
按操作顺序列出典型业务流程，包含：
- 每个步骤的操作位置（左侧菜单 → 哪个页面）
- 表单字段说明（哪些必填、哪些自动生成）
- 按钮和交互行为

### 4. 状态与流转
如果模块涉及状态机，用图示或表格说明状态如何流转，各状态下可执行哪些操作。

### 5. 常见问题
常见操作误区和注意事项。
