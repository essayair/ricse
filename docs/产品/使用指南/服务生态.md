# 服务生态 — 使用指南

## 功能定位

服务生态用于提前维护物流承运商、质检机构、仓储与港口服务商和加工服务商。专业档案不重复建立企业主体，而是关联一条已存在的合作伙伴档案。

外部服务机构对应的合作伙伴必须具备“供应商”合作伙伴角色，以便后续运费、检测费、仓储费等进入应付结算。

## 维护入口

进入“主数据管理”，可以分别访问：

- 物流承运商
- 质检机构
- 仓储与港口
- 加工服务商

新增专业档案时，先选择有效状态且具备供应商角色的合作伙伴，再补充专业资质和服务能力。同一合作伙伴可以分别建立多类专业档案，但同一专业类型只能建立一条有效档案。

## 物流承运商

维护道路运输许可证、资质有效期、运输方式、承运货物、服务区域、调度联系人、保险和结算方式。第三方物流运单必须从有效物流承运商中选择，不能再自由填写承运单位。

## 质检机构

维护机构资质、CMA、CNAS、支持物料、检测项目、服务区域和报告周期。合作方或第三方质检单必须从有效质检机构中选择；我方和其他检测机构仍可按机构类型记录。

## 仓储与港口

维护运营类型、仓储能力、支持货物、服务区域和结算方式。新建或编辑租赁仓库时，必须选择有效的仓储与港口服务商。

## 加工服务商

维护加工能力、支持物料、服务范围、产能、资质和结算方式。委外生产任务必须选择有效的加工服务商；生产任务保存服务生态档案关联，后续加工费应付仍以其统一供应商合作伙伴作为往来主体。

## 停用规则

专业档案支持有效、停用和黑名单状态。停用或黑名单档案不会出现在新业务单据的选择列表中；历史运单、质检单和仓库仍保留合作伙伴 ID 与业务发生时的名称。

## 权限与外部账号边界

- 服务生态档案的新增、修改和停用属于内部平台主数据管理能力。
- 物流承运商、质检机构或仓储服务商的专业身份本身不会自动赋予合同和业务单据查看权限。
- 当前外部企业业务范围以合同卖方、买方或签约主体为根；未来开放服务商门户时，需增加业务参与方映射及价格等敏感字段权限。
- 外部账号正式开放前，不应授予服务生态维护权限。

统一口径见[权限与数据范围规范](../权限与数据范围规范.md)。
