# 质检管理 — 使用指南

> ✅ 任务、标准与现场影像第一阶段完成（2026-08-27）

## 功能概述

执行通知已配置质检时，物流运单确认到达或送达后，系统自动生成一条质检任务。列表一行代表一辆车的一次质检，任务详情内可以录入一家或多家检测机构的独立报告，并在实际有效报告基础上形成一个最终质检结论。

采购入库会展示任务级质检最终结论、异常指标和人工验收提示；异常不自动禁止入库，现场及业务人员须依据合同与实际情况确认是否入库。销售交付质检按合同或执行通知选配，不作为销售出库放行和库存扣减的强制条件。

## 操作流程

1. 物流人员在运单详情确认到达或送达；执行通知已勾选质检时，系统自动生成质检任务，初始状态为“待取样”。采购业务应保持质检选项开启，取消勾选只会停止自动建任务，并不能绕过入库质量校验。
2. 进入「磅单质检 → 质检管理」，打开对应质检任务，在“取样与送检登记及现场影像”板块新增第一份样品。系统默认生成任务内唯一的样品编号，也允许填写样品标签、封签编号、取样人、取样方法、送检机构、送检时间和备注。
3. 在该样品行内上传或拍摄取样、混样、分样、封样等现场照片。每张照片直接归属当前样品，不再与其他样品共用一组任务级照片。完成一份样品后，可点击“增加一份样品”继续登记，样品数量不固定。
4. 磅单完成称重或复核后，在“机构检测报告”板块点击“添加检测报告”，先选择一份已登记样品。系统只列出当前质检任务对应物流运单下的有效磅单，并按“当前执行磅单 → 已复核发货磅单 → 其他有效磅单”顺序默认选择；用户仍可在本运单的发货、收货磅单间切换。随后系统按物料解析质检模板，带出指标、阈值及允许的检测方法。
5. 填写该样品对应的检测机构、报告编号、检测时间和实测值，并上传该机构的检测报告附件。报告保存样品关联，任务详情可由样品追溯现场照片和机构报告。
6. 返回任务详情，对每份已出报告执行“确认报告有效”。
7. 至少存在一份有效报告后，为当前车辆任务选择一份作为最终判定依据，确认形成最终结论。入库取当前任务对应车辆的我方实物磅单和该依据报告；商业结算另按合同和最终确认的结算证据办理。

### 先录报告、后关联车辆；混样跨车共用

在「磅单质检 → 检测报告」进入独立报告列表，可先录入物料、混样编号、样品编号、机构、取样/检测时间和实测指标，上传该机构报告附件。报告保存后，从报告详情搜索实际参与混样的车辆质检任务并逐项关联；也可在「磅单质检 → 质检管理」的任务详情搜索现有报告。

一份报告可关联多辆车，同车也可关联多份报告。首次关联将报告限定为该任务的合同、供方、事业部和物料；之后不得跨上述范围引用。首次关联可以解除，所有有效关联都解除后才释放归属范围，关联历史保留。若某任务已把报告作为最终判定依据，或该车入库单已引用报告，则不能直接解除，须先办理下游更正。每辆车即使共用一份混样报告，称重数量仍取自己的磅单，不把混样重量重复算给每辆车。

计划报告数默认 1，可根据合同及风险要求调整为 2 份、3 份或更多。最终判定仅有一份有效报告（即使计划数也是 1），或者有效报告少于计划数量时，必须填写判定原因；系统会直接显示原因输入框，并提示缺少平行检测对比的风险后要求二次确认。

## 名称口径

| 名称 | 含义 |
|------|------|
| 到货质检任务 | 一次到货的完整质检业务容器，管理列表中的一行 |
| 独立样品 | 任务下实际分出的一个送检样或留样，拥有独立编号、标签、登记信息和现场影像 |
| 机构检测报告 | 一家检测机构对一个样品出具的一份具体报告 |
| 最终质检结论 | 综合实际有效报告形成的任务级业务结论 |
| 执行口径报告 | 为入库扣水扣杂及结算提供具体数值的一份已确认报告 |

传统单车路径为“质检任务 → 多份独立样品 → 各样品现场影像与机构检测报告”；混样路径为“独立检测报告 ↔ 多辆车的质检任务”，两条路径使用同一套报告数据，不复制报告。传统单车报告可以关联本运单已完成/复核的磅单；独立报告不强制归属某一辆车的磅单。

## 状态说明

```text
待取样 → 待送检 → 检测中 → 待综合判定 → 已完成
                                   └→ 新增报告后待复判
任一阶段可进入异常处理中；作废后终止
```

机构报告自身仍有“已出报告、已确认、已作废”等状态。确认机构报告只表示该份报告有效，不会直接形成库存；任务最终判定后才会把质量依据传到相应入库作业单，异常需要人工复核。

## 附件与追溯

- 新增现场影像按具体样品归档，并细分为取样、混样、分样、封样和其他节点；系统保存影像来源、拍摄/上传时间、上传人、文件 SHA-256 和水印文本快照。
- 升级前已存在的任务级现场影像作为“历史未归属样品影像”保留，可继续查看，不会因数据模型升级丢失。
- 小程序拍摄来源标记为“MINI_PROGRAM_CAPTURE”；Web 端可选择第三方水印相机、系统导入、外部影像或普通电脑上传。
- 第一阶段以任务关联、来源标记和文件校验完成证据留痕；外部水印照片原样保存，不伪造其原始水印。
- 每份机构检测报告可单独上传附件，支持 JPG、JPEG、PNG、WEBP 和 PDF，单个文件不超过 20 MB。
- 附件在当前页面预览，不打开新标签页。
- 任务详情同时显示合同、执行批次、物流运单、磅单和入库作业单入口。
- 系统记录报告录入人、确认人、任务处理人、最终判定人、判定时间及版本。

## 权限

当前采用轻量权限：拥有“质检管理”权限的人员可以完成样品新增、修改、删除、样品影像维护、报告维护、报告确认和最终判定，不再拆分多个质检岗位角色。已经关联有效检测报告的样品不能直接删除；应先作废填错的报告，再处理样品。只有查看权限的人员可以查看任务、样品、报告和附件，但不能执行操作。

## 质检标准维护

入口为「主数据管理 → 质检标准」，包含三类可配置主数据：

- 检测指标：如 CaF₂、水分、SiO₂、粒度，维护编码、名称、符号、默认单位和精度。
- 检测方法：如化学滴定法、XRF、烘干法、筛分法，维护方法编码、标准编号和版本。
- 质检模板：按业务场景和物料分类组合指标、判定符、标准值、拒收值及默认检测方法。

指标与方法是多对多关系，但模板中的每个指标只能选择已关联的方法。物料可直接绑定一个模板；未绑定时系统按物料分类和采购/销售场景解析默认模板。用户在某物料下选过检测方法后，系统下次优先带出该选择。
