# 质检管理 — 使用指南

> ✅ 任务、标准与现场影像第一阶段完成（2026-08-27）

## 功能概述

物流运单确认到达后，系统自动生成一条“到货质检任务”。列表一行代表一辆车的一次到货质检，任务详情内可以录入一家或多家检测机构的独立报告，并在实际有效报告基础上形成一个最终质检结论。

## 操作流程

1. 物流人员在运单详情确认到达，系统自动生成质检任务，初始状态为“待取样”。
2. 进入「质检影像 → 质检管理」，打开对应质检任务；登记取样时间、取样人、取样方法和计划报告数。
3. 在 Web 端上传第三方水印相机/普通相机影像，或由已绑定后台账号的小程序用户在现场选择节点并调用相机拍摄。
4. 磅单完成称重或复核后，点击“追加检测报告”。系统按物料解析质检模板，带出指标、阈值及允许的检测方法。
5. 填写样品编号、检测机构、报告编号、检测时间和实测值，并上传该机构的检测报告附件。
6. 返回任务详情，对每份已出报告执行“确认报告有效”。
7. 至少存在一份有效报告后，选择一份作为入库和结算执行口径，确认形成最终结论。

计划报告数默认 1，可根据合同及风险要求调整为 2 份、3 份或更多。有效报告少于计划数量时，必须填写提前判定原因；系统会提示缺少平行检测对比的风险并要求二次确认。

## 名称口径

| 名称 | 含义 |
|------|------|
| 到货质检任务 | 一次到货的完整质检业务容器，管理列表中的一行 |
| 机构检测报告 | 一家检测机构对一个样品出具的一份具体报告 |
| 最终质检结论 | 综合实际有效报告形成的任务级业务结论 |
| 执行口径报告 | 为入库扣水扣杂及结算提供具体数值的一份已确认报告 |

## 状态说明

```text
待取样 → 待送检 → 检测中 → 待综合判定 → 已完成
                                   └→ 新增报告后待复判
任一阶段可进入异常处理中；作废后终止
```

机构报告自身仍有“已出报告、已确认、已作废”等状态。确认机构报告只表示该份报告有效，不会直接形成库存；只有任务级最终结论为“合格”后，系统才会补齐入库作业依据。

## 附件与追溯

- 任务级现场影像按取样、混样、分样、封样和其他节点归档，保存影像来源、拍摄/上传时间、上传人、文件 SHA-256 和水印文本快照。
- 小程序拍摄来源标记为“MINI_PROGRAM_CAPTURE”；Web 端可选择第三方水印相机、系统导入、外部影像或普通电脑上传。
- 第一阶段以任务关联、来源标记和文件校验完成证据留痕；外部水印照片原样保存，不伪造其原始水印。
- 每份机构检测报告可单独上传附件，支持 JPG、JPEG、PNG、WEBP 和 PDF，单个文件不超过 20 MB。
- 附件在当前页面预览，不打开新标签页。
- 任务详情同时显示合同、执行批次、物流运单、磅单和入库作业单入口。
- 系统记录报告录入人、确认人、任务处理人、最终判定人、判定时间及版本。

## 权限

当前采用轻量权限：拥有“质检管理”权限的人员可以完成取样信息录入、报告维护、报告确认和最终判定，不再拆分多个质检岗位角色。只有查看权限的人员可以查看任务、报告和附件，但不能执行操作。

## 质检标准维护

入口为「主数据管理 → 质检标准」，包含三类可配置主数据：

- 检测指标：如 CaF₂、水分、SiO₂、粒度，维护编码、名称、符号、默认单位和精度。
- 检测方法：如化学滴定法、XRF、烘干法、筛分法，维护方法编码、标准编号和版本。
- 质检模板：按业务场景和物料分类组合指标、判定符、标准值、熔断值及默认检测方法。

指标与方法是多对多关系，但模板中的每个指标只能选择已关联的方法。物料可直接绑定一个模板；未绑定时系统按物料分类和采购/销售场景解析默认模板。用户在某物料下选过检测方法后，系统下次优先带出该选择。
