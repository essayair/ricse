# 公司试运行岗位个人操作手册

> 文档状态：试运行版
>
> 编制日期：2026年9月21日
>
> 适用对象：参与采购、销售、物流、过磅、质检、出入库和结算工作的公司员工
>
> 使用目的：员工先确认“我是谁、我的岗位是什么”，再按岗位查看自己在系统中要做什么、操作前需要什么、操作后产生什么，以及下一步交给谁。

## 一、怎么使用这份手册

1. 先在“人员岗位速查表”找到自己的姓名；
2. 确认自己的公司岗位、系统角色和业务单元（事业部）；
3. 打开对应的“岗位操作卡”；
4. 操作前先检查前置条件，不满足时不要提前点击完成；
5. 操作完成后检查系统产生的单据、状态和待办，并通知下一岗位接续处理；
6. 一个人承担多个岗位时，应分别完成对应操作，系统会记录每次操作的账号、时间和结果。

本文只使用面向员工的中文岗位和角色名称。

## 三、共同业务链路：我处在什么位置

### 3.1 采购业务

```text
业务责任人确认商务条件
  → 采销业务员创建合同
  → 运营经理、风控/财务经理、业务责任人、总经理依次审批
  → 采销业务员创建执行批次和采购执行通知
  → 物流运营询价、建运单、调度并跟踪到达
  → 地磅质检人员完成过磅、取样、检测和质量判定
  → 仓储库管确认收货并入库过账
  → 物流运营整理运费结算
  → 财务人员核对采购应付、发票和付款（完整线上功能待开发）
```

### 3.2 销售业务

```text
业务责任人确认商务条件
  → 采销业务员创建合同并完成四级审批
  → 采销业务员创建执行批次和销售发货通知
  → 系统生成出库管理单并冻结库存
  → 物流运营建运单并调度车辆
  → 地磅质检人员完成我方发货称重
  → 仓储库管完成批次拣配、差异处理和放行
  → 物流运营跟踪送达、客户签收并上传凭证
  → 财务人员核对销售应收、发票和回款（完整线上功能待开发）
```

### 3.3 每个人都要遵守的规则

- 使用本人账号，不共用账号；
- 只能处理本人所属业务单元及角色权限范围内的数据；
- 线下动作真实发生后，再更新线上状态；
- 操作前确认上一步已完成，不能为了赶进度提前点击；
- 填错后使用编辑、驳回、作废或冲销等正规方式修改，不重复创建单据掩盖错误；
- 上传的合同、磅单、检测报告、签收单和现场照片必须与当前业务单据一致；
- 操作完成后主动通知下一岗位，不能只改状态不交接。

## 四、岗位操作卡：采销业务员（黄蕾）

### 4.1 我是谁

我是合同建档和合同执行安排人员。商务人员确定交易条件后，由我把线下约定转为系统合同；合同审批通过后，由我把合同拆成可以实际履约的执行批次和执行通知。

### 4.2 我主要操作哪些功能

| 功能模块 | 模块概念 | 我操作前需要什么 | 我操作后产生什么 | 下一岗位 |
|---|---|---|---|---|
| 合同管理 | 采购、销售或双边交易的正式业务源头 | 商务条件已确定；业务单元、部门、我方主体、合作伙伴和物料已维护；合同资料已收齐 | 合同草稿或待审批合同、合同附件、审批任务 | 运营经理及后续审批人 |
| 执行批次 | 将一份合同拆成若干次具体履约计划 | 合同已审批通过并有待执行数量/金额 | 执行批次，记录本批数量、金额和计划日期 | 仍由采销业务员继续下达通知 |
| 执行通知 | 对某一次采购发货或销售发货作出执行安排 | 已有执行批次；起运地、目的地、地址联系人、运输和质检要求已明确 | 采购通知供物流建运单；销售通知还会自动生成出库管理单并冻结库存 | 物流运营；销售同时交仓储库管关注待出库 |
| 履约跟踪 | 从合同查看执行、物流、过磅、质检和出入库进度 | 下游已经产生业务数据 | 合同履约状态和异常跟进记录 | 业务责任人、物流、仓储或财务 |

### 4.3 合同具体怎么操作

1. 进入「采销管理→合同管理」；
2. 点击“新建合同”，选择采购、销售或双边合同；
3. 先填写内部信息：业务单元（事业部）、业务部门；
4. 填写合同标题和外部合同号；
5. 选择我方签约主体和交易对手方；
6. 填写物料、数量、价格、日期、结算方式、收发货约定等；
7. 上传合同原件及相关附件；
8. 暂未完成时保存草稿；确认完整后提交审批；
9. 提交成功后检查合同状态是否变为待审批，审批任务是否已生成。

**前置不满足时**：缺少主数据先联系系统管理员维护；合同资料不完整时保存草稿，不要提交空合同。

### 4.4 执行批次和执行通知怎么操作

1. 打开已生效合同详情；
2. 点击“新建执行批次”；
3. 填写批次名称、本次计划数量、金额和计划发货日期；
4. 保存后进入执行通知；
5. 选择采购或销售业务，填写起运地点、目的地、联系人、运输方式和质检要求；
6. 地址既可以从仓库、我方主体或合作伙伴地址选择，也允许直接录入实际新地址；
7. 核对数量不超过合同和批次剩余可执行量；
8. 下达通知并通知物流人员接单。

**我完成后的检查**：采购通知应能创建物流运单；销售通知应自动出现出库管理单和待出库库存。

## 五、岗位操作卡：运营经理、风控/财务经理（黄蕾、王静）

### 5.1 我是谁

- 运营经理负责第一级审批，重点检查合同资料是否完整、履约安排是否清楚；
- 风控/财务经理负责第二级审批，重点检查价格、账期、税务、付款、结算和资金风险。

### 5.2 合同审批是什么

合同审批是合同生效前的内部控制。当前顺序为：

```text
运营经理 → 风控/财务经理 → 业务责任人 → 总经理
```

前一节点通过后，系统才会把任务交给下一节点。审批被驳回后，合同返回修改，不能继续履约。

### 5.3 我操作前需要什么

- 合同已经由采销业务员提交；
- 合同正文、价格、数量、合作伙伴、物料和附件可以正常查看；
- 当前审批任务确实到达本人节点；
- 本人属于合同业务单元，并拥有相应审批角色。

### 5.4 具体怎么操作

1. 从小程序工作台“合同待审批”或Web合同详情打开任务；
2. 查看合同基本信息、货物价格、交付结算条款和附件；
3. 查看前序审批意见；
4. 发现问题时，在审批意见中明确写出需修改内容并驳回；
5. 确认无误时填写审批意见并通过；
6. 返回列表检查本人任务已完成、合同已进入下一节点。

### 5.5 我操作后产生什么

- 通过：形成本人审批记录并生成下一节点待办；
- 驳回：形成驳回意见，合同交回采销业务员修改；
- 或签节点由一人处理后，其他同节点人员显示“他人已审批”或“他人已驳回”。

**下一岗位**：运营经理通过后交风控/财务经理；风控/财务经理通过后交业务责任人。

> 当前黄蕾同时承担合同创建和运营经理第一级审批。系统可以按两个角色执行，但公司应在试运行期间确认是否需要实行“制单人与第一级审批人分离”。

## 六、岗位操作卡：业务责任人（陈飞祥、杨宇豪）

### 6.1 我是谁

我是某一业务单元经营结果的责任人，负责确定是否做这笔业务，并对利润、风险和履约结果负责。我不是日常录单人员，但需要查看完整业务依据并完成第三级合同审批。

### 6.2 我主要操作哪些功能

| 功能 | 操作前需要什么 | 怎么操作 | 操作后产生什么 | 下一岗位 |
|---|---|---|---|---|
| 商务条件确认 | 已获得供应、客户、价格、数量、物流和资金条件 | 线下完成谈判；在系统查看历史合同、库存和履约数据 | 完整的合同建档资料 | 采销业务员 |
| 合同第三级审批 | 运营经理和风控/财务经理均已通过 | 查看合同、前序意见和经营风险，填写意见并通过或驳回 | 业务责任审批记录 | 总经理或采销业务员修改 |
| 履约查看 | 合同已经生效并产生执行数据 | 从合同详情查看执行批次、物流、磅单、质检、库存和结算进度 | 异常协调意见或经营决策 | 对应运营、物流、仓储或财务岗位 |

### 6.3 注意事项

- 只审批本人负责业务单元的合同；
- 若同时属于多个业务单元，数据查看和审批仍按每个单元的角色授权判断；
- 发现利润、回款、履约或质量风险时应写明具体原因，不使用“不同意”等无法执行的模糊意见；
- 合同通过后仍需关注履约，不把“审批完成”等同于“业务完成”。

## 七、岗位操作卡：总经理（杨永清）

### 7.1 我是谁

我是合同最终审批人，基于前三级意见作出最终经营决策。

### 7.2 我操作前需要什么

- 运营经理、风控/财务经理和业务责任人均已通过；
- 合同正文、附件和审批意见完整；
- 重大风险和例外事项已经被明确说明。

### 7.3 具体怎么操作

1. 从工作台打开待审批合同；
2. 重点查看交易主体、货物与价格、付款与结算、业务责任人意见及例外风险；
3. 填写最终审批意见；
4. 选择通过或驳回；
5. 检查合同最终状态。

### 7.4 我操作后产生什么

- 通过后合同生效，采销业务员可以创建执行批次；
- 驳回后合同返回修改，不允许进入执行；
- 系统保留最终审批人、时间和意见。

**下一岗位**：采销业务员开始执行拆分。

## 八、岗位操作卡：物流运营（郑小明、李纯福、蔡宇豪；郑学按授权参与）

### 8.1 我是谁

我是把执行通知转成实际车辆运输的人，负责承运资源、车辆司机、运单、物流状态、签收凭证和物流费用资料。

### 8.2 我主要操作哪些功能

| 功能模块 | 模块概念 | 操作前需要什么 | 操作后产生什么 | 下一岗位 |
|---|---|---|---|---|
| 服务生态/车辆管理 | 承运商及其车辆、司机的基础档案 | 承运关系和车辆司机资料真实有效 | 可被运单选择的承运商、车辆和司机 | 运单创建人 |
| 物流运单 | 一辆车执行一次运输的业务单据 | 已下达的执行通知，且仍有可调度数量 | 每辆车一张运单 | 调度和现场人员 |
| 调度与状态跟踪 | 记录车辆从待调度到发运、到达/送达和签收的过程 | 运单已创建，车辆司机已明确 | 状态记录、现场任务和履约时间 | 过磅、质检、仓储或客户签收 |
| 收货/签收凭证 | 证明货物已现场交接 | 车辆已到达或送达，已取得真实凭证 | 签收单、现场照片、其他交接凭证 | 运费结算及财务核对 |

### 8.3 创建和调度运单怎么操作

1. 从执行通知点击创建运单；多辆车时使用批量创建；
2. 先选择运输方式；
3. 选择物流承运商；
4. 再选择该承运商下面的车辆和司机，也可以录入临时车辆和司机；
5. 填写计划发运时间、预计到达时间、运输数量等；
6. 保存并检查是否每辆车形成独立运单；
7. 按实际情况完成调度并通知司机和现场岗位。

### 8.4 采购运单怎么推进

1. 车辆实际出发后点击“确认发运”；
2. 车辆实际到达我方现场后点击“确认到达”；
3. 到达后系统自动生成我方收货待过磅任务，并按通知要求生成质检任务；
4. 等待过磅、质检和仓储岗位完成现场作业；
5. 上传签收单、收货现场照片或其他交接凭证；
6. 满足系统条件后完成运单层面的“物流确认收货/现场交接”。

> 物流确认收货表示车辆及货物交接完成；仓储库管在入库单上的“确认收货”表示货物满足入库条件。两者属于不同岗位、不同单据，不能互相代替。

### 8.5 销售运单怎么推进

1. 等待我方出库称重、库存批次拣配和车辆放行；
2. 实际发运后点击“确认发运”；
3. 车辆到达客户后点击“确认送达”；
4. 上传客户签收单、现场照片或其他交付凭证；
5. 确认客户签收。

**我完成后的结果**：运单形成完整时间轴和附件，已签收运单进入运费结算候选。

## 九、岗位操作卡：过磅人员（郑学；其他授权人员）

### 9.1 我是谁

我是现场称重和磅单真实性的责任人，负责记录每次毛重、皮重、净重、称重时间、司磅员和现场证据。

### 9.2 磅单管理是什么

磅单管理以一笔物流称重业务为主记录，向上关联运单，向下可以包含供应商发货、我方收货、我方发货、客户收货等多张有效磅单，再从中选择库存和结算实际采用的执行口径。

### 9.3 我操作前需要什么

- 采购：运单已经确认到达，系统自动生成“我方收货称重”任务；
- 销售：运单已经确定车辆，系统自动生成“我方发货称重”任务；
- 车辆、车牌号、物料和关联运单信息正确；
- 地磅设备和现场拍照条件正常。

### 9.4 具体怎么操作

1. 从小程序现场待办或Web「磅单管理」打开任务；
2. 采购我方收货默认先称毛重、再称皮重；销售我方发货默认先称皮重、再称毛重；
3. 核对车牌后录入重量和实际称重时间；
4. 上传磅单、地磅显示照片及必要现场照片；
5. 系统计算净重后，检查是否与原始凭证一致；
6. 有追加称重时新增记录，并标明采用哪次称重；
7. 完成复核；存在多张有效磅单时选择库存和结算使用的执行磅单；
8. 改选执行磅单时填写原因。

### 9.5 我操作后产生什么

- 已复核磅单及毛重、皮重、净重；
- 可追溯的时间、人员和附件；
- 库存及结算执行重量；
- 采购入库、销售出库和运费结算可继续使用的重量依据。

**下一岗位**：采购交质检人员和仓储库管；销售交仓储库管完成拣配与放行。

## 十、岗位操作卡：质检人员（郑小明、康书红、李纯福、林娜）

### 10.1 我是谁

我是取样、送检、检测报告和最终质量判定的执行人员。多人可以分别承担现场取样、本地检测、异地检测和最终判定，但每一步都要用本人账号留痕。

### 10.2 质检管理是什么

一辆车或一个到货批次对应一项质检任务；任务下可以有一份或多份样品；每份样品可以送往一家检测机构并形成一份检测报告；系统把报告归集后形成最终质检结论。

### 10.3 我操作前需要什么

- 执行通知已要求质检；
- 运单已经到达，系统已生成质检任务；
- 已明确取样要求、检测指标、检测方法和检测机构；
- 采购入库必须取得最终合格结论；销售质检按合同或通知选配。

### 10.4 取样人员怎么操作

1. 从小程序现场待办或Web「质检管理」打开任务；
2. 点击新增样品；
3. 填写或确认样品编号、取样人、取样时间和送检机构；
4. 现场完成取样、混样、分样和标签粘贴；
5. 为每份样品分别拍照或上传照片；
6. 有多份样品时点击加号逐行增加，不把多份样品写在一行；
7. 保存并交给对应检测人员。

### 10.5 检测人员怎么操作

1. 打开本人负责样品；
2. 在“机构检测报告”区域点击“添加检测报告”；
3. 选择检测机构、指标和方法；
4. 填写实测值、检测时间和报告时间；
5. 上传正式质检单或检测报告附件；
6. 核对无误后确认报告。

### 10.6 最终判定人员怎么操作

1. 确认至少已有一份有效报告；
2. 对比合同质量标准和各机构检测结果；
3. 选择本次判定采用的执行报告；
4. 填写合格、不合格或其他最终结论；
5. 只有一份报告或少于计划份数时，填写原因并进行二次确认。

**我操作后产生什么**：样品追溯记录、检测报告、附件和任务级最终质量结论。

**下一岗位**：采购合格后交仓储库管入库；不合格或有争议时交业务责任人和运营经理处理。

## 十一、岗位操作卡：仓储库管（康书红、纪美琴）

### 11.1 我是谁

我是实物收发、库存批次和库存账的责任人。采购业务由我确认货物是否可以入库；销售业务由我按实际重量分配库存批次并完成放行和扣减。

### 11.2 采购入库是什么

采购入库管理单是从采购运单自动生成的待到货作业，不需要仓管手工新建。它归集物流、磅单、质检、仓库和收货信息，确认后再正式增加库存。

### 11.3 采购入库怎么操作

**操作前必须具备**：

- 采购运单已到达；
- 至少一张有效磅单已经复核，并已选为执行口径；
- 质检任务已形成最终合格结论；
- 仓库、实际收货时间和收货人明确。

**操作步骤**：

1. 进入「库存管理→入库单管理」；
2. 打开系统自动生成的待到货/待处理入库单；
3. 核对物流、车牌、物料、执行重量、质检结论和现场附件；
4. 补齐仓库、收货时间和收货人；
5. 点击“确认收货”；
6. 状态进入已收货待入账后，执行“生成业务入库并入账”；
7. 到在库总览和库存台账核对新增库存。

**操作结果**：生成业务入库单、库存批次和库存台账，正式增加相应业务单元、库存主体和仓库的库存。

### 11.4 销售出库怎么操作

**操作前必须具备**：

- 销售执行通知已下达，系统已生成出库管理单并冻结库存；
- 已创建车次运单；
- 我方发货磅单已完成并复核；
- 存在可分配的同业务单元、库存主体、仓库和物料库存批次。

**操作步骤**：

1. 进入「库存管理→出库单管理」；
2. 打开对应车次作业；
3. 选择本次有效出库磅单；
4. 使用先进先出自动分配，或按实际情况手工调整库存批次；
5. 核对锁定数量与实际出库重量；
6. 对短装、溢装或库存不足进行差异处理；
7. 确认车辆放行；
8. 到库存台账检查库存扣减结果。

**操作结果**：生成销售出库单，扣减库存批次，释放或调整冻结数量并写入库存台账。

**下一岗位**：放行后交物流运营确认销售发运；库存结果供业务责任人和财务查看。

## 十三、岗位操作卡：物流运费结算（蔡宇豪；财务复核人待确认）

### 13.1 我是谁

我是运费资料归集和结算制单人员，负责把已完成签收的运单按承运商和结算周期形成运费结算单。

### 13.2 我操作前需要什么

- 运单已经完成签收；
- 运单已有结算执行磅单；
- 运单未被其他未作废结算单占用；
- 固定承运商最好已维护物流合同和有效路线运价；
- 临时运输已取得可录入的人工单价和依据。

### 13.3 具体怎么操作

1. 长期合作承运商先在「物流管理→物流合同」维护合同期限和路线价格；
2. 进入「物流管理→运费结算单」；
3. 选择结算周期和承运商；
4. 从候选列表勾选已签收运单；
5. 检查系统是否按我方主体、承运商、路线和有效期匹配合同价；
6. 未匹配合同的临时运输手工补充单价；
7. 如调整合同价，填写调整原因；
8. 核对重量、单价、金额和异常扣款后提交；
9. 由指定复核人员完成复核；错误结算单通过作废重开处理。

### 13.4 我操作后产生什么

- 运费结算单及结算明细；
- 运单、执行磅单、物流合同和结算金额的追溯关系；
- 供财务核对和未来生成物流应付的数据来源。

> 当前“物流对账”汇总页面和运费结算到财务应付的自动衔接仍待开发。

## 十六、操作异常怎么处理

| 问题 | 正确处理方式 |
|---|---|
| 找不到合同、运单或任务 | 先检查业务单元、本人角色、单据状态和筛选条件，不要重复建单 |
| 上一步已做但没有生成下游任务 | 记录来源单号、操作人、操作时间和截图，交系统管理员或开发人员排查 |
| 信息填错但单据尚未提交/过账 | 使用编辑或删除草稿功能修正 |
| 合同已提交审批 | 由审批人驳回后修改，不直接篡改审批中合同 |
| 已生效合同不再执行 | 先按规则作废，再由管理员按权限处理删除；不直接删除正常合同 |
| 已过账库存错误 | 发起库存冲销，审核后反向过账；不删除库存台账 |
| 磅单或检测报告选错 | 在允许状态下修改，并记录改选原因；已经被下游使用时先确认影响范围 |
| 现场暂时无网络 | 保留真实原始凭证、时间和照片，恢复网络后及时补录并注明实际发生时间 |
| 系统按钮无反应或提示不明确 | 不连续重复点击；记录页面、单据号、时间、账号、提示和截图后反馈 |
