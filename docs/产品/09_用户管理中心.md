# 用户管理中心

> 状态：个人用户关联、企业工作台、移动合同审批及核心业务只读查询已完成

## 1. 模块定位

“用户管理”是运营管理后台的独立一级模块，导航位置在“内容运营”下方、“基础管理”上方；进入页面后使用完整名称“用户管理中心”。

该模块面向官网、小程序及未来产业链平台中的个人用户，承接个人身份、微信登录资料、已验证手机号、后台企业账号关联及后续用户运营能力。

## 2. 与现有账号体系的边界

- 用户管理中心：面向平台外部个人用户，例如官网访客、小程序用户及未来平台注册用户。
- 组织数据中的员工和用户账号：面向 RICSE 内部员工及获得后台访问权限的外部企业员工。
- 合作伙伴：继续维护企业、机构或其他业务主体，不因新增个人用户管理而改变现有主数据口径。
- 个人用户与后台账号不合并为一条数据，通过受控的一对一关联建立移动端企业身份。
- 手机号只用于检索和人工核对，不根据相同手机号自动合并、自动关联或覆盖数据。

## 3. 已实现范围

- “用户管理 → 个人用户”提供真实小程序用户列表、详情、检索、状态筛选和关联状态筛选。
- 小程序用户完成微信登录后自动建立个人用户档案，保存 OpenID、UnionID、昵称、头像、来源、注册时间和最近登录时间。
- 用户可在小程序主动授权手机号；系统只接受微信服务端换取的手机号并记录验证时间。
- 运营管理员可以选择现有的有效企业后台账号进行关联、重新关联和解除关联。
- 一个个人用户同一时间只能关联一个后台账号，一个后台账号也只能关联一个个人用户。
- 关联、重新关联和解除关联均保留操作人、时间、目标账号及备注等审计记录。
- 后台“组织数据 → 用户账号”显示小程序关联状态，并可跳转个人用户管理。
- 小程序“我的”显示手机号验证状态、后台账号关联状态、所属企业、员工与部门。
- 已关联且有效的用户可进入小程序“企业工作台”，查看待审批数量、合同数量和执行中合同数量。
- 企业工作台提供合同待审批、已审批列表及合同审批详情，支持填写审批意见后同意或驳回。
- 移动审批直接复用后台合同状态机、节点分配、或签/会签、管理员审批全部节点及并发校验，不单独复制审批规则。
- 企业工作台根据关联后台账号的实时权限，开放合同、执行批次、执行通知、物流运单、磅单信息、质检任务和库存批次查询入口。
- 各移动业务列表支持关键字检索，详情展示来源单据、关键业务字段和向下关联记录；第二阶段统一保持只读。
- 移动业务查询直接调用后台既有业务服务，继续执行功能权限、企业范围及来源单据数据范围校验。
- 个人用户被禁用，或关联的后台账号、员工、企业被禁用时，不开放企业工作台。
- 管理端接口沿用 `system.user.manage` 权限，当前导航仍仅系统管理员可见。

## 4. 小程序导航与登录交互

- 未登录或已微信登录但尚未关联有效后台账号时，底部保持四项：`首页｜资讯｜行情｜我的`，不提前展示企业功能。
- 仅当服务端返回 `workspaceEnabled=true` 时，底部动态显示五项：`首页｜资讯｜工作台｜行情｜我的`。
- “我的”页面始终保留“我的工作台”入口：未登录时点击后提示微信登录；已登录未关联时提示联系企业管理员并可刷新；关联账号失效时显示停用提示；有效关联时直接进入工作台。
- AI 助手不占用底部导航，改为首页快捷入口；资讯和行情继续服务所有用户。
- 关联、解除关联、账号停用或重新登录后，小程序重新获取服务端账号上下文并即时刷新底部导航；本地缓存仅用于首屏显示，不作为授权依据。
- 通过历史路径直接打开企业工作台时仍执行服务端校验，未开通用户返回“我的”页面，不能以隐藏导航代替权限控制。

## 5. 关联业务规则

1. 后台账号仍在“组织数据”中创建，必须关联有效企业和员工档案。
2. 关联不创建新账号、不占用额外企业账号名额，也不授予新角色。
3. 企业权限实时继承后台账号已有的角色、权限和数据范围。
4. 外部企业用户继续限定在本企业关联业务数据范围内。
5. 用户名、员工手机号、微信验证手机号三者独立保存；微信手机号不能替代后台账号主数据。
6. 列表中的 OpenID 默认脱敏，运营人员可使用完整 OpenID 搜索定位但不在页面完整展示。
