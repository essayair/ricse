# 用户管理中心

> 状态：一级模块和页面入口已占位，具体产品方案待讨论

## 1. 模块定位

“用户管理”是运营管理后台的独立一级模块，导航位置在“内容运营”下方、“基础管理”上方；进入页面后使用完整名称“用户管理中心”。

该模块主要面向官网、小程序及未来产业链平台中的个人用户，后续用于承接个人身份、账号、用户档案和用户运营能力。

## 2. 与现有账号体系的边界

- 用户管理中心：面向平台外部个人用户，例如官网访客、小程序用户及未来平台注册用户。
- 组织数据中的员工和用户账号：面向 RICSE 内部员工及获得后台访问权限的外部企业员工。
- 合作伙伴：继续维护企业、机构或其他业务主体，不因新增个人用户管理而改变现有主数据口径。
- 当前阶段三类数据不合并，也不建立自动映射关系。

## 3. 当前实现范围

- 新增一级菜单“用户管理”，二级入口暂设为“个人用户”。
- 新增“用户管理中心”占位页面和中文面包屑。
- 页面说明候选规划方向：用户档案、账号与身份、用户运营。
- 暂不新增数据库表、后端接口、用户同步任务和业务权限编码。
- 为避免未定方案提前扩大数据访问范围，占位入口当前仅系统管理员可见。

## 4. 后续需要确认的产品问题

1. 用户来源：官网、小程序和其他平台账号是否合并为一个自然人档案。
2. 身份标识：手机号、微信 OpenID/UnionID、邮箱及实名信息的主次关系。
3. 用户生命周期：游客、注册、认证、正常、限制和注销等状态口径。
4. 用户运营：标签、分群、活跃行为、内容偏好、供需记录和服务跟进的范围。
5. 隐私合规：授权记录、敏感字段脱敏、数据导出、注销和留存期限。
6. 权限边界：哪些运营角色可以查看、编辑、导出或限制个人用户。
7. 与交易体系的关系：个人用户何时可以升级为企业员工、业务联系人或交易参与人。

以上问题完成评审后，再确定数据模型、接口、页面字段、权限和分阶段交付范围。
