# 矿产供应链运营管理系统
## 05 仓储库管 · 库存管理

---

## 角色定位

仓储库管是**货物进入仓库后的管理中枢**，以批次为核心记录货物的数量、位置与质量状态，连接采购入库与销售出库两端，为财务成本核算和风控敞口管理提供库存数据基础。

> **典型岗位**：仓库管理员、台账录入内勤（如徐甜甜、海文岗）

> **系统角色**：`WAREHOUSE_KEEPER`（仓储库管）。默认可以管理出入库、库存批次、库存台账和库存冲销，并查看合同、执行、物流、质检及主数据。库存冲销审核还需组合授予“审批人”角色。

---

## 业务链位置

```
【物流运营】（到货确认，物流入库单）
【现场一线】（质检合格，磅单净重）
          ↓
【仓储库管 · 库存管理】← 你在这里
     ↙              ↘
采销业务员           财务结算
（履约进度跟踪）    （批次成本核算）
                         ↓
                    风控/管理者
                  （库存敞口计算）
```

## 上游任务流：开始操作前需确认

| 前置条件 | 来源 | 说明 |
|---------|------|------|
| 入库作业单已自动生成 | 系统 | 采购运单确认发运、进入在途时自动创建；确认到达时幂等补生成 |
| 车辆到达与签收 | 物流运营 | 入库作业单持续展示待到货、已到达和签收状态，不再等质检结束后才出现 |
| 磅单净重已确认 | 现场一线（地磅） | 磅单净重是最终入库数量的基础依据；未复核时作业单提示当前阻塞节点 |
| 质检结论已确认合格 | 现场一线（质检化验） | 合格结论补齐原作业单的最终验收依据；超标扣款、熔断和待判定不可形成库存 |
| 采购合同已生效 | 采销业务员 | 业务入库单关联对应采购合同，跟踪合同履约进度 |

### 一、业务入库单

#### 1.1 功能说明

采购运单确认发运、进入在途时，系统自动生成一张“待到货”的入库作业单。该单持续跟踪运输到达、物流签收、过磅复核、质量验收、现场收货和库存入账。仓管在最终验收合格后补齐仓库、实际收货时间和收货人，完成**收货确认**后生成业务入库、库存批次和库存台账，确认货权及库存正式形成。

**数据来源**：物流入库单 + 采购合同 + 质检结果

#### 1.2 关键规则

| 规则 | 说明 |
|------|------|
| 自动生成 | 采购运单进入“在途”时生成入库作业单，“到达”时再次幂等检查；一张采购运单只能有一张有效入库作业单 |
| 作业跟踪 | 单据分别展示运输、签收、过磅、质检、收货和入账节点，并提示“待过磅”“待复核”“待质检”等当前阻塞事项 |
| 质检前置 | 同车可存在多张独立质检单；第一张确认合格单自动成为最终验收依据，也可在待入库阶段改选其他已确认合格单；“超标扣款”“熔断”和“待判定”均不可形成系统库存 |
| 磅单数量 | 入库数量优先使用最终验收质检单结算重量，否则使用已复核磅单结算重量 |
| 合同关联 | 业务入库单关联采购合同，系统自动更新合同履约进度 |
| 预出库规则 | 业务入库单**未过账时**（业务状态"业务已确认"、入账状态"未生成"），**可以先做销售发货通知单（预出库）** |
| 过账操作 | 财务"确认"和"过账"合并为一个按钮"确认并过账"，过账后库存正式计入账面 |

#### 1.3 特殊业务场景

| 场景 | 说明 |
|------|------|
| 无采购入库 | 支持创建新批次入库（非采购来源的库存形成） |
| 商品编码转化 | 入库时支持物料编码转化映射 |
| 定价调整单 | 价格确认后通过定价调整单更新批次成本 |

#### 1.4 入库关联链

```
物流入库单
    + 磅单净重（数量依据）
    + 质检报告（合格结论）
    + 采购合同（履约关联）
         ↓
    业务入库单（库存形成）
         ↓
    批次成本核算开始计算
```

### 二、过磅管理（仓库侧）

#### 2.1 功能说明

电脑本地磅单上传到系统，手动关联物流车辆，核对供货/收货单位。

| 功能 | 说明 |
|------|------|
| 磅单上传 | 从地磅电脑本地导出/上传磅单数据到线上系统 |
| 双磅单采集 | 同时录入供方磅单（供应商/矿山端）和我方现场磅单 |
| 磅单关联 | 手动关联物流运单和车辆，核对货物来源 |
| 拍照留存 | 上传磅单拍照，图片与磅单记录绑定存档 |

> **操作说明**：一期共用地磅设备但不共用本地数据，由仓库岗位同事在地磅电脑手动上传磅单数据到系统。

### 三、销售出库（销售发货通知单）

#### 3.1 功能说明

销售发货通知单是销售出库的核心执行单据，直接关联销售执行批次，并通过执行批次追溯销售合同；向下触发物流出库和库存扣减。

#### 3.2 支持的出库模式

**常规出库**：
```
销售执行批次 → 销售发货通知单 → 拣配库存 → 物流出库 → 过磅确认 → 库存扣减
```

**直拨出库**：
```
供应商直接发货给客户（不经我方仓库）
→ 系统补完入库+出库流程（维持数据完整性）
```

**销售退货**：
```
支持退货到原批次（合并）或创建新批次入库
```

#### 3.3 关键规则

- 出库必须关联销售执行批次、对应销售合同和库存批次
- 出库数量不可超过可用库存量
- 出库数量以已复核出库磅单为依据，并可追溯相关入库批次及其入库磅单
- 常规销售出库在物流运单发运前完成；已复核出库磅单是物流出库单的数量依据
- 支持从同仓库、同物料的多个库存批次组合出库，并可按入库时间先进先出自动分配
- 销售出库入账、逐批次库存扣减和负数库存台账必须在同一事务完成
- 一期支持单一物料常规出库；直拨、多物料混装和销售退货后续完善

### 四、库存查询（业务库存）

| 查询维度 | 说明 |
|---------|------|
| 按物料 | 特定物料（如萤石粉精矿）当前总库存 |
| 按批次 | 每个批次的来源、入库数量、质检状态、已出库数量、剩余数量 |
| 按仓库/库位 | 每个库位当前存放的货物和数量 |
| 按部门 | 不同业务组归属的库存 |
| 库存日报 | 每日库存变动明细（入库/出库/移库/调整） |

---

### 五、库存调拨

| 功能 | 说明 | 优先级 |
|------|------|--------|
| 仓库间调拨 | 货物从一个仓库移到另一个仓库 | P1 |
| 库位间调拨 | 同仓库内库位间移动 | P1 |
| 原批次调拨 | 保持原批次号，更新位置信息 | P1 |
| 新批次创建 | 调拨时新建批次（如分批存放场景） | P1 |
| 销售移库 | 内部利润中心间按移库核算（利润中心A → 利润中心B） | P1 |

> **销售移库说明**：当货物从一个利润中心转移到另一个利润中心时，系统按移库金额核算内部利润，而非等待最终销售完成。

---

### 五-A、库存冲销

已经入账的业务入库单和销售出库单不得删除或直接修改数量，应通过库存冲销处理：

- 入库冲销：减少原业务入库批次的初始数量与可用数量。
- 出库冲销：严格恢复到原销售出库明细使用的库存批次。
- 支持多次部分冲销，待审批、审批通过、已过账数量共同占用冲销额度。
- 系统管理员和审批人审核，审核通过后再执行库存过账。
- 冲销过账生成独立正/负库存台账并保留原台账。

### 六、报损 / 报溢

| 功能 | 说明 | 优先级 |
|------|------|--------|
| 盘点录入 | 录入实际盘点数量，系统对比账面库存 | P1 |
| 差异单生成 | 账面 vs 实盘，生成盘点差异单 | P1 |
| 报损处理 | 差异为负（实际少于账面），生成报损单，关联审批流程，更新库存 | P1 |
| 报溢处理 | 差异为正（实际多于账面），生成报溢单，关联审批流程，更新库存 | P1 |

---

### 七、批次成本核算
**优先级：P1**

| 内容 | 说明 |
|------|------|
| 成本构成 | 货款（采购单价×入库数量）+ 运费分摊 + 其他费用分摊 |
| 分摊方式 | 货款/费用按重量比例分摊到批次 |
| 加权平均 | 同物料多批次按加权平均实际成本计算综合单位成本 |
| 出库成本 | 出库时按批次成本确认销售成本 |
| 适用场景 | 普通采购入库、委托加工入库、移库核算等多种场景 |

---

### 八、库存报表
**优先级：P1**

月底自动出具以下报表供财务使用：
- **库存台账**：按批次列示期初/本期入库/本期出库/期末数量和金额
- **收发存汇总**：按物料汇总当期收货量、发货量、期末库存量
- **库龄分析**：按批次列示入库日期和在库天数，识别滞销风险

## 完整操作流程

**采购入库标准流程**：

```
① 采购运单确认发运、进入在途，系统自动生成“待到货”入库作业单
② 车辆到达，系统更新运输节点；若此前漏单则自动补生成
③ 现场完成过磅并复核磅单，作业单更新为“已过磅待质检”
④ 创建一张或多张质检单，确认合格质检单成为最终验收依据
⑤ 仓管打开入库作业单，核对物流运单、磅单、最终质检、采购合同和供应商
⑥ 补齐仓库、实际收货时间和收货人，上传现场照片和签收凭证
⑦ 确认收货
⑧ 生成业务入库并入账（同步生成库存批次和库存台账）
⑨ 通知采销业务员：收货完成，可发起结算
```

**销售出库标准流程**：

```
① 接收销售发货通知单（由采销业务员下达）
② 确认库存可用数量（质检合格、未预占的库存）
③ 拣配库存批次
④ 通知物流运营安排出库运输
⑤ 出库过磅（地磅数据确认出库数量）
⑥ 在系统中创建物流出库单/业务出库单
⑦ 库存扣减（批次剩余数量更新）
⑧ 关联销售合同（销售合同履约进度更新）
```

| 下游角色 | 触发事项 | 说明 |
|---------|---------|------|
| 采销业务员 | 业务入库单确认 | 采购合同履约进度更新，系统触发结算流程 |

## 模块关联关系

| 关联模块 | 关系说明 |
|---------|---------|
| 物流管理 | 到货/发货触发入库/出库单；物流入库单是业务入库单的前置 |
| 质检化验 | 入库批次触发质检；质检结论决定批次是否可用入库 |
| 地磅管理 | 过磅净重作为入库数量依据；磅单关联入库单 |
| 采销系统 | 出入库关联合同及其执行批次，跟踪合同履约进度 |
| 财务结算 | 批次成本数据为成本核算和资金计息提供基础 |
| 主数据管理 | 仓库、库位、物料取自主数据 |

## 权限与企业数据范围

- 入库、出库、库存批次、库存台账和库存冲销统一使用库存模块查看/管理权限。
- 采购库存从采购合同链继承范围，销售出库从销售合同链继承范围；冲销继续继承被冲销原单。
- 外部企业员工可查看本企业参与交易形成的入库、出库和库存数据，不按收货人、库管或创建人拆分。
- 库存总览的汇总值只统计用户可见库存批次；候选库存批次同时校验销售运单范围和库存来源范围。
- 冲销审批读取有效多角色授权，仅审批人或系统管理员可以审核。

统一口径见[权限与数据范围规范](./权限与数据范围规范.md)。
