# 合同复制新建

日期：2026-11-13；集成更新：2026-11-18。状态：本地已开发及验证，纳入本次功能集成提交；线上生效以云效部署结果为准。

## 1. 用途与入口

适用于交易主体、货物及条款相近的新合同。复制是新建，不是修改原合同、合同变更或补充协议。

- 合同管理列表：点击操作列「复制」。
- 合同详情：点击「更多 → 复制新建」。
- 进入完整填写页面，标题默认「原合同标题（副本）」。仅打开页面不会创建数据库草稿。

## 2. 带入与重置

| 内容 | 处理 |
| --- | --- |
| 合同类型、我方主体、交易对手方、联系人 | 带入，可修改；停用、删除或当前不可选的主体清空并提示 |
| 全部货物行、数量、单位、税率、含税/不含税价格 | 逐行带入，不只复制第一行；双边采购价、销售价分别保留 |
| 品位分档、扣水模式及基准水分、人工例外规则 | 按原合同快照带入，采销各自独立；规则确认勾选清空，需重新核对 |
| 合同质量结算规则 | 保留原合同快照，不自动覆盖为最新物料模板；主动更换物料时按新物料重新带入 |
| 履约、交货及结算条款、备注 | 带入，可修改 |
| 业务单元（事业部） | 原单元在当前新建授权范围内时保留，否则改用默认单元或要求重新选择 |
| 业务部门 | 使用当前操作人员工的默认部门，不照搬原创建人部门 |
| 系统 ID、合同编号、状态、创建人和创建时间 | 不复制；保存时生成新编号，创建人及时间取本次实际操作 |
| 外部合同号、采销签订日期、生效日期、到期日期 | 清空，按新合同填写 |
| 合同附件 | 不复制，须重新上传新合同文件 |
| 审批、执行批次、执行通知、运单、计量、质检、库存和结算 | 均不复制、不关联到新合同 |

草稿、已驳回合同以已保存的原始表单恢复未填完的货物；已审批或执行合同以正式内容为准，不采用残留草稿缓存。停用或删除的物料需要重新选择，原文字保留便于核对。

## 3. 使用步骤

1. 找到相近合同并点击「复制」。
2. 核对页面显示的来源合同、事业部、当前部门及不可选档案提示。
3. 修改新合同标题，填写外部编号与日期，核对各行货物、采销价格、质量及扣水规则。
4. 重新选择附件，名称可修改。首次保存时附件随新草稿上传，不上传至原合同。
5. 点击「保存草稿」，或者在有提交权限时点击「提交审批」。审批完整性要求与普通新建合同一致。

未填完整可保存草稿。离开页面可选择保存、不保存或继续填写；未保存而放弃不会产生新合同。刷新/关闭标签页受浏览器限制，应主动保存。

## 4. 失败与重试

- 同次页面新建使用唯一请求标识，重复点击、并发请求或网络重试只生成一份草稿。
- 草稿保存成功后即记住新合同 ID；附件上传或提交审批失败，继续处理同一份新草稿，不重新复制、不影响原合同。
- 已上传成功的附件从待上传列表移除，后续可继续处理失败的附件。
- 提交未通过时，按提示补齐新合同后继续提交；原审批及履约数据不发生变化。

## 5. 权限及追溯

- 必须同时有来源合同查看权限、来源数据范围以及合同新建权限；新合同仍按目标事业部的新建授权校验。
- 后续编辑、附件、提交等操作继续遵循现有合同权限，不因复制额外放权。
- 外部企业用户不得复制双边合同，避免取得两侧商业条款。
- 新合同操作记录登记「复制新建合同」、来源合同编号、操作人员和时间，沿用管理员专属的操作记录入口。
- 本期提供 Web 入口，小程序不新增合同创建/复制入口。

## 6. 验收重点

单行与多行、双边采销独立价格、未完整草稿、停用主体/物料、事业部越权、重复保存、上传/提交失败后继续、原合同及其附件/执行/审批完全不变。

无需数据库结构迁移；不自动重写任何既有合同。
